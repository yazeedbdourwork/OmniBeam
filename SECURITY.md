# Security policy

Thank you for helping keep OmniBeam and the people who use it safe.

## Reporting a problem

Please report security problems **privately**, not in a public issue:

- Use GitHub's private report form: <https://github.com/yazeedbdourwork/OmniBeam/security/advisories/new>

Please include what you found, the steps to reproduce it, and which page or feature it affects. You can write in
English or Arabic. You should get a first reply within a few days.

## What is in scope

- The website <https://omnibeam.site> and its server (`server.js`)
- The browser extensions and the command-line tool (`cli/`) in this repository

Please don't run tests that slow the site down for other people (load tests, spam), and don't look at or keep other
people's files or messages.

The machine-readable version of this policy is at <https://omnibeam.site/.well-known/security.txt>.
