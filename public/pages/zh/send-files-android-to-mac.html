如何不用数据线把文件从 Android 传到 Mac

Mac 和 Android 手机之间没有隔空投送，Android File Transfer 也已经停止支持。OmniBeam 通过 Wi‑Fi 在浏览器中直接在它们之间传照片、视频和文档，无需安装任何东西。

步骤

  1. 在 Mac 上用 Safari、Chrome 或 Firefox 打开 omnibeam.site。
  2. 在 Android 手机上用 Chrome 打开 omnibeam.site。片刻后两台设备会互相显示。
  3. 在手机上点按 Mac，选择照片、视频或任何文件。
  4. 在 Mac 上点击接受，然后点保存。多个文件可以一起保存为 ZIP。

从 Mac 发到手机

双向都能用：在 Mac 上把文件从访达拖到手机的卡片上，然后在手机上接受。

更快的用法

  • 在手机上安装 OmniBeam(Chrome 菜单，然后选安装应用)。之后它会出现在 Android 的分享菜单中：从图库分享并选择 Mac 即可。
  • 在 Mac 上可以把 OmniBeam 添加到访达的右键菜单；参见从 Mac 和 Linux 发送文件。
  • 不在同一 Wi‑Fi？用 6 位数代码把两台设备配对一次，之后在哪里都能找到彼此。

Android File Transfer 已不再更新，很多 Mac 用户没有简单的办法从 Android 手机取出文件。两边各开一个浏览器标签页就够了：Mac 上不用装任何东西，照片和视频以原画质送达。

用 OmniBeam，你无需数据线、应用或账号，就能把文件从 Android 发到 Mac。

问题与解答

为什么我的 Mac 通过 USB 看不到 Android 手机？

没有额外软件时，macOS 不支持 Android 手机通过 USB 使用的文件传输模式，而 Apple 的隔空投送也不包括 Android。基于浏览器的工具能同时避开这两个问题。

Mac 上应该用哪个浏览器？

Safari、Chrome、Edge 和 Firefox 都可以。在其中任意一个打开 omnibeam.site，发送时保持标签页打开。

文件保存在 Mac 的哪里？

默认保存在“下载”文件夹，或你的浏览器设置的下载位置。多个文件也可以一起保存为一个 ZIP。

可以发送文件夹吗？

可以。你可以从 Mac 发送整个文件夹，在 Android 上也可以从图库或文件管理器一次选择很多文件。

反过来也能用吗？

能，从 Mac 发到 Android 手机也可以。

需要同一个 Wi‑Fi 吗？

不一定。在同一 Wi‑Fi 下 Mac 会自动出现。如果手机用的是移动数据，用 Mac 上显示的 6 位数代码或二维码把两台设备配对一次即可。

传文档安全吗？

安全。每次传输都在你的手机上端到端加密，只有 Mac 能解密。途中不会在服务器上存储任何内容。

能让 Mac 上的 OmniBeam 随时待命吗？

能。在浏览器中固定这个标签页，或在 Chrome 中添加 OmniBeam 扩展程序，Mac 随时打开都能接收。
