一步步教你使用 OmniBeam

OmniBeam 直接在浏览器中，在你的设备之间发送文件和文字。下面一步步介绍它能做的所有事情。

1. 同一 Wi‑Fi 下的设备

  1. 在两台设备上打开 omnibeam.site。
  2. 每台设备都会自动显示另一台，并带有一个类似“Blue Fox”的随机名字。点按底部你的名字可以给这台设备改名。
  3. 点按另一台设备并选择文件，或把文件拖放到它上面。在电脑上，你也可以把鼠标悬停在它上面，选择发送文件或发送消息。
  4. 另一台设备会询问是否接受。之后文件到达，可以保存或打开。

2. 不同网络中的设备

手机用移动数据、VPN 或 iCloud 专用代理时，设备会处在不同网络中，因此不会自动看到彼此。把它们配对一次：

  1. 点按顶部的链接按钮，选择创建配对代码。
  2. 在另一台设备上输入 6 位数代码、用相机扫描二维码，或打开分享的链接。
  3. 从此以后，两台设备在任何网络中都能找到彼此。你可以在同一个窗口中取消配对。

3. 适合多台设备的公开房间

在配对窗口中创建一个公开房间。分享它的 5 个字母的代码或链接，任意数量的设备都能从任何网络加入。适合课堂、会议和家人交换照片。创建房间前加个密码，就能把陌生人挡在外面。

4. 通过链接分享文件

在顶部的 ⋯ 菜单中点按通过链接分享文件，选择文件和链接的有效期。文件在你的设备上加密后上传，你会得到一个链接和一个二维码，任何人都能打开，即使是之后、在任何设备上。详见通过链接发送文件。

5. 发送文字和链接

右键点击一台设备（触摸屏上长按）并选择 发送消息：会打开与这台设备的聊天，在底部的输入框中输入文字、链接或复制的内容（见下文与设备聊天）。收到的消息也在同一个聊天里阅读：收到消息时，对应的聊天会伴随一声简短的提示音自动打开。如果你正忙于其他操作，则改为在顶部显示一个小横幅，显示发送者和开头几个字：点按它即可打开聊天。你也可以在页面中粘贴，发送剪贴板中的内容。

6. 收到的文件

点按顶部的下载按钮，查看过去 7 天收到的文件并再次保存。多个文件可以一次保存为一个 ZIP。iPhone 的 HEIC 照片可以保存为 JPG。

7. 把 OmniBeam 安装为应用

在 Android 以及使用 Chrome 或 Edge 的电脑上，OmniBeam 会在页面底部提供安装。在 iPhone 上，点按 Safari 中的分享按钮，选择添加到主屏幕。在 Android 上安装后，OmniBeam 还会出现在图库和其他应用的分享菜单中。

8. Windows：Microsoft Store 中的 OmniBeam 应用

获取免费的 Microsoft Store 版 OmniBeam 应用。它在自己的窗口中打开，可从开始菜单或任务栏启动，并会出现在 Windows 共享菜单中：在文件资源管理器中右键单击文件，选择共享，然后选择 OmniBeam。在 Chrome 或 Edge 中，OmniBeam 扩展程序可以通过右键发送页面、链接、图片或选中的文字。具体步骤见 Windows 版 OmniBeam。

9. 同一 Wi‑Fi 下更快地传输

点按底部的⚡ 加快 Wi‑Fi 传输，允许一次麦克风权限。不会录制任何内容；浏览器只把设备的本地网络地址告诉拥有这项权限的网站，有了它，设备就能通过你的 Wi‑Fi 直接连接，而不是经过路由器的互联网连接。点按设备名旁边的网络 ID 可以运行连接检查。

10. 文件夹、队列、取消和自动接受

  • 文件夹：把文件夹拖到设备上，或悬停在设备上选择“发送文件夹”。它会以 ZIP 的形式到达，里面的文件夹结构保持不变。
  • 队列和取消：传输进行中发送的文件会排队等待。点按设备上的 ✕ 即可停止。看得到多台设备时，“发送给所有人”会发给所有设备。
  • 自动接受：在链接窗口中，为已配对的设备开启自动接受，就能不经询问接收它的文件。
  • 受信任的设备：在链接窗口中，勾选你自己已记住的设备旁边的“受信任”。它们总是显示在主屏幕上(离线时显示为灰色)，发来的文件无需询问就会到达。
  • 原图或缩小的照片：照片按原始大小发送。网络较慢时，在“更多…”窗口或聊天的照片下选择缩小，或在设置的发送时的照片大小中选择：大照片会缩小到最长边 2048 像素(JPG)，方向正确，OmniBeam 还会显示节省了多少。GIF、带透明部分的图片和本来就小的照片会原样发送。设置中也可以缩小视频(720p)。你设备上的原文件不会改变，选择会被记住。
  • 中断的传输：如果页面重新加载或连接断开，在一天之内再次发送同样的文件，只会发送缺少的部分。
  • 语言：在页面底部选择 English、العربية、Français、Español、Türkçe、Deutsch、Português、हिन्दी、Bahasa Indonesia、Русский、日本語、简体中文、한국어、Italiano、اردو。

11. 通过电子邮件或短信发送链接

在顶部的 ⋯ 菜单中点按发送到邮箱或手机(电脑上显示为通过邮件发送)。输入电子邮件地址，或在手机上输入电话号码，然后选择文件。OmniBeam 会加密并上传它们，然后打开你的邮件或信息应用，下载链接已经写好，你只需按发送。通过链接分享文件时，你也可以填写发送给(可选)。短信在手机上可用；电脑使用电子邮件。

12. 链接选项：最长 7 天、下载次数限制和 PIN 码

  • 有效期：链接有效 1 小时、1 天、3 天或最长 7 天。之后文件会从服务器上删除。
  • 允许下载次数：选择不限，或 1、3、5、10 次。达到上限后链接就会失效。在你的链接中可以看到已用和剩余的下载次数。
  • PIN 码：添加 4 到 8 位数字的 PIN 码。对方就需要链接和 PIN 码才能下载。请用别的方式告诉对方 PIN 码，例如打电话，而不是在同一条消息里。输错 10 次后，链接会永久锁定。

13. 在另一台设备上继续中断的发送

如果发往某台已配对设备的发送中途停止，比如那部手机离开了 Wi‑Fi，几秒后 OmniBeam 会显示一张卡片，提议把剩下的部分发到你的另一台已配对设备。点按发送到 …，只有没送达的文件会发到那里。如果第一台设备回来了，传输会自动继续，卡片也会消失。

14. 历史记录、图库和全部保存

点按顶部的下载按钮打开历史记录。它有三个标签页：

  • 已收到：过去 7 天的文件和消息，可以再次保存。
  • 图库：其中的照片和视频以缩略图显示。点按一个可查看原图，然后滑动或用方向键查看下一个。全部保存会一次保存所有照片和视频：在电脑上保存为一个 ZIP，在 iPhone 和 iPad 上保存到“照片”。
  • 已发送：这台设备发送过的内容，带有“再次发送”(见下一步)。

当两张或更多照片或视频一起到达时，显示它们的窗口里也有一个图库按钮。在 iPhone 和 iPad 上，点按存储到照片，然后选择“存储图像”或“存储视频”，照片就会进入“照片”应用，而不是“文件”。

15. 发送记录、再次发送和导出

历史记录中的已发送标签页列出了你过去 7 天发送的内容：发给了哪台设备、哪些文件，以及是否送达、被拒绝或失败。点按再次发送可以把同样的文件再发给同一台设备，如果那台设备不在，可以选另一台。页面重新加载后，因为浏览器不会保留文件，“再次发送”会要求你重新选择文件。导出会把列表下载为 Excel 或 Google 表格可用的表格(CSV)，全部清除会清空这个标签页。

16. 适合家庭或办公室的团队房间

团队房间是一组设备专用的固定链接。点按顶部的链接按钮，在团队房间下输入一个名字，比如“家庭”或“办公室”，然后点按创建。分享链接或展示它的二维码。每台打开过一次链接的设备都会留在房间里，无论在什么网络，每次打开 OmniBeam 都在，无需代码，也不用再次配对。团队成员的卡片会显示团队名称，你还可以为团队开启自动接受。一个团队房间最多容纳 50 台设备，你可以在同一个窗口中退出。

17. 你的设备名称、图片和主题

点按底部的设备名，或设置中的更改名称和图片，给这台设备起个名字并选一个表情图片。其他设备会在它的卡片上看到这两样。随机名称会帮你挑一个新名字。在设置中你还可以选择主题：“自动”跟随你的设备，也可以选浅色或深色。

18. 剪贴板同步和测速

  • 剪贴板同步：先配对设备，然后在两台设备的设置中开启与已配对设备同步剪贴板。只要 OmniBeam 开着，在一台上复制的文字就会进入另一台的剪贴板。如果浏览器阻止访问剪贴板，点按立即发送我的剪贴板。
  • 测速：在 ⋯ 菜单或设置中点按测试速度，看看这台设备和另一台实际能以多快的速度传输，以及文件走的是哪条路。

19. 拍照、语音消息、屏幕共享和秘密便签

  • 更多…：把鼠标悬停在设备上选择更多…，或在手机上长按设备，就能看到可以发给它的所有内容。
  • 拍照：相机直接在 OmniBeam 中打开。点按拍照，然后点按发送。开启文档扫描，就能拍出清晰的黑白页面和白板。
  • 语音消息：说话时按住圆形按钮，松开即停止。试听后再发送。
  • 共享屏幕：在电脑上选择共享我的屏幕，然后选一个窗口或整个屏幕。另一台设备，即使是平板电脑或电视浏览器，点按观看就能实时观看，无需安装任何东西。不会录制任何内容。
  • 秘密便签：发送只显示一次、从不保存的密码或代码。在通过链接分享文件中，改为秘密便签会生成一个只能打开一次的链接。
  • 预览：在收到的文件和历史记录中点按预览，可以在保存前查看 PDF、图片、音频、文本或代码文件。

20. 向任何人请求文件

在顶部的 ⋯ 菜单中点按请求文件。你可以写下需要什么(例如“周六的照片”)，选择链接的有效期、可接收的上传次数和可选的 PIN 码，然后把链接或二维码发给任何人。对方在任何手机或电脑上打开，无需应用、账号或配对，选好文件点按发送即可。文件在对方的设备上加密后到达你的设备，出现在“收到的文件”中。如果对方发送时 OmniBeam 是关着的，文件会在服务器上等待，下次你打开时到达(开启通知的话会收到通知)。你的请求链接会显示每个链接收到了多少次上传。

21. 在电视上展示照片

在智能电视的浏览器(或连接到电视的电脑)中打开 omnibeam.site/tv，或在 ⋯ 菜单中选择电视模式。电视会显示一个大二维码：用手机相机扫描，手机上的 OmniBeam 就会打开，并且已经和电视配对。点按电视并选择照片或视频；它们会自动到达，并以全屏幻灯片播放，每 8 秒换一张。用遥控器的方向键在按钮之间移动，按 OK 选择。在幻灯片中，◀ 和 ▶ 切换照片（视频中快退/快进 10 秒），▲ 和 ▼ 切到上一个或下一个，OK 暂停，返回键打开照片墙，即收到的所有内容的网格；再按返回回到二维码。发送到电视的音乐在后台播放，消息以大字显示（链接还会显示为可扫描的二维码），电视无法读取的 iPhone 照片会说明如何发送。幻灯片设置可以更改速度、顺序、淡入淡出和缓慢放大。电视页面重新加载后照片仍在，直到你选择“清除照片”。配对的手机可以当遥控器：点一下电视，再点“遥控器”。几分钟无操作后，时钟屏保会在屏幕上缓慢移动。同一 Wi‑Fi 下的手机无需扫描就能看到电视(电视在接收它们的文件前会先询问)。电视模式只接收：它从不发送任何东西。每个二维码配对一部手机，下一个人的新代码会立即出现。

电视的密码：在电视屏幕上选择设置 PIN，输入 4 到 8 位数字。扫描二维码后，手机会要求输入 PIN 码，只有输入正确的手机才能配对。开启 PIN 码后，即使在同一 Wi‑Fi 下，电视也会拒绝没有配对的手机发来的文件。PIN 码从不离开电视或手机。和每次 OmniBeam 传输一样，发到电视的照片都是端到端加密的。

22. 网站上的“给我发送文件”框

在请求文件中选择1 年(用于网站)，创建链接，点按放到你的网站上，然后把代码复制到你的网站或博客中(HTML 或 Embed 区块)。访客可以直接在那里给你发送文件，端到端加密，它们会像链接收到的任何上传一样到达这里。在 WordPress 上，你也可以改用免费的 OmniBeam 插件：一个区块和一个 [omnibeam_box] 短代码。工作原理。

23. Telegram

在设置中点按关联 Telegram，然后在与 OmniBeam 机器人的聊天中点按“开始”。你发给机器人的文件、照片、视频、语音消息和文字会到达这台设备，⋯ 菜单中的发送到 Telegram可以把文件和文字发到那个聊天。Telegram 允许机器人接收最大 20 MB、发送最大 50 MB 的文件。经过 Telegram 的文件不是端到端加密的，因为 Telegram 能看到它们。

24. 与设备聊天

在设备的更多…窗口中选择聊天，或在链接窗口中已配对设备旁边选择聊天。你会看到过去 7 天发给这台设备和从它收到的所有内容，包括消息和文件，像聊天软件一样按时间排列：收到的在一边，发出的在另一边。收到的照片会显示小图，每个收到的文件都有保存(可以预览的还有预览)。在底部的输入框中输入即可发送消息，点按回形针可以发送文件。离线的已配对设备一打开 OmniBeam 就会收到。有新内容到达时，设备卡片上会出现一个小数字：点按它即可打开聊天。聊天由这台设备上的历史记录生成；不会额外保存任何内容，也不会发到我们的服务器。每个 发送消息 都会打开这个聊天：这是书写和阅读消息的唯一地方。收到消息时，对应的聊天会伴随一声简短的提示音（手机上还会振动）自动打开；如果你正忙于其他操作，则改为显示横幅，聊天不在屏幕上时还会收到通知。顶部的扬声器按钮可关闭提示音（也可在设置的消息提示音中关闭）。垃圾桶按钮只在这台设备上清空与该设备的聊天，几秒内可以撤销。

25. 扫描为 PDF

  1. 在设备的更多…窗口中选择扫描为 PDF。相机会在 OmniBeam 中打开(或点按使用相机应用)。
  2. 在光线充足的地方把页面放平，让四个角都在画面里，然后点按拍摄页面。需要几页就拍几页，然后点按完成。
  3. OmniBeam 会找到每一页的边缘并把它摆正。如果某页裁切不对，点按它，把四个角拖到页面的四个角上。
  4. 选择彩色或黑白(白底上清晰的黑字，适合文件和收据)，把页面往前或往后移，或删除某一页。
  5. 点按发送到 …。PDF 在你的手机上生成，生成时不会上传任何东西，然后像其他文件一样发送。你也可以通过链接分享或保存 PDF。

26. 支持者福利

OmniBeam 是免费的，没有广告，也没有任何功能被锁住。如果你用 ♥ 按钮捐款，作为感谢可以获得一个支持者代码。在设置的支持者下输入它，然后点按解锁：其他设备就会在你设备的卡片上看到一个 ♥，你还会获得四种额外的颜色主题(海洋、森林、日落和玫瑰)，以及在更改名称和图片中为设备选择的更多图片。这个代码在你所有的设备上都能用，离线时也能继续使用。

27. 活动相册

在顶部的 ⋯ 菜单中点按 活动相册。给它起个名字（例如“Sara 和 Omar 的婚礼”），选择开放时间（1、3、7 或 30 天）和照片大小，然后点按 创建相册。你会得到一个链接和二维码：可以展示、发送，或点按 打印海报 摆在桌上。来宾用手机相机扫码，上传照片和视频，并能看到所有人的照片，无需应用、账号或配对。照片在来宾手机上加密，密钥位于链接中 # 之后的部分，这部分永远不会到达我们的服务器。

点按 打开相册（也在“你的相册”中）即可查看所有照片、全部保存、删除任意照片或停止接收新照片。相册停止接收照片时，来宾会立刻看到，仍可查看和保存相册里的照片。你删除的照片，或上传它的来宾自己删除的照片，几秒内就会从所有打开的相册页面消失。相册到期后会从服务器删除。

28. 共享文件夹并在手机上浏览

在电脑上点按 ⋯ 菜单中的 共享文件夹，选择一个文件夹，并在 谁可以查看 中勾选你已配对的手机。在手机上点按这台电脑，再点 更多… 和 浏览文件：你会看到电脑上的文件夹和文件，可以搜索，并取走一个或多个文件。文件直接从电脑加密传来，不会上传任何内容。需要时请让电脑上的标签页保持打开。隐藏文件不会显示。

29. 发送到我的所有设备

当屏幕上有两台或更多你的设备时，会出现 发送到我的所有设备 按钮。点按它，取消勾选不想发送的设备，即可把文件或消息一次发给所有设备。也可以把文件直接拖到按钮上。离线（灰色）的已配对设备会在打开 OmniBeam 后立即收到，所以请保持此页面打开。

30. 让设备响铃来找到它

手机在家里找不到了？在另一台设备上，在它的 更多… 窗口或聊天顶部选择 让此设备响铃。手机会大声响铃（并振动），直到有人点按 停止。如果它的 OmniBeam 已关闭但开启了通知，它会收到通知并在打开时响铃；否则，只要它在接下来 2 分钟内打开 OmniBeam 就会响铃。

31. 链接、置顶便签和邀请卡

  • 打开链接：从其他设备发来的链接会显示 打开链接，点一下即可打开。在设置的 链接 中，可以让已配对设备发来的链接自动打开（浏览器可能会要求允许弹出窗口）。
  • 置顶便签：在聊天中点按置顶按钮（置顶便签），把便签固定在顶部，例如 Wi‑Fi 密码或地址。即使清空聊天，它也会留在这台设备上，直到你取消置顶。
  • 邀请朋友：在 ⋯ 菜单中点按 邀请朋友，生成一张带有可打开 OmniBeam 的二维码图片，方形或快拍尺寸。分享到聊天或快拍，或点按 保存图片。

32. 应用锁和记录保留时间

  • 应用锁：在设置的 隐私 中开启 应用锁，并设置 4 到 8 位数字的 PIN。之后 OmniBeam 打开前会先要求输入，这样在你之后使用这台设备的人看不到你的历史记录、聊天和设备。你还可以用指纹、面容或 Windows Hello 解锁，选择何时再次锁定，或点按 ⋯ 菜单中的 立即锁定。锁定期间文件照常接收，通知会隐藏内容。如果忘记 PIN，忘记 PIN？ 会解除锁定，同时删除这台设备上的历史记录、聊天和记住的设备。
  • 记录保留时间：选择收到的文件和消息、“已发送”列表和剪贴板历史在这台设备上保留多久：1 小时、1 天、7 天（默认）或 30 天。更早的内容会自动删除。置顶便签会保留。

33. 换到新手机

在设置的 设备 中点按 保存备份文件，并为文件设置 PIN 或密码。文件包含你的已配对设备、设置、置顶便签和聊天，并用这个密码加密。收到的文件不在其中。把它发到新手机（直接用 OmniBeam 发送），在新手机上打开 OmniBeam，点按 打开备份文件 并输入密码。一切都会恢复，新手机也会立刻认出你的其他设备。

34. 通知中的按钮

开启通知后，消息通知有 回复，文件通知有 保存，响铃设备的通知有 停止。如果浏览器支持在通知中输入，回复会直接发出；否则，点按“回复”会打开聊天并准备好输入。开启应用锁时，通知只能用来打开 OmniBeam 或停止响铃。

35. 快速缩小视频

在设置的 发送时的照片大小 中，也可以缩小视频：缩到 720p，或选“最小”缩到 480p。Chrome、Edge 和 Safari 能在你的设备上几秒内缩小一分钟的视频；在其他浏览器中，所需时间大约等于视频的播放时长。你设备上的原视频不会改变。

36. 文字大小、对比度和液态玻璃

在设置的 设备 中：文字大小 可把所有文字调为“大”或“最大”；对比度 设为“高”会使用边缘清晰的纯色（“自动”会跟随设备设置）；风格 可在“经典”和 液态玻璃 之间切换，后者是通透的玻璃质感外观，浅色和深色模式都可用。OmniBeam 也支持屏幕阅读器、键盘操作和 Windows 高对比度模式。

37. 自动发送文件夹、剪贴板历史和 Firefox

  • 自动发送文件夹：在装有 Chrome 或 Edge 的电脑上，或在 Windows 应用中，在设置的 自动发送文件夹 中选择一个文件夹和要发送到的设备。只要 OmniBeam 开着，放进该文件夹的新文件就会自动发到那台设备。在手机上为这台电脑开启自动接受，文件就能无需点按直接收到。
  • 剪贴板历史：开启剪贴板同步后，勾选 在历史记录中保留最近 20 条，以后就能再次复制之前的文本。
  • Firefox：除了 Chrome 网上应用店版本，OmniBeam 扩展也已上架 Firefox 附加组件。

38. 在两台电脑之间同步文件夹

在两台装有 Chrome 或 Edge 的电脑上，点按 ⋯ 菜单中的同步文件夹，选择一个文件夹，在同步对象下选择另一台电脑，然后点按开始同步。在另一台电脑上也这样做，并选择这台电脑。只要两台电脑上都开着 OmniBeam，新的和改动过的文件（包括子文件夹）就会自动复制过去，直接从一台电脑到另一台，并且是加密的。在一台电脑上删除的文件会留在另一台上；如果两台电脑都改动了同一个文件，两个版本都会保留。隐藏文件和临时文件不会同步。

故障排除

  • 设备没有出现：检查两台设备是否在同一 Wi‑Fi 下且没有使用 VPN，或用代码配对它们。
  • 同一 Wi‑Fi 下路线显示“正在通过服务器发送”或“互联网”：请看如何解决同一 Wi‑Fi 下传输慢的问题。传输仍然可以进行，只是慢一些，而且仍然端到端加密。
  • 屏幕关闭时传输停止：手机在屏幕锁定或切换应用时会暂停网页。传输完成前请保持 OmniBeam 打开、屏幕亮着；OmniBeam 会请求手机保持唤醒，并在卡片上显示提醒。如果屏幕还是熄灭了，再次打开 OmniBeam，传输会自动从停止处继续。
