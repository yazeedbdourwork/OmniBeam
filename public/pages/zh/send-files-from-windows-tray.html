Windows 版 OmniBeam：从 Microsoft Store 获取免费应用

OmniBeam 已上架 Microsoft Store。这个应用在自己的窗口中打开 OmniBeam，可以从开始菜单或任务栏启动，并会出现在 Windows 共享菜单中，所以无需先打开浏览器就能把文件发到 iPhone 或 Android 手机。

从 Microsoft Store 获取 OmniBeam

安装

  1. 打开 Microsoft Store 中的 OmniBeam 页面，点击获取。免费，无需账号，也没有广告。
  2. 从开始菜单打开 OmniBeam。要让它随时一键可用，在任务栏上右键单击它的图标，选择固定到任务栏。

适用于 Windows 10 和 11。每当 OmniBeam 变得更好，应用都会自动更新，所以不用重新下载。

把手机配对一次

  1. 在手机上打开 omnibeam.site。在同一 Wi‑Fi 下，电脑会自动出现。
  2. 在不同网络中，点击电脑上应用里的链接按钮，用手机相机扫描它的二维码，或输入 6 位数代码。
  3. 在手机上打开配对界面，勾选电脑旁边的受信任，这样它发来的文件无需询问就会到达。

从电脑发送

  • 在应用中点击手机并选择文件，或从文件资源管理器把文件拖到它上面。
  • 在文件资源管理器中选中文件，右键单击，选择共享，然后选择 OmniBeam。
  • 要发送链接或便条，指向手机并选择发送消息。在设置中开启剪贴板同步后，你在电脑上复制的文字会发到手机上。

从 Chrome 或 Edge 发送：OmniBeam 扩展程序

这个扩展程序可以通过右键把你正在看的页面、链接、图片或选中的文字发到手机。从 Chrome 应用商店添加；它在 Microsoft Edge 中也能用。

更喜欢托盘图标和“发送到”菜单？

如果你想在时钟旁边有个图标，并在右键发送到菜单中看到 OmniBeam，旧版托盘应用仍然可用。它需要 Node.js 22 或更新版本：下载托盘应用(ZIP)，解压到一个你会保留的文件夹，然后双击 install-tray.cmd。对大多数人来说，Microsoft Store 应用更简单。

只要网络允许，文件就会在你的设备之间直接传输，并且始终端到端加密。

问题与解答

应用和网站有什么区别？

它们做的事情一样。Microsoft Store 应用随 Windows 启动并随时待命，所以手机随时都能发到电脑，无需先打开浏览器。网站无需安装任何东西即可使用。

应用会自动更新吗？

会。Microsoft Store 会自动让它保持最新，所以你用的总是最新版本。

能从文件资源管理器发送文件吗？

使用旧版托盘应用可以：它会把 OmniBeam 加到右键“发送到”菜单中，你选中文件，选择“发送到”，再选 OmniBeam 即可。在 Microsoft Store 应用中，把文件拖到窗口上或使用文件选择器。

可以卸载应用吗？

可以。像其他应用一样，从 Windows 设置或开始菜单卸载即可。如果你回到网站，设备在浏览器中仍保持配对。
