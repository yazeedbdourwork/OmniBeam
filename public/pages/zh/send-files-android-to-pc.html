如何不用 USB 数据线把文件从 Android 传到电脑

USB 数据线、驱动程序和“文件传输”模式都很麻烦。用 OmniBeam，你可以直接在 Chrome 中，通过 Wi‑Fi 把文件从任何 Android 手机发到 Windows 电脑、Mac 或 Chromebook。

步骤

  1. 在电脑上和手机的 Chrome 中打开 omnibeam.site。
  2. 稍等片刻，直到两边都显示对方。没出现？用配对代码：在电脑上点击链接按钮，创建代码，然后在手机上输入。
  3. 在手机上点按电脑，选择照片、视频或任何文件。
  4. 在电脑上接受并保存。多个文件可以一起保存为一个 ZIP。

更快的方法：Android 分享菜单

把 OmniBeam 添加到主屏幕(Chrome 菜单，然后选添加到主屏幕或安装应用)。之后，OmniBeam 会出现在图库、文件和大多数其他应用的分享菜单中：选中照片，点按分享，选择 OmniBeam，再选电脑。

大视频小贴士

  • 传输完成前，请保持手机屏幕亮着、页面打开。
  • 连接较慢时，在设置(顶部的 ⋯ 菜单中)选择缩小照片和视频：发送前照片会缩放到 2048 像素，视频会重新编码为 720p。
  • 同一 Wi‑Fi 下传输最快。如果进度卡片显示路线是“互联网”或“服务器”，请看如何解决同一 Wi‑Fi 下传输慢的问题。
  • 如果你经常从 Android 手机发送，安装免费的 Windows 版 OmniBeam 应用，有文件发来时从开始菜单打开它即可。

当手机和电脑在不同网络中时也能用，比如手机用移动数据：用代码配对后，文件会通过加密连接传输。不会先上传到云端文件夹，所以大视频马上就开始到达。

OmniBeam 无需 USB 数据线，通过 Wi‑Fi 或移动数据把文件从 Android 发到电脑。

问题与解答

需要在电脑上安装什么吗？

不需要。在电脑上的任意浏览器中打开 omnibeam.site 即可。如果你经常发送文件，Microsoft Store 中免费的 OmniBeam 应用会在后台随时待命。

能直接从 Android 图库分享吗？

能。从浏览器菜单把 OmniBeam 安装为应用，它就会出现在 Android 分享菜单中，你可以直接从图库发送照片。

如果电脑用有线网络、手机用 Wi‑Fi 呢？

只要两者在同一个家庭网络中就没问题。如果在不同网络中，就用代码配对一次。

比 USB 数据线快吗？

在良好的 Wi‑Fi 网络中差不多，发几张照片还更快，因为你不用找数据线，也不用打开手机的文件传输模式。

在 Windows 上文件保存到哪里？

保存到“下载”文件夹，或浏览器保存下载内容的位置。多个文件可以一起保存为一个 ZIP。

电脑能把文件发回手机吗？

能。在电脑上的 OmniBeam 中点击手机，选择文件，然后在手机上接受。使用旧版 OmniBeam 托盘应用时，也可以在文件资源管理器中右键单击文件发送到手机。
