如何不用 U 盘在两台电脑之间传输文件

拷到 U 盘、发邮件给自己或上传到云端，花的时间都是应有的两倍。OmniBeam 把文件从一台电脑直接发到另一台，Windows、Mac、Linux 或 Chromebook 任意组合都行。

步骤

  1. 在两台电脑的浏览器中打开 omnibeam.site。
  2. 在同一网络中它们会自动出现。否则在一台上点击配对按钮，在另一台上输入 6 位数代码。
  3. 把文件或整个文件夹拖到另一台电脑的卡片上，或点击它选择文件。
  4. 在另一台电脑上接受。文件夹保留原有结构，可以保存为一个 ZIP。

为什么快

  • 文件通过你的网络直接在两台电脑之间传输，不经过云服务器。
  • 没有大小限制，连接中断时大文件传输也会自动继续。
  • 全程端到端加密，任何地方都不保存。

经常这样传？

在 Windows 上，安装 Microsoft Store 版 OmniBeam 应用，就能在它自己的窗口或 Windows 共享菜单中发送(如何使用)；再添加 Chrome 扩展程序，一键发送你正在看的页面或链接。

因为只需要一个现代浏览器，所以 Windows、Mac、Linux 和 Chromebook 任意组合都能用。在同一网络中电脑会自动找到彼此；在不同地方，就用配对代码。

你可以不用 U 盘、数据线或云账号，在两台电脑之间传输文件。

问题与解答

Windows 和 Mac 之间能用吗？

能。OmniBeam 在两者的浏览器中都能运行，所以你可以从 Windows 电脑发到 Mac，从 Mac 发到 Chromebook，或在任意两台电脑之间发送。

能传整个文件夹吗？

能。在 OmniBeam 中把文件夹拖到另一台电脑上。接收端可以把文件一起保存为一个 ZIP，保留文件夹结构。

非常大的文件呢？

直接传输没有大小限制，连接中断后会从停止处继续。如果是整个硬盘，外接硬盘仍然更快。

两台电脑需要在同一网络中吗？

不需要。在同一网络中会自动出现；否则用代码配对一次，之后它们就能找到彼此。

在共享或公共网络中安全吗？

安全。每次传输都在发送端电脑上端到端加密，只在接收端解密，所以同一网络中的其他人无法读取文件。

也能在电脑之间复制文字或链接吗？

能。把文字粘贴到 OmniBeam 中发送，或开启剪贴板同步，在一台电脑上复制的文字一键就能发到另一台。

两台电脑都需要账号吗？

不需要。没有账号、无需注册，也不用安装。在两台电脑上打开页面就能开始发送。
