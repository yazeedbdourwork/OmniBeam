OmniBeam 常见问题

OmniBeam 是一个免费网站，可以在任意两台设备之间发送文件、照片、视频和文字，比如 iPhone 和 Windows 电脑。在两台设备上打开 omnibeam.site 就能发送。无需安装应用，无需账号，每次传输都经过端到端加密。

基本问题

OmniBeam 是什么？

OmniBeam 让你直接在浏览器里在自己的设备之间发送文件，类似 AirDrop，但适用于所有品牌。它支持 iPhone、iPad、Android、Windows、Mac、Linux 和 Chromebook，可在 Safari、Chrome、Edge、Firefox 等现代浏览器中使用。

OmniBeam 免费吗？

免费。发送文件、链接、聊天和其他所有功能都免费，无需账号，也没有广告。想支持项目的人可以捐款，获得带额外主题的支持者徽章，但没有任何功能因此被锁住。

需要安装应用吗？

不需要。OmniBeam 在网页浏览器中运行。你也可以把它添加到手机主屏幕、在 Windows 上从 Microsoft Store 安装，或添加 Chrome、Edge、Firefox 扩展，但只用网站就能完成所有操作。

需要注册账号吗？

不需要。没有注册、邮箱或密码。每台设备只会有一个名字，你可以随时修改。

怎样发送文件？

在两台设备上打开 omnibeam.site。在同一 Wi‑Fi 下，它们很快就会互相出现。点按另一台设备，选择文件，然后在另一台设备上接受。文件会直接传过去。

网络和设备

两台设备必须连同一个 Wi‑Fi 吗？

不必。在同一 Wi‑Fi 下它们会自动找到对方。在不同网络下，比如手机用移动数据，只需用 6 位数字码或扫描二维码配对一次。之后配对过的设备无论在哪里都能找到彼此。

可以从 iPhone 发到 Windows 或 Android 吗？

可以。OmniBeam 正是为此而做：iPhone 到电脑、Android 到 iPhone、Android 到 Mac、Mac 到 Windows，以及任何其他组合。每台设备上的步骤都一样。

没有网络也能用吗？

设备需要连接 omnibeam.site 才能找到对方。在同一 Wi‑Fi 下，文件本身随后会直接通过你的局域网传输。

隐私和安全

OmniBeam 安全吗？

安全。每次传输都在发送设备上进行端到端加密，只有接收设备能解密。只要可能，文件都直接在设备之间传输。无法直连时，加密数据会经过一个无法读取内容的中继服务器。实时传输的内容不会被保存，而且每个文件都必须在接收设备上接受。

OmniBeam 会保存我的文件吗？

不会。实时传输从不保存在服务器上。只有你通过链接分享的文件，或别人通过文件请求发来的文件，才会加密存储，并在链接过期时删除。

OmniBeam 开源吗？

开源。源代码以 GPL-3.0 许可证发布在 GitHub 上，任何人都可以查看它的工作方式。

文件和限制

有文件大小限制吗？

直接发送没有：OmniBeam 不设上限，在 Chrome、Edge 和 Firefox 中大文件会直接写入磁盘。分享链接有大小上限，会在应用中显示，因为这些文件要保存到链接过期为止。

照片和视频是原画质发送吗？

是的，默认发送原始文件。想节省时间或空间时，可以选择“更小的照片”或“更小的视频”；iPhone 的 HEIC 照片也可以保存为 JPG。

连接断了怎么办？

传输会从中断的地方继续，而不是从头开始：直连恢复后走直连，否则走加密中继。

可以发给现在不在线的人吗？

可以。用加密链接分享文件，默认有效 7 天，最长 30 天。你可以加上 PIN 码，也可以让 OmniBeam 通过邮件发送链接。

与其他工具对比

和 AirDrop 有什么不同？

AirDrop 只能在彼此靠近的苹果设备之间使用。OmniBeam 在浏览器中运行，支持所有品牌，也能跨不同网络使用。详见 OmniBeam 与 AirDrop 对比。

和 WeTransfer 有什么不同？

WeTransfer 会先把文件上传到它的服务器。OmniBeam 则直接从设备发到设备，不限大小，也能生成加密链接。详见 OmniBeam 与 WeTransfer 对比。

和 Snapdrop、PairDrop、LocalSend 有什么不同？

它们都能在局域网内发送文件。OmniBeam 还提供跨网络配对、加密链接、断线续传、聊天，以及 Windows 和浏览器应用。对比页面逐项说明。
