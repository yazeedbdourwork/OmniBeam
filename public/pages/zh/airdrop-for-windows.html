Windows 和 Android 上的隔空投送：浏览器替代方案

隔空投送只在 Apple 设备之间工作。OmniBeam 在网页浏览器中运行，所以在任何设备之间都能实现同样“点一下就发送”的体验。

你能得到什么

  • 同一 Wi‑Fi 下的设备会像隔空投送一样自动找到彼此。
  • 可在 iPhone、iPad、Mac、Windows、Android、Linux 和 Chromebook 之间使用。
  • 文件直接从设备发到设备，并且端到端加密。
  • 直接传输没有大小限制，无需账号，也不用安装任何东西。
  • 不同网络中的设备可以用 6 位数代码配对一次。

隔空投送与 OmniBeam 对比

  • 设备：隔空投送仅限 Apple；OmniBeam 在任何装有现代浏览器的设备上都能用。
  • 距离：隔空投送需要设备在附近；OmniBeam 也能跨互联网使用。
  • 与他人分享：OmniBeam 还能生成任何人之后都能打开的加密链接。

详见 OmniBeam 与隔空投送对比。

让它用起来像应用

从浏览器安装 OmniBeam(在 Chrome 或 Edge 中选“安装”，在 iPhone 上选“添加到主屏幕”)。在 Windows 上，获取免费的 Microsoft Store 版 OmniBeam 应用；请看 Windows 版 OmniBeam。

与隔空投送不同，OmniBeam 不需要蓝牙，也不需要 Apple 账户。两台设备只需要一个浏览器，每次传输都端到端加密，所以即使经过中转服务器，文件也保持私密。

OmniBeam 是在浏览器中运行的、适用于 Windows 和 Android 的免费隔空投送替代品。

问题与解答

有官方的 Windows 或 Android 版隔空投送吗？

没有。隔空投送只内置在 Apple 设备中，Apple 没有为 Windows 或 Android 推出它。要在 iPhone 和电脑或 Android 手机之间同样快速地分享，你需要一个两边都能用的工具，比如浏览器中的 OmniBeam。

OmniBeam 和隔空投送有多接近？

日常使用中非常接近：同一 Wi‑Fi 下的设备会自动出现，你点按一台并选择文件，另一台设备接受即可。区别在于 OmniBeam 在浏览器标签页中运行，而不是系统菜单中，而且配对一次后在不同网络之间也能用。

能发给没有打开浏览器的 Windows 电脑吗？

接收设备上必须打开页面，就像隔空投送需要接收方处于唤醒且可见状态一样。在 Windows 上，Microsoft Store 中免费的 OmniBeam 应用让这更简单：它随电脑启动，所以无需先打开浏览器文件就能到达。

iPhone 照片也能用吗？

能。照片和视频以原画质到达，iPhone 的 HEIC 照片可以保存为 JPG，在任何 Windows 电脑或 Android 手机上都能打开。

安全吗？

每次传输都在你的设备上端到端加密，途中不会在任何服务器上保存内容。

可以多台设备同时接收吗？

可以。用“发送给所有人”把同样的文件发到所有打开的设备，或者加入一个公开房间，让一组手机和电脑互相分享。这在教室或会议中很方便，因为在那里隔空投送只能发到房间里的 Apple 设备。

离线能用吗？

设备需要互联网连接才能找到彼此，不过文件本身会尽可能直接通过你的 Wi‑Fi 传输。
