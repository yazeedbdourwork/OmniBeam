适用于网站或博客的“给我发送文件”框

让访客、客户或学生直接从你的页面给你发送文件。你只需粘贴一段短代码；文件在他们的设备上加密，然后到达你设备上的 OmniBeam。

步骤

  1. 在要接收文件的设备上打开 omnibeam.site，点按 ⋯ 菜单中的请求文件。
  2. 写下你需要什么(可选)，在“链接有效期”中选择 1 年(用于网站)，然后点按创建请求链接。
  3. 点按放到你的网站上，再点按复制代码。
  4. 把代码粘贴到你的页面中：WordPress 中用自定义 HTML 区块，Blogger 中用 HTML/JavaScript 小工具，Wix 中用 Embed HTML 元素，Squarespace 中用 Code 区块。

访客会看到一个小框，里面有“选择文件”、一个可选的姓名栏和一个发送按钮。他们不需要应用，也不需要账号。文件会到达你设备上的“收到的文件”；如果那边的 OmniBeam 是关着的，文件会在服务器上等待，等你打开时到达，如果你开启了通知，还会收到通知。

WordPress：免费的 OmniBeam 插件

在 WordPress 上有更简单的方法：下载 OmniBeam 插件(omnibeam-wordpress.zip)，然后在 WordPress 中进入插件 → 安装插件 → 上传插件，选择 zip 文件并点按启用。把你的代码(或只是它的链接)粘贴到设置 → OmniBeam Box 中，然后在任意页面添加区块 OmniBeam: Send me files，或短代码 [omnibeam_box]。使用自己的链接和高度的框：[omnibeam_box url="https://omnibeam.site/embed/r/…" height="520"]。插件只接受来自 omnibeam.site 的框，文件也从不经过你的 WordPress 网站。

代码的样子

<iframe src="https://omnibeam.site/embed/r/…?lang=zh#…" title="给我发送文件" style="width:100%;max-width:520px;height:470px;border:0" loading="lazy"></iframe>
<p><a href="https://omnibeam.site/zh/">由 OmniBeam 提供支持</a> · 免费、端到端加密的文件分享</p>

请保留“由 OmniBeam 提供支持”这一行：这个框正是靠它保持免费的。

它私密、安全吗？

  • 每次上传都在访客的浏览器中加密。它的密钥用你设备的公钥封存，只有你的设备持有对应的私钥，所以无论是 OmniBeam 还是任何读到你页面代码的人，都打不开这些文件。
  • 你页面上的代码是公开的。任何看到它的人都能给你发送文件，也能读到“你需要什么”的文字和你设备的名称，所以不要在那里写任何私人内容。
  • 只有你的设备能下载这些上传，每个上传在你的设备拿到后会立即从服务器删除。无人领取的文件会在 7 天后删除。
  • 常规限制仍然有效：每次上传有大小限制，每个网络每小时有次数限制，每个框每天最多 100 次上传。
  • 随时在同一个窗口中删除请求链接，这个框就会立即停止工作。

问题与解答

要花钱吗？

不要。这个框是免费的，无需账号，没有广告。WordPress 插件也是免费的。

可以在好几个页面上用吗？

可以。在你喜欢的每个页面上粘贴同样的代码；所有上传都会到达同一台设备。如果你想区分它们，就另建一个请求链接。

为什么这个框过一段时间就不能用了？

每个请求链接都会在你选择的时间结束。网站请选择 1 年，并在到期前创建新的链接和代码。

有人能用我的框给我发垃圾内容吗？

和电子邮件地址一样，任何访问页面的人都能给你发送文件。文件从不会自己打开，上传按网络和按天受到限制，你也可以删除链接来关闭这个框。
