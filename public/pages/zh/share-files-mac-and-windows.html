如何不用 U 盘在 Mac 和 Windows 电脑之间共享文件

macOS 和 Windows 之间的网络共享意味着 SMB 设置、用户名和防火墙。用 U 盘则要在房间里来回走。OmniBeam 在浏览器中点几下，就能在 Mac 和 Windows 电脑之间传文件。

步骤

  1. 在 Mac 上用 Safari 或 Chrome、在电脑上用 Edge 或 Chrome 打开 omnibeam.site。
  2. 在同一网络中，两台电脑会互相显示。如果没有，用链接按钮中的代码配对一次。
  3. 把文件或整个文件夹拖到另一台电脑上，或点击它来选择文件。
  4. 在另一台电脑上接受。多个文件可以保存为一个 ZIP，文件夹会保留原有结构。

无需文件共享设置

Mac 和 Windows 之间的传统文件共享需要相同的工作组、另一台电脑上的账户以及正确的防火墙规则。OmniBeam 只需要两台电脑各有一个浏览器。两台电脑之间的连接是直接且加密的，所以在共享的办公网络中也更安全。

更快捷的用法

  • 在 Windows 上，从 Microsoft Store 安装免费的 OmniBeam 应用，从“开始”菜单打开。
  • 把两台电脑配对并开启“自动接受”，这样你自己 Mac 发来的文件无需点击就会到达电脑。
  • 在设置中开启剪贴板同步，在一台电脑上复制文字，在另一台上粘贴。
  • 在电脑上使用“自动发送文件夹”，让文件夹里的每个新文件(比如截图)自动发出。

它适用于任何电脑组合：MacBook 和 Windows 笔记本、iMac 和游戏电脑，或者配对后处于不同网络的工作笔记本和家里的电脑。

用 OmniBeam，你无需 U 盘、云文件夹或网络设置，就能通过 Wi‑Fi 在 Mac 和 Windows 之间共享文件。

问题与解答

大视频文件也可以吗？

可以。直接发送没有大小限制，1 GB 及以上的文件会在到达时逐块校验。

可以发送整个文件夹吗？

可以。把文件夹拖到另一台电脑上。它会连同子文件夹一起到达，你可以保存为一个 ZIP。

两台电脑需要在同一网络中吗？

配对一次后就不需要了。已配对的电脑在任何网络中都能找到彼此，比如家里的笔记本和办公室的电脑。

比 iCloud 云盘或 OneDrive 快吗？

对于一次性传输，通常更快，因为文件直接在电脑之间传输，而不是先上传到云端再下载。

Linux 也能用吗？

能。任何装有现代浏览器的电脑都能加入，包括 Linux 和 Chromebook。

收到的文件保存在哪里？

保存在每台电脑上浏览器的下载文件夹。在 Mac 上是访达中的“下载”文件夹，在 Windows 上是文件资源管理器中的“下载”文件夹。

在办公网络中连接安全吗？

安全。两台电脑使用加密连接，只有你配对的设备或同一网络中的设备才能互相看到。
