同样适用于 iPhone 和 Mac 的快速分享替代方案

快速分享(Quick Share，原名 Nearby Share)在 Android 手机和部分 Windows 电脑之间很方便，但它够不着 iPhone、Mac 或旧笔记本。OmniBeam 在任何网页浏览器中都能做同样的事，让你所有的设备都能互相发送文件。

如何用它代替快速分享

  1. 在两台设备上打开 omnibeam.site，比如一部 Android 手机和一台 MacBook。
  2. 在同一 Wi‑Fi 下它们会自动出现。否则用链接按钮中的二维码配对一次。
  3. 点按或点击另一台设备并选择文件，在电脑上也可以把文件拖上去。
  4. 在另一台设备上接受并保存。已配对的设备也可以自动接收。

OmniBeam 能做而快速分享做不到的事

快速分享需要蓝牙、Android 手机或受支持的 Windows 电脑，以及相同的账号或联系人设置。OmniBeam 这些都不需要：它在 iPhone、iPad、Mac、Linux 和 Chromebook 上也能用，两台设备配对后还能跨网络使用。它还能通过链接和远方的人分享文件。

值得了解

  • 文件直接在两台设备之间传输，途中经过加密。
  • 直接发送没有大小限制，照片保持原画质。
  • 在 Windows 上，免费的 Microsoft Store 版 OmniBeam 应用会在后台待命，就像 Windows 版的快速分享。
  • 剪贴板同步和自动发送文件夹(在设置中)会自动在你的设备之间传送文字和新文件。

很多家庭里 Android 手机、iPhone 和笔记本混在一起。有一个在哪里都能用的网站，就没人需要问对方装了什么应用，或者蓝牙开没开。

如果你在找一个同样适用于 iPhone 和 Mac 的快速分享或 Nearby Share 替代方案，OmniBeam 免费，并且在你已经在用的浏览器中就能用。

问题与解答

OmniBeam 使用蓝牙吗？

不使用。它使用你的 Wi‑Fi 或网络连接，比蓝牙快得多，距离也更远。

Android 手机能用它发到 iPhone 吗？

能。这恰恰是快速分享做不到的。在两部手机上打开 OmniBeam 发送即可。

两台设备都需要 Google 账号吗？

不需要。根本没有账号。设备在同一网络中或配对一次后就能找到彼此。

和快速分享一样快吗？

在同一 Wi‑Fi 下通常一样快甚至更快，因为文件以 Wi‑Fi 速度直接在你的网络中传输。

旧的 Windows 笔记本能用吗？

能。任何装有 Chrome、Edge 或 Firefox 等现代浏览器的笔记本都行，包括 Windows 10 和较旧的 Mac。

可以同时发给几台设备吗？

可以。用 ⋯ 菜单中的“发送给所有人”，相同的文件会发到你网络中所有打开的设备，这是快速分享做不到的。

私密吗？

私密。文件加密后直接从一台设备发到另一台，直接发送时服务器上不会保存任何内容。
