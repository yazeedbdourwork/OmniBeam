适用于 Windows 和 Android 的最佳隔空投送替代品

隔空投送很好用，直到涉及 Windows 电脑或 Android 手机。下面是在你所有设备之间发送文件的主要方法，以及各自适合的场景。

1. 基于浏览器的分享(OmniBeam、PairDrop、Snapdrop)

在两台设备上打开同一个网站，它们就会找到彼此，很像隔空投送。无需安装，可在 iPhone、Android、Windows、Mac 和 Linux 上使用，网络允许时文件会在设备之间直接传输。

OmniBeam 还增加了用于不同网络的配对代码、直接路径失败时的端到端加密、连接断开后的续传、给不在线的人用的链接、Microsoft Store 中的 Windows 应用以及 Chrome 扩展程序。

2. Quick Share(Android 和 Windows)

Google 的 Quick Share 通过蓝牙和 Wi‑Fi，在 Android 手机和 Windows 电脑之间工作得很好。它不支持 iPhone，电脑上需要安装 Quick Share 应用。

3. LocalSend

一款适用于所有平台的免费开源应用，通过局域网发送文件。非常快，但每台设备都要安装，而且只有两台都在同一网络中时才能用。

4. 云端链接(Google 云端硬盘、OneDrive、WeTransfer)

先上传，再分享链接。适合发给远方的人或保留一份副本，但每个文件都要上传到互联网再下载下来，大视频会很慢，而且文件放在别人的服务器上。

5. 聊天应用

发一两张照片很快，但大多数聊天应用会压缩照片和视频。请看如何保持原画质。

该选哪个

  • 各种设备混用，不想安装任何东西：浏览器应用，比如 OmniBeam。
  • 只有 Android 和 Windows：Quick Share。
  • 每天在同一网络中传很多大文件：LocalSend，或在同一 Wi‑Fi 下用浏览器中的 OmniBeam。
  • 对方现在不在线：用链接。OmniBeam 的链接在你的设备上加密，并会自动过期。

详细对比请看比较 OmniBeam。

简而言之，适用于 Windows 和 Android 的最佳隔空投送替代品是那些能在浏览器中使用的工具，OmniBeam 就是其中之一。

问题与解答

好的隔空投送替代品应该做到什么？

它应该能在你拥有的任意两台设备之间使用，而不仅仅是 Apple 设备之间，并且能快速开始。最好的选择还会用端到端加密保护文件隐私，发送照片和视频时不缩小，并且在两台设备不在同一 Wi‑Fi 下时也能使用。

需要安装什么吗？

用 OmniBeam 不需要：它在浏览器中运行，所以在不能安装应用的工作笔记本或朋友的电脑上也能用。其他一些替代品需要在每台设备上安装应用，在家里还好，但只想发一个文件时就比较慢。

哪个替代品最快？

在同一 Wi‑Fi 下，能直接连接两台设备的工具最快，因为不需要先上传。OmniBeam 能直连时就直接发送，只有在直接连接被阻止时才改用加密中转。

可以同时用好几个吗？

可以。很多人在 Apple 设备之间保留隔空投送，其他情况都用 OmniBeam，比如 iPhone 到 Windows 或 Android 到 Mac。

发到别人的手机呢？

也可以。请对方打开 omnibeam.site，或创建一个公开房间，你们用同一个短代码加入。如果对方现在不在线，就发一个之后可以打开的加密链接。
