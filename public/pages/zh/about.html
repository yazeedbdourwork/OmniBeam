关于 OmniBeam，一个免费的文件发送工具

OmniBeam 是一个免费、无需安装的工具，用于在你的设备之间发送文件和文字，无论远近。

把照片从手机移到笔记本电脑，不应该需要数据线、账号或应用。OmniBeam 在你已有的浏览器中运行：在两台设备上打开网站就能发送。它可以在 iPhone、Android、Windows、Mac 和 Linux 之间使用，支持英语、阿拉伯语、法语、西班牙语、土耳其语、德语、葡萄牙语、印地语、印度尼西亚语、俄语、日语、中文、韩语、意大利语和乌尔都语。

工作原理

OmniBeam 使用 WebRTC(与浏览器视频通话相同的技术)直接连接你的设备，并对数据进行端到端加密。OmniBeam 的服务器只负责让设备互相认识。当无法直接连接时，服务器会中转传输，仍然是端到端加密，并且不保存任何内容。

要把文件发给不能同时在线的人，你也可以通过链接分享：文件在上传前就在你的浏览器中加密，密钥只存在于你分享的链接里。

问题与解答

为什么要做 OmniBeam？

在自己的手机和电脑之间移动一张照片或一份文档，本该只需几秒钟，但往往要用数据线、给自己发邮件或上传到云端。做 OmniBeam 就是为了省掉这些步骤：在两台设备上打开同一个页面就能发送。它还必须能在不同品牌之间使用，让 iPhone 和 Windows 电脑、Android 手机和 Mac 也能像两台 Apple 设备一样轻松地分享文件。

OmniBeam 要花钱吗？

不要。在设备之间发送文件、文字和链接都是免费的，无需账号，没有广告。这个项目靠使用它的人维持运行；如果它为你节省了时间，你可以用页面顶部的爱心按钮支持它，但没有任何功能需要付费才能使用。作为感谢，捐款的人可以获得一个支持者代码：在设置中输入后，他们设备的卡片上会出现一个别人也能看到的 ♥，还能使用四种颜色主题和更多图片。

哪些设备和浏览器可以用？

任何设备上的任何较新浏览器：iPhone 和 iPad 上的 Safari，Android 上的 Chrome 或三星浏览器，以及 Windows、Mac、Linux 和 Chromebook 上的 Chrome、Edge、Firefox 或 Safari。也有可选的应用供喜欢的人使用：Windows 的 Microsoft Store 版 OmniBeam、Chrome 扩展程序，以及把 OmniBeam 加入分享菜单的 Android 应用。

我的文件会怎样？

它们从一台设备发到另一台，端到端加密，途中不会保存在任何地方。当无法直接连接时，加密中转会转交数据，但无法读取。只有你选择通过链接分享的文件才会以加密形式保存，直到链接过期。

我能怎样帮助这个项目？

告诉为发文件发愁的朋友，在 Microsoft Store 或 Chrome 应用商店留下评分，或在某些功能不如预期时发送反馈。关于连接有问题的手机或浏览器的报告尤其有用，因为它们有助于让每个人的传输都更可靠。

OmniBeam 背后是谁？

OmniBeam 是 Yazeed Bdour 制作的独立项目，不是大公司做的。它在真实的手机和电脑上构建和测试，并根据使用者的问题和建议不断成长。这也是为什么指南和文章用 15 种语言撰写：每天发送文件的人说着其中的许多语言。

OmniBeam 会一直免费吗？

会。OmniBeam 的核心功能，即在你的设备之间发送文件和文字，将对所有人保持免费。捐款用于支付服务器费用，这些服务器让设备互相认识，并在无法直接连接时中转传输。
