ケーブルなしでAndroidからMacにファイルを転送する方法

MacとAndroidスマホではAirDropが使えず、Android File Transferも提供終了しました。OmniBeamなら、写真、動画、書類をWi‑Fi経由でブラウザだけで移せます。インストールは不要です。

手順

  1. MacのSafari、Chrome、Firefoxでomnibeam.siteを開きます。
  2. AndroidスマホのChromeでomnibeam.siteを開きます。少しすると、お互いの画面に相手が表示されます。
  3. スマホでMacをタップし、写真、動画、ファイルを選びます。
  4. Macで受け取るをクリックし、保存します。複数のファイルはまとめてZIPで保存できます。

Macからスマホへ

逆方向も使えます。Finderからファイルを、Macに表示されたスマホのカードにドラッグし、スマホで受け取ります。

もっと速く使うには

  • スマホにOmniBeamをインストールします(Chromeのメニュー →アプリをインストール)。するとAndroidの共有メニューに表示されるので、ギャラリーから共有してMacを選ぶだけです。
  • MacではFinderの右クリックメニューにOmniBeamを追加できます。MacとLinuxからファイルを送るをご覧ください。
  • 同じWi‑Fiにいない場合は、6桁のコードで一度ペアリングすれば、どこにいてもお互いを見つけます。

Android File Transferはもう更新されていないので、多くのMacユーザーはAndroidスマホからファイルを取り出す簡単な方法がありません。両方でブラウザのタブを開くだけで十分です。Macには何もインストールする必要がなく、写真や動画は元の画質のまま届きます。

OmniBeamなら、ケーブルもアプリもアカウントもなしにAndroidからMacへファイルを送れます。

よくある質問

MacがUSBでAndroidスマホを認識しないのはなぜ?

macOSは、追加ソフトなしではAndroidスマホがUSBで使うファイル転送モードに対応しておらず、AppleのAirDropもAndroidには対応していません。ブラウザで使うツールなら両方の問題を避けられます。

Macではどのブラウザを使えばいいですか?

Safari、Chrome、Edge、Firefoxのどれでも使えます。いずれかでomnibeam.siteを開き、送信中はタブを開いたままにしてください。

Macではファイルはどこに保存されますか?

標準では「ダウンロード」フォルダ、またはブラウザで設定した保存先に入ります。複数のファイルを1つのZIPとしてまとめて保存することもできます。

フォルダを送れますか?

はい。Macからはフォルダごと送れ、Androidではギャラリーやファイルマネージャーで多くのファイルを一度に選べます。

逆方向でも使えますか?

はい、MacからAndroidスマホへも送れます。

同じWi‑Fiが必要ですか?

必須ではありません。同じWi‑Fiなら自動でMacが表示されます。スマホがモバイルデータの場合は、Macに表示される6桁のコードかQRコードで一度ペアリングしてください。

書類を送っても安全ですか?

はい。すべての転送はスマホ上でエンドツーエンド暗号化され、復号できるのはMacだけです。途中でサーバーに保存されることはありません。

MacでOmniBeamをすぐ使える状態にできますか?

はい。ブラウザでタブを固定するか、ChromeにOmniBeam拡張機能を追加すれば、Macはいつでも受信できます。
