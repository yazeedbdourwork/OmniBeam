วิธีแชร์ไฟล์ระหว่าง Mac กับ PC Windows โดยไม่ต้องใช้แฟลชไดรฟ์

การแชร์เครือข่ายระหว่าง macOS กับ Windows ต้องยุ่งกับการตั้งค่า SMB ชื่อผู้ใช้ และไฟร์วอลล์ ส่วนแฟลชไดรฟ์ก็ต้องเดินข้ามห้อง OmniBeam ย้ายไฟล์ระหว่าง Mac กับ PC Windows ได้ในเบราว์เซอร์ด้วยไม่กี่คลิก

ขั้นตอน

  1. เปิด omnibeam.site ใน Safari หรือ Chrome บน Mac และใน Edge หรือ Chrome บน PC
  2. ถ้าอยู่ในเครือข่ายเดียวกัน คอมพิวเตอร์แต่ละเครื่องจะแสดงอีกเครื่อง ถ้าไม่ ให้จับคู่ครั้งเดียวด้วยรหัสจากปุ่มลิงก์
  3. ลากไฟล์หรือทั้งโฟลเดอร์ไปวางบนคอมพิวเตอร์อีกเครื่อง หรือคลิกที่เครื่องนั้นเพื่อเลือกไฟล์
  4. กดรับบนคอมพิวเตอร์อีกเครื่อง บันทึกหลายไฟล์เป็น ZIP ไฟล์เดียวได้ และโฟลเดอร์จะคงโครงสร้างเดิม

ไม่ต้องตั้งค่าการแชร์ไฟล์

การแชร์ไฟล์แบบเดิมระหว่าง Mac กับ Windows ต้องใช้เวิร์กกรุ๊ปเดียวกัน มีบัญชีบนคอมพิวเตอร์อีกเครื่อง และตั้งกฎไฟร์วอลล์ให้ถูก OmniBeam ต้องการแค่เบราว์เซอร์บนแต่ละเครื่อง การเชื่อมต่อระหว่างคอมพิวเตอร์สองเครื่องเป็นแบบตรงและเข้ารหัส จึงปลอดภัยกว่าบนเครือข่ายออฟฟิศที่ใช้ร่วมกันด้วย

ทำให้เร็วขึ้นอีก

  • บน Windows ให้ติดตั้ง แอป OmniBeam ฟรีจาก Microsoft Store แล้วเปิดจากเมนู Start
  • จับคู่คอมพิวเตอร์ทั้งสองเครื่องแล้วเปิด รับอัตโนมัติ ไฟล์จาก Mac ของคุณเองจะได้เข้ามาที่ PC โดยไม่ต้องคลิก
  • เปิด ซิงค์คลิปบอร์ด ใน การตั้งค่า เพื่อคัดลอกข้อความบนเครื่องหนึ่งแล้ววางบนอีกเครื่อง
  • ใช้ ส่งโฟลเดอร์อัตโนมัติ บน PC เพื่อส่งทุกไฟล์ใหม่ในโฟลเดอร์ เช่น ภาพหน้าจอ ไปเองโดยอัตโนมัติ

ใช้ได้กับคอมพิวเตอร์ทุกแบบ: MacBook ไปแล็ปท็อป Windows, iMac ไป PC เล่นเกม หรือแล็ปท็อปที่ทำงานไปคอมพิวเตอร์ที่บ้านในเครือข่ายอื่นเมื่อจับคู่แล้ว

ด้วย OmniBeam คุณแชร์ไฟล์ระหว่าง Mac กับ Windows ผ่าน Wi‑Fi ได้โดยไม่ต้องใช้แฟลชไดรฟ์ โฟลเดอร์คลาวด์ หรือการตั้งค่าเครือข่าย

คำถามและคำตอบ

ใช้กับไฟล์วิดีโอขนาดใหญ่ได้ไหม?

ได้ การส่งตรงไม่จำกัดขนาด และไฟล์ตั้งแต่ 1 GB ขึ้นไปจะถูกตรวจสอบทีละส่วนเมื่อมาถึง

ส่งทั้งโฟลเดอร์ได้ไหม?

ได้ ลากโฟลเดอร์ไปวางบนคอมพิวเตอร์อีกเครื่อง โฟลเดอร์จะไปถึงพร้อมโฟลเดอร์ย่อย และคุณบันทึกเป็น ZIP ไฟล์เดียวได้

คอมพิวเตอร์ต้องอยู่ในเครือข่ายเดียวกันไหม?

ไม่ต้องถ้าจับคู่ไว้ครั้งหนึ่งแล้ว คอมพิวเตอร์ที่จับคู่จะเจอกันบนทุกเครือข่าย เช่น แล็ปท็อปที่บ้านกับ PC ที่ออฟฟิศ

เร็วกว่า iCloud Drive หรือ OneDrive ไหม?

สำหรับการส่งครั้งคราว มักจะเร็วกว่า เพราะไฟล์ส่งตรงระหว่างคอมพิวเตอร์ แทนที่จะอัปโหลดขึ้นคลาวด์แล้วดาวน์โหลดลงมาอีกรอบ

ใช้บน Linux ได้ด้วยไหม?

ได้ คอมพิวเตอร์ทุกเครื่องที่มีเบราว์เซอร์รุ่นใหม่เข้าร่วมได้ รวมถึง Linux และ Chromebook

ไฟล์ที่ได้รับบันทึกไว้ที่ไหน?

ในโฟลเดอร์ดาวน์โหลดของเบราว์เซอร์บนแต่ละเครื่อง บน Mac คือโฟลเดอร์ Downloads ใน Finder บน Windows คือโฟลเดอร์ Downloads ใน File Explorer

การเชื่อมต่อปลอดภัยบนเครือข่ายออฟฟิศไหม?

ปลอดภัย คอมพิวเตอร์สองเครื่องใช้การเชื่อมต่อที่เข้ารหัส และมีแค่อุปกรณ์ที่คุณจับคู่หรือที่อยู่ในเครือข่ายเดียวกันเท่านั้นที่มองเห็นกัน
