OmniBeam สำหรับ Windows: ดาวน์โหลดแอปฟรีจาก Microsoft Store

OmniBeam มีอยู่ใน Microsoft Store แอปจะเปิด OmniBeam ในหน้าต่างของตัวเอง เปิดได้จากเมนู Start หรือแถบงาน และแสดงในเมนูแชร์ของ Windows คุณจึงส่งไฟล์ไปยัง iPhone หรือโทรศัพท์ Android ได้โดยไม่ต้องเปิดเบราว์เซอร์ก่อน

ดาวน์โหลด OmniBeam จาก Microsoft Store

ติดตั้ง

  1. เปิด หน้า OmniBeam ใน Microsoft Store แล้วคลิก รับ ใช้ฟรี ไม่ต้องมีบัญชี และไม่มีโฆษณา
  2. เปิด OmniBeam จากเมนู Start ถ้าอยากให้เปิดได้ในคลิกเดียว ให้คลิกขวาที่ไอคอนบนแถบงานแล้วเลือก ปักหมุดที่แถบงาน

ใช้ได้บน Windows 10 และ 11 แอปจะอัปเดตเองทุกครั้งที่ OmniBeam ดีขึ้น จึงไม่ต้องดาวน์โหลดใหม่

จับคู่โทรศัพท์ครั้งเดียว

  1. บนโทรศัพท์ ให้เปิด omnibeam.site ถ้าอยู่ใน Wi‑Fi เดียวกัน PC จะแสดงขึ้นมาเอง
  2. ถ้าอยู่คนละเครือข่าย ให้คลิกปุ่มลิงก์ในแอปบน PC แล้วสแกน QR code ด้วยกล้องโทรศัพท์ หรือพิมพ์รหัส 6 หลัก
  3. บนโทรศัพท์ ให้เปิดหน้าจอจับคู่แล้วติ๊ก เชื่อถือได้ ข้าง PC เพื่อให้ไฟล์จาก PC เข้ามาโดยไม่ต้องถาม

ส่งจาก PC

  • คลิกโทรศัพท์ในแอปแล้วเลือกไฟล์ หรือลากไฟล์จาก File Explorer ไปวางบนโทรศัพท์
  • ใน File Explorer ให้เลือกไฟล์ คลิกขวา เลือก แชร์ แล้วเลือก OmniBeam
  • ถ้าจะส่งลิงก์หรือโน้ต ให้ชี้ที่โทรศัพท์แล้วเลือก ส่งข้อความ เมื่อเปิด ซิงค์คลิปบอร์ด ใน การตั้งค่า ข้อความที่คุณคัดลอกบน PC จะไปอยู่บนโทรศัพท์

ส่งจาก Chrome หรือ Edge: ส่วนขยาย OmniBeam

ส่วนขยายนี้ส่งหน้าที่เปิดอยู่ ลิงก์ รูปภาพ หรือข้อความที่เลือกไปยังโทรศัพท์ของคุณได้ด้วยการคลิกขวา เพิ่มได้จาก Chrome Web Store และใช้ได้ใน Microsoft Edge ด้วย

ชอบไอคอนในถาดระบบและเมนู ส่งไปยัง มากกว่าใช่ไหม?

แอปในถาดระบบรุ่นเก่ายังมีให้ใช้ ถ้าคุณอยากได้ไอคอนข้างนาฬิกาและ OmniBeam ในเมนูคลิกขวา ส่งไปยัง ต้องใช้ Node.js 22 ขึ้นไป: ดาวน์โหลดแอปถาดระบบ (ZIP) แตกไฟล์ไว้ในโฟลเดอร์ที่จะเก็บไว้ แล้วดับเบิลคลิก install-tray.cmd สำหรับคนส่วนใหญ่ แอปจาก Microsoft Store ใช้ง่ายกว่า

ไฟล์จะส่งตรงระหว่างอุปกรณ์ของคุณทุกครั้งที่เครือข่ายเอื้ออำนวย และเข้ารหัสแบบ end-to-end เสมอ

คำถามและคำตอบ

แอปกับเว็บไซต์ต่างกันอย่างไร?

ทำงานเดียวกัน แอปจาก Microsoft Store เริ่มพร้อม Windows และพร้อมใช้งานตลอด โทรศัพท์ของคุณจึงส่งไปยัง PC ได้ทุกเมื่อโดยไม่ต้องเปิดเบราว์เซอร์ก่อน ส่วนเว็บไซต์ใช้ได้โดยไม่ต้องติดตั้งอะไร

แอปอัปเดตเองไหม?

อัปเดตเอง Microsoft Store จะอัปเดตให้อัตโนมัติ คุณจึงได้เวอร์ชันล่าสุดเสมอ

ส่งไฟล์จาก File Explorer ได้ไหม?

ถ้าใช้แอปถาดระบบรุ่นเก่า ได้: แอปจะเพิ่ม OmniBeam ลงในเมนูคลิกขวา ส่งไปยัง คุณเลือกไฟล์ เลือก ส่งไปยัง แล้วเลือก OmniBeam ในแอปจาก Microsoft Store ให้ลากไฟล์ไปวางบนหน้าต่างหรือใช้ตัวเลือกไฟล์

ลบแอปออกได้ไหม?

ได้ ถอนการติดตั้งเหมือนแอปอื่นจาก Settings ของ Windows หรือเมนู Start อุปกรณ์ของคุณยังจับคู่ไว้ในเบราว์เซอร์ถ้าคุณกลับไปใช้เว็บไซต์
