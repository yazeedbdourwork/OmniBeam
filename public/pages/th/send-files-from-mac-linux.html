ส่งไฟล์จาก Mac หรือ PC Linux ไปยังโทรศัพท์ด้วยการคลิกขวา

ตัวช่วย OmniBeam จะเพิ่ม Send with OmniBeam ลงในเมนูคลิกขวาของ Finder บน Mac และของตัวจัดการไฟล์บน Linux เลือกไฟล์ เลือกโทรศัพท์ แล้วไฟล์ก็จะส่งไป โดยไม่ต้องเปิดเบราว์เซอร์บนคอมพิวเตอร์

ดาวน์โหลดสำหรับ Mac และ Linux (ZIP)

ติดตั้งบน Mac

  1. ติดตั้ง Node.js ซึ่งตัวช่วยใช้ในการส่งไฟล์
  2. แตกไฟล์ที่ดาวน์โหลดแล้วดับเบิลคลิก install-mac.command ถ้า macOS ไม่ยอมเปิด ให้คลิกขวา เลือก เปิด แล้วเลือก เปิด อีกครั้ง
  3. พิมพ์รหัสจับคู่จากโทรศัพท์ของคุณเมื่อมีการถาม (ดูด้านล่าง)

จากนั้นคลิกขวาที่ไฟล์ใน Finder แล้วเลือก การทำงานด่วน และ Send with OmniBeam สำหรับข้อความที่เลือกในแอปใดก็ได้ ให้คลิกขวาแล้วเลือก บริการ และ Send text with OmniBeam ถ้าไม่มีให้เลือก ให้เปิดใช้ใน การตั้งค่าระบบ, แป้นพิมพ์, คำสั่งลัดแป้นพิมพ์, บริการ

ติดตั้งบน Linux

  1. ติดตั้ง Node.js 18 ขึ้นไป เช่น sudo apt install nodejs และ zenity (หรือ kdialog บน KDE) สำหรับหน้าต่างเลือกอุปกรณ์
  2. แตกไฟล์ที่ดาวน์โหลด เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วรัน sh install-linux.sh
  3. พิมพ์รหัสจับคู่จากโทรศัพท์ของคุณเมื่อมีการถาม

จากนั้นคลิกขวาที่ไฟล์แล้วเลือก Scripts และ Send with OmniBeam ใน Files, Nemo หรือ Caja หรือเลือก Send with OmniBeam ในเมนูได้เลยใน Dolphin และ Thunar

จับคู่โทรศัพท์ครั้งเดียว

  1. บนโทรศัพท์ ให้เปิด omnibeam.site แตะปุ่มลิงก์แล้วแตะ สร้างรหัสจับคู่
  2. พิมพ์รหัสนั้นลงในตัวติดตั้งบนคอมพิวเตอร์
  3. บนโทรศัพท์ ให้เปิดหน้าจอจับคู่อีกครั้งแล้วติ๊ก เชื่อถือได้ ข้างคอมพิวเตอร์ เพื่อให้ไฟล์จากคอมพิวเตอร์เข้ามาโดยไม่ต้องถาม

โทรศัพท์ต้องเปิด omnibeam.site ไว้จึงจะรับได้ ไฟล์จะผ่านเซิร์ฟเวอร์ OmniBeam แบบเข้ารหัส end-to-end เซิร์ฟเวอร์จึงอ่านไม่ได้ ถ้าจะลบรายการในเมนูออก ให้รัน node omnibeam-send.js --uninstall

ใช้ Chrome หรือ Edge อยู่ใช่ไหม? ส่วนขยาย OmniBeam ส่งหน้าเว็บ ลิงก์ รูปภาพ หรือข้อความที่เลือกไปยังโทรศัพท์ของคุณได้ด้วยการคลิกขวา บน Mac, Linux และ Windows

คำถามและคำตอบ

เมนูคลิกขวาใช้ได้บนเดสก์ท็อป Linux ทุกแบบไหม?

ใช้ได้ในตัวจัดการไฟล์ที่นิยม: Files (Nautilus), Nemo, Caja, Dolphin และ Thunar บนเดสก์ท็อปอื่น คุณยังเปิด omnibeam.site ในเบราว์เซอร์แล้วลากไฟล์เข้าไปได้

ลบรายการในเมนูออกทีหลังได้ไหม?

ได้ รัน node omnibeam-send.js --uninstall ในโฟลเดอร์ของตัวช่วย แล้วรายการจะหายไปจากเมนูคลิกขวา

ส่งไปยัง iPhone และ Android ได้ไหม?

ได้ ส่งไปยังโทรศัพท์ที่คุณจับคู่ด้วยรหัส ไม่ว่าจะเป็น iPhone หรือโทรศัพท์ Android ใน Wi‑Fi เดียวกันหรือใช้เน็ตมือถือ ขอแค่เปิด omnibeam.site ไว้บนโทรศัพท์

ทำไมตัวช่วยต้องใช้ Node.js?

ตัวช่วยเป็นสคริปต์เล็กๆ ที่ทำงานด้วย Node.js จับคู่กับโทรศัพท์ของคุณครั้งเดียว แล้วส่งไฟล์ที่คุณเลือกโดยไม่ต้องเปิดเบราว์เซอร์บนคอมพิวเตอร์ ทำให้การคลิกขวาใช้งานได้รวดเร็ว

ส่งข้อความที่เลือกได้ด้วยไหม?

บน Mac ได้: เลือกข้อความในแอปใดก็ได้ คลิกขวาแล้วเลือก บริการ แล้ว Send text with OmniBeam ข้อความจะไปถึงโทรศัพท์พร้อมให้คัดลอก

ไฟล์ถูกเข้ารหัสไหม?

ถูกเข้ารหัส ไฟล์เข้ารหัสแบบ end-to-end บนคอมพิวเตอร์ และเซิร์ฟเวอร์แค่ส่งต่อโดยอ่านไม่ได้
