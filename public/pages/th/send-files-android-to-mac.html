วิธีส่งไฟล์จาก Android ไปยัง Mac โดยไม่ต้องใช้สาย

Mac กับโทรศัพท์ Android ใช้ AirDrop ร่วมกันไม่ได้ และ Android File Transfer ก็เลิกไปแล้ว OmniBeam ย้ายรูป วิดีโอ และเอกสารระหว่างกันผ่าน Wi‑Fi ได้ในเบราว์เซอร์เลย โดยไม่ต้องติดตั้งอะไร

ขั้นตอน

  1. บน Mac ให้เปิด omnibeam.site ใน Safari, Chrome หรือ Firefox
  2. บนโทรศัพท์ Android ให้เปิด omnibeam.site ใน Chrome รอสักครู่ อุปกรณ์แต่ละเครื่องจะแสดงอีกเครื่องขึ้นมา
  3. บนโทรศัพท์ ให้แตะ Mac แล้วเลือกรูป วิดีโอ หรือไฟล์ใดก็ได้
  4. คลิก รับ บน Mac แล้วคลิก บันทึก บันทึกหลายไฟล์พร้อมกันเป็น ZIP ได้

จาก Mac ไปยังโทรศัพท์

ใช้ได้ทั้งสองทาง: ลากไฟล์จาก Finder ไปวางบนการ์ดของโทรศัพท์บน Mac แล้วกดรับบนโทรศัพท์

ทำให้เร็วขึ้นอีก

  • ติดตั้ง OmniBeam บนโทรศัพท์ (เมนู Chrome แล้วเลือก ติดตั้งแอป) จากนั้นจะแสดงในเมนูแชร์ของ Android: แชร์จากแกลเลอรีแล้วเลือก Mac
  • บน Mac คุณเพิ่ม OmniBeam ลงในเมนูคลิกขวาของ Finder ได้ ดู การส่งไฟล์จาก Mac และ Linux
  • ไม่ได้อยู่ใน Wi‑Fi เดียวกันใช่ไหม? จับคู่อุปกรณ์ทั้งสองครั้งเดียวด้วยรหัส 6 หลัก แล้วจะเจอกันได้ทุกที่

Android File Transfer ไม่ได้อัปเดตแล้ว ผู้ใช้ Mac หลายคนจึงไม่มีวิธีง่ายๆ ในการดึงไฟล์ออกจากโทรศัพท์ Android แค่แท็บเบราว์เซอร์ฝั่งละแท็บก็พอ: ไม่ต้องติดตั้งอะไรบน Mac และรูปกับวิดีโอจะไปถึงในคุณภาพต้นฉบับ

ด้วย OmniBeam คุณส่งไฟล์จาก Android ไปยัง Mac ได้โดยไม่ต้องใช้สาย แอป หรือบัญชี

คำถามและคำตอบ

ทำไม Mac ไม่เห็นโทรศัพท์ Android ผ่าน USB?

macOS ไม่รองรับโหมดส่งไฟล์ที่โทรศัพท์ Android ใช้ผ่าน USB ถ้าไม่มีซอฟต์แวร์เพิ่ม และ AirDrop ของ Apple ก็ไม่รองรับ Android เครื่องมือที่ทำงานบนเบราว์เซอร์จึงเลี่ยงปัญหาทั้งสองได้

ควรใช้เบราว์เซอร์ไหนบน Mac?

Safari, Chrome, Edge และ Firefox ใช้ได้ทั้งหมด เปิด omnibeam.site ในเบราว์เซอร์ไหนก็ได้และเปิดแท็บค้างไว้ระหว่างส่ง

ไฟล์บันทึกไว้ที่ไหนบน Mac?

ค่าเริ่มต้นจะไปที่โฟลเดอร์ดาวน์โหลด หรือที่ที่เบราว์เซอร์ของคุณตั้งไว้สำหรับบันทึกไฟล์ดาวน์โหลด บันทึกหลายไฟล์รวมเป็น ZIP ไฟล์เดียวก็ได้

ส่งโฟลเดอร์ได้ไหม?

ได้ คุณส่งทั้งโฟลเดอร์จาก Mac ได้ และบน Android คุณเลือกหลายไฟล์พร้อมกันจากแกลเลอรีหรือตัวจัดการไฟล์ได้

ส่งกลับอีกทางได้ไหม?

ได้ จาก Mac ไปยังโทรศัพท์ Android ก็ได้เช่นกัน

ต้องอยู่ใน Wi‑Fi เดียวกันไหม?

ไม่จำเป็น ถ้าอยู่ใน Wi‑Fi เดียวกัน Mac จะแสดงขึ้นมาเอง ถ้าโทรศัพท์ใช้เน็ตมือถือ ให้จับคู่อุปกรณ์ทั้งสองครั้งเดียวด้วยรหัส 6 หลักหรือ QR code ที่แสดงบน Mac

ปลอดภัยสำหรับเอกสารไหม?

ปลอดภัย ทุกการส่งเข้ารหัสแบบ end-to-end บนโทรศัพท์ของคุณ และมีแค่ Mac เท่านั้นที่ถอดรหัสได้ ไม่มีอะไรเก็บไว้บนเซิร์ฟเวอร์ระหว่างทาง

ให้ OmniBeam พร้อมใช้บน Mac ตลอดได้ไหม?

ได้ ปักหมุดแท็บไว้ในเบราว์เซอร์ หรือเพิ่มส่วนขยาย OmniBeam ใน Chrome แล้ว Mac จะพร้อมรับไฟล์ทุกครั้งที่คุณเปิด
