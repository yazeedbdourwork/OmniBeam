วิธีส่งไฟล์ระหว่างคอมพิวเตอร์สองเครื่องโดยไม่ต้องใช้แฟลชไดรฟ์

การคัดลอกลงแฟลชไดรฟ์ ส่งอีเมลหาตัวเอง หรืออัปโหลดขึ้นคลาวด์ ล้วนใช้เวลานานกว่าที่ควรเป็นสองเท่า OmniBeam ส่งไฟล์จากคอมพิวเตอร์เครื่องหนึ่งตรงไปยังอีกเครื่อง ไม่ว่าจะเป็น Windows, Mac, Linux หรือ Chromebook จับคู่แบบไหนก็ได้

ขั้นตอน

  1. เปิด omnibeam.site ในเบราว์เซอร์บนคอมพิวเตอร์ทั้งสองเครื่อง
  2. ถ้าอยู่ในเครือข่ายเดียวกัน คอมพิวเตอร์จะแสดงขึ้นมาเอง ถ้าไม่ ให้คลิกปุ่มจับคู่บนเครื่องหนึ่งแล้วพิมพ์รหัส 6 หลักบนอีกเครื่อง
  3. ลากไฟล์หรือทั้งโฟลเดอร์ไปวางบนการ์ดของคอมพิวเตอร์อีกเครื่อง หรือคลิกที่การ์ดแล้วเลือกไฟล์
  4. กดรับบนคอมพิวเตอร์อีกเครื่อง โฟลเดอร์จะคงโครงสร้างเดิมและบันทึกเป็น ZIP ไฟล์เดียวได้

ทำไมถึงเร็ว

  • ไฟล์ส่งตรงระหว่างคอมพิวเตอร์สองเครื่องผ่านเครือข่ายของคุณ ไม่ผ่านเซิร์ฟเวอร์คลาวด์
  • ไม่จำกัดขนาด และการส่งไฟล์ใหญ่จะดำเนินต่อเองถ้าการเชื่อมต่อหลุด
  • ทุกอย่างเข้ารหัสแบบ end-to-end และไม่มีอะไรเก็บไว้ที่ไหนเลย

ส่งแบบนี้บ่อยใช่ไหม?

บน Windows ให้ดาวน์โหลด แอป OmniBeam จาก Microsoft Store เพื่อส่งจากหน้าต่างของแอปเองหรือจากเมนูแชร์ของ Windows (ทำงานอย่างไร) และเพิ่ม ส่วนขยาย Chrome เพื่อส่งหน้าเว็บหรือลิงก์ที่คุณกำลังดูได้ในคลิกเดียว

ใช้ได้ระหว่าง Windows, Mac, Linux และ Chromebook ทุกแบบ เพราะต้องการแค่เบราว์เซอร์รุ่นใหม่ ถ้าอยู่ในเครือข่ายเดียวกัน คอมพิวเตอร์จะเจอกันเอง ถ้าอยู่คนละที่ ให้ใช้รหัสจับคู่

คุณส่งไฟล์ระหว่างคอมพิวเตอร์สองเครื่องได้โดยไม่ต้องใช้แฟลชไดรฟ์ สายเคเบิล หรือบัญชีคลาวด์

คำถามและคำตอบ

ใช้ระหว่าง Windows กับ Mac ได้ไหม?

ได้ OmniBeam ทำงานในเบราว์เซอร์บนทั้งสองระบบ คุณจึงส่งจาก PC Windows ไป Mac จาก Mac ไป Chromebook หรือระหว่างคอมพิวเตอร์สองเครื่องใดก็ได้

ย้ายทั้งโฟลเดอร์ได้ไหม?

ได้ ลากโฟลเดอร์ไปวางบนคอมพิวเตอร์อีกเครื่องใน OmniBeam ฝั่งที่รับบันทึกไฟล์ทั้งหมดรวมเป็น ZIP ไฟล์เดียวได้ เพื่อคงโครงสร้างโฟลเดอร์ไว้

ไฟล์ใหญ่มากล่ะ?

การส่งตรงไม่จำกัดขนาด และถ้าการเชื่อมต่อหลุด การส่งจะดำเนินต่อจากจุดที่ค้างไว้ ถ้าจะย้ายทั้งไดรฟ์ ฮาร์ดดิสก์ภายนอกก็ยังเร็วกว่า

คอมพิวเตอร์ทั้งสองต้องอยู่ในเครือข่ายเดียวกันไหม?

ไม่ต้อง ถ้าอยู่ในเครือข่ายเดียวกันจะแสดงขึ้นมาเอง ถ้าไม่ ให้จับคู่ครั้งเดียวด้วยรหัส แล้วจะเจอกันเองตั้งแต่นั้น

ปลอดภัยบนเครือข่ายที่ใช้ร่วมกันหรือเครือข่ายสาธารณะไหม?

ปลอดภัย ทุกการส่งเข้ารหัสแบบ end-to-end บนคอมพิวเตอร์ที่ส่ง และถอดรหัสได้บนเครื่องที่รับเท่านั้น คนอื่นในเครือข่ายเดียวกันจึงอ่านไฟล์ไม่ได้

คัดลอกข้อความหรือลิงก์ระหว่างคอมพิวเตอร์ได้ด้วยไหม?

ได้ วางข้อความลงใน OmniBeam แล้วส่ง หรือเปิดซิงค์คลิปบอร์ด เพื่อให้ข้อความที่คัดลอกบนเครื่องหนึ่งส่งไปยังอีกเครื่องได้ในคลิกเดียว

ต้องมีบัญชีบนคอมพิวเตอร์ทั้งสองเครื่องไหม?

ไม่ต้อง ไม่มีบัญชี ไม่ต้องสมัคร และไม่ต้องติดตั้งอะไร เปิดหน้าเว็บบนคอมพิวเตอร์ทั้งสองเครื่องแล้วเริ่มส่งได้เลย
