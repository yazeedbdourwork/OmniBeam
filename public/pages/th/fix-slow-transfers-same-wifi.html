อยู่ Wi‑Fi เดียวกัน แต่ส่งช้าหรือส่งผ่านเซิร์ฟเวอร์

ใน Wi‑Fi เดียวกัน OmniBeam ควรเชื่อมต่ออุปกรณ์สองเครื่องโดยตรง และเส้นทางใต้แถบความคืบหน้าควรแสดงว่า “เครือข่ายเดียวกัน” ถ้าแสดงว่า “อินเทอร์เน็ต” “ผ่านเราเตอร์” หรือ “กำลังส่งผ่านเซิร์ฟเวอร์” มักมีสาเหตุจากข้อใดข้อหนึ่งต่อไปนี้

1. ตรวจสอบการเชื่อมต่อ

แตะ ID เครือข่ายข้างชื่ออุปกรณ์ของคุณที่ด้านล่างของ OmniBeam การตรวจสอบจะแสดงว่าอุปกรณ์นี้แชร์ที่อยู่ภายในไหม มี VPN ขวางอยู่ไหม และการส่งครั้งล่าสุดใช้เส้นทางไหน พร้อมเคล็ดลับตามสิ่งที่พบ

2. อนุญาตการเชื่อมต่อภายใน (⚡)

เบราว์เซอร์ซ่อนที่อยู่เครือข่ายภายในของอุปกรณ์จากเว็บไซต์ อุปกรณ์อีกเครื่องจึงต้องหาจากชื่อภายใน (mDNS) ซึ่งหลายเครือข่ายบล็อกไว้ และการส่งจะอ้อมผ่านเราเตอร์ แตะ ⚡ ส่งผ่าน Wi‑Fi เร็วขึ้น แล้วอนุญาตไมโครโฟนครั้งเดียวบนเครื่องเดียวหรือทั้งสองเครื่อง: ไม่มีการบันทึกเสียงใดๆ แต่เบราว์เซอร์จะแชร์ที่อยู่ภายใน และอุปกรณ์จะเชื่อมต่อตรงได้

3. ปิด VPN และ private relay

  • ปิดแอป VPN รวมถึงฟีเจอร์ “การเชื่อมต่อที่ปลอดภัย” ของแอนติไวรัส บนอุปกรณ์ทั้งสองระหว่างส่ง
  • บน iPhone ให้ปิด iCloud Private Relay และใน การตั้งค่า → Wi‑Fi → เครือข่ายของคุณ ให้ปิด “จำกัดการติดตามที่อยู่ IP”

4. Windows: ใช้เครือข่ายส่วนตัว

บนเครือข่าย “Public” Windows จะบล็อกการค้นหาภายในที่อุปกรณ์ใช้หากัน เปิด Settings → Network & internet → Wi‑Fi (หรือ Ethernet) → เครือข่ายของคุณ แล้วเลือก Private network ไฟร์วอลล์ของคุณต้องอนุญาตเบราว์เซอร์บนเครือข่ายส่วนตัวด้วย

5. ตรวจสอบเราเตอร์

  • เครือข่ายแขกและ “AP isolation” หรือ “client isolation” ทำให้อุปกรณ์ใน Wi‑Fi เดียวกันติดต่อกันไม่ได้ ให้ใช้เครือข่ายหลัก หรือปิด isolation ในการตั้งค่าเราเตอร์
  • เราเตอร์บางรุ่นแยกเครือข่าย 2.4 GHz กับ 5 GHz ออกจากกัน ให้เชื่อมต่ออุปกรณ์ทั้งสองกับเครือข่ายเดียวกัน

ยังไม่ส่งตรงอีกใช่ไหม?

การส่งยังใช้ได้อยู่: OmniBeam จะส่งผ่านเซิร์ฟเวอร์แบบเข้ารหัส end-to-end เพียงแต่ช้ากว่า คุณจับคู่อุปกรณ์ด้วยรหัสได้ด้วย ซึ่งไม่ได้ทำให้เส้นทางเร็วขึ้น แต่อุปกรณ์จะเจอกันเสมอ

เมื่อการส่งใน Wi‑Fi เดียวกันช้าหรือผ่านเซิร์ฟเวอร์ ขั้นตอนด้านบนมักแก้ได้ภายในไม่กี่นาที

คำถามและคำตอบ

จะรู้ได้อย่างไรว่าการส่งผ่านเซิร์ฟเวอร์?

OmniBeam แสดงประเภทการเชื่อมต่อบนการส่ง การเชื่อมต่อตรงใน Wi‑Fi เดียวกันมักได้หลายเมกะไบต์ต่อวินาที ส่วนการส่งผ่านรีเลย์จะถูกจำกัดด้วยความเร็วอัปโหลดอินเทอร์เน็ตของคุณ และมักช้ากว่ามาก

เครือข่ายแขกเป็นสาเหตุได้ไหม?

บ่อยครั้งใช่ เครือข่ายแขกและเราเตอร์ mesh บางรุ่นแยกอุปกรณ์ออกจากกันเพื่อความปลอดภัย การส่งจึงต้องผ่านรีเลย์ ให้อุปกรณ์ทั้งสองอยู่ในเครือข่ายหลักเพื่อให้เชื่อมต่อตรงได้

รีสตาร์ทเราเตอร์ช่วยไหม?

บางครั้ง ถ้าการตั้งค่าเราเตอร์ถูกต้องอยู่แล้ว การรีสตาร์ทช่วยแก้สถานะที่ค้างได้ แต่ VPN บนอุปกรณ์เครื่องหนึ่งหรือโปรไฟล์เครือข่ายสาธารณะบน Windows จะยังทำให้เกิดปัญหาจนกว่าคุณจะเปลี่ยน

ทำไมเชื่อมต่อตรงแล้วยังช้าอยู่?

การส่งตรงจะเร็วได้เท่ากับส่วนที่ช้าที่สุดของเส้นทาง โทรศัพท์รุ่นเก่า สัญญาณ Wi‑Fi ที่อ่อนในอีกห้อง หรือเครือข่าย 2.4 GHz ที่แออัด ล้วนจำกัดความเร็วได้ ขยับเข้าใกล้เราเตอร์ หรือใช้เครือข่าย 5 GHz สำหรับไฟล์ใหญ่
