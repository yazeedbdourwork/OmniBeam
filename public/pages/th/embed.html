กล่อง “ส่งไฟล์ให้ฉัน” สำหรับเว็บไซต์หรือบล็อกของคุณ

ให้ผู้เข้าชม ลูกค้า หรือนักเรียนส่งไฟล์ให้คุณได้จากหน้าเว็บของคุณเอง คุณแค่วางโค้ดสั้นๆ หนึ่งชุด ไฟล์จะเข้ารหัสบนอุปกรณ์ของผู้ส่งแล้วมาถึง OmniBeam บนอุปกรณ์ของคุณ

ขั้นตอน

  1. เปิด omnibeam.site บนอุปกรณ์ที่จะรับไฟล์ แล้วแตะ ขอไฟล์ ในเมนู ⋯
  2. เขียนสิ่งที่ต้องการ (ไม่บังคับ) เลือก 1 ปี (สำหรับเว็บไซต์) ใต้ “ลิงก์ใช้ได้” แล้วแตะ สร้างลิงก์ขอไฟล์
  3. แตะ ใส่ไว้บนเว็บไซต์ของคุณ แล้วแตะ คัดลอกโค้ด
  4. วางโค้ดในหน้าเว็บของคุณ: ใน WordPress ใช้บล็อก Custom HTML ใน Blogger ใช้แกดเจ็ต HTML/JavaScript ใน Wix ใช้องค์ประกอบ Embed HTML ใน Squarespace ใช้บล็อก Code

ผู้เข้าชมจะเห็นกล่องเล็กๆ ที่มี “เลือกไฟล์” ช่องใส่ชื่อ (ไม่บังคับ) และปุ่ม ส่ง ไม่ต้องลงแอปและไม่ต้องมีบัญชี ไฟล์จะมาถึงอุปกรณ์ของคุณใน ไฟล์ที่ได้รับ ถ้า OmniBeam ปิดอยู่ที่นั่น ไฟล์จะรออยู่บนเซิร์ฟเวอร์และเข้ามาเมื่อคุณเปิด พร้อมการแจ้งเตือนถ้าคุณเปิดการแจ้งเตือนไว้

WordPress: ปลั๊กอิน OmniBeam ฟรี

บน WordPress มีวิธีที่ง่ายกว่า: ดาวน์โหลดปลั๊กอิน OmniBeam (omnibeam-wordpress.zip) จากนั้นใน WordPress ไปที่ Plugins → Add New → Upload Plugin เลือกไฟล์ zip แล้วแตะ Activate วางโค้ดของคุณ (หรือแค่ลิงก์) ใน Settings → OmniBeam Box แล้วเพิ่มบล็อก OmniBeam: Send me files ในหน้าไหนก็ได้ หรือใช้ shortcode [omnibeam_box] กล่องที่มีลิงก์และความสูงของตัวเอง: [omnibeam_box url="https://omnibeam.site/embed/r/…" height="520"] ปลั๊กอินรับเฉพาะกล่องจาก omnibeam.site และไฟล์จะไม่ผ่านเว็บไซต์ WordPress ของคุณเลย

เป็นส่วนตัวและปลอดภัยไหม?

  • ทุกการอัปโหลดเข้ารหัสในเบราว์เซอร์ของผู้เข้าชม คีย์ของไฟล์ถูกปิดผนึกด้วยคีย์สาธารณะของอุปกรณ์คุณ และมีแค่อุปกรณ์ของคุณที่มีคีย์ส่วนตัวที่ตรงกัน ทั้ง OmniBeam และใครก็ตามที่อ่านโค้ดในหน้าของคุณจึงเปิดไฟล์ไม่ได้
  • โค้ดบนหน้าเว็บของคุณเป็นสาธารณะ ใครที่เห็นก็ส่งไฟล์ให้คุณได้ และอ่านข้อความ “ต้องการอะไร” กับชื่ออุปกรณ์ของคุณได้ จึงอย่าเขียนอะไรที่เป็นส่วนตัวไว้ตรงนั้น
  • มีแค่อุปกรณ์ของคุณที่ดาวน์โหลดสิ่งที่อัปโหลดมาได้ และแต่ละไฟล์จะถูกลบจากเซิร์ฟเวอร์ทันทีที่อุปกรณ์ได้รับ ไฟล์ที่ไม่มีใครรับจะถูกลบหลัง 7 วัน
  • ขีดจำกัดปกติยังคงอยู่: ขีดจำกัดขนาดต่อการอัปโหลด ขีดจำกัดต่อเครือข่ายต่อชั่วโมง และไม่เกิน 100 การอัปโหลดต่อวันต่อกล่อง
  • ลบลิงก์ขอไฟล์ในหน้าต่างเดียวกันได้ทุกเมื่อ แล้วกล่องจะหยุดทำงานทันที

คำถามและคำตอบ

มีค่าใช้จ่ายไหม?

ไม่มี กล่องใช้ฟรี ไม่ต้องมีบัญชีและไม่มีโฆษณา ปลั๊กอิน WordPress ก็ฟรีเช่นกัน

ใช้บนหลายหน้าได้ไหม?

ได้ วางโค้ดเดียวกันในทุกหน้าที่ต้องการ ทุกการอัปโหลดจะมาถึงอุปกรณ์เดียวกัน สร้างลิงก์ขอไฟล์แยกถ้าอยากแยกแยะว่ามาจากหน้าไหน

ทำไมกล่องหยุดทำงานหลังจากผ่านไประยะหนึ่ง?

ลิงก์ขอไฟล์ทุกลิงก์สิ้นสุดตามเวลาที่คุณเลือก สำหรับเว็บไซต์ให้เลือก 1 ปี และสร้างลิงก์กับโค้ดใหม่ก่อนหมดอายุ

มีคนใช้กล่องของฉันส่งสแปมได้ไหม?

ใครที่เข้าชมหน้าก็ส่งไฟล์ให้คุณได้ เหมือนที่อยู่อีเมล ไฟล์ไม่เคยเปิดเอง การอัปโหลดถูกจำกัดต่อเครือข่ายและต่อวัน และคุณลบลิงก์เพื่อปิดกล่องได้
