AirDrop สำหรับ Windows และ Android: ทางเลือกบนเบราว์เซอร์

AirDrop ใช้ได้เฉพาะระหว่างอุปกรณ์ Apple OmniBeam ให้คุณแตะแล้วส่งได้แบบเดียวกันระหว่างอุปกรณ์ใดก็ได้ เพราะทำงานในเว็บเบราว์เซอร์

สิ่งที่คุณจะได้

  • อุปกรณ์ใน Wi‑Fi เดียวกันจะเจอกันเองอัตโนมัติ เหมือน AirDrop
  • ใช้ได้ระหว่าง iPhone, iPad, Mac, Windows, Android, Linux และ Chromebook
  • ไฟล์ส่งตรงจากอุปกรณ์ถึงอุปกรณ์และเข้ารหัสแบบ end-to-end
  • การส่งตรงไม่จำกัดขนาด ไม่ต้องมีบัญชี และไม่ต้องติดตั้งอะไร
  • อุปกรณ์ที่อยู่คนละเครือข่ายจับคู่ครั้งเดียวด้วยรหัส 6 หลักได้

เปรียบเทียบ AirDrop กับ OmniBeam

  • อุปกรณ์: AirDrop ใช้ได้เฉพาะ Apple ส่วน OmniBeam ใช้ได้บนทุกอุปกรณ์ที่มีเบราว์เซอร์รุ่นใหม่
  • ระยะทาง: AirDrop ต้องให้อุปกรณ์อยู่ใกล้กัน ส่วน OmniBeam ใช้ผ่านอินเทอร์เน็ตได้ด้วย
  • การแชร์ให้คนอื่น: OmniBeam สร้างลิงก์เข้ารหัสที่ใครก็เปิดได้ภายหลังด้วย

รายละเอียดเพิ่มเติมใน OmniBeam เทียบกับ AirDrop

ใช้ให้รู้สึกเหมือนแอป

ติดตั้ง OmniBeam จากเบราว์เซอร์ (ติดตั้ง ใน Chrome หรือ Edge, เพิ่มไปยังหน้าจอโฮม บน iPhone) บน Windows ให้ดาวน์โหลด แอป OmniBeam ฟรีจาก Microsoft Store ดู OmniBeam สำหรับ Windows

ต่างจาก AirDrop ตรงที่ OmniBeam ไม่ต้องใช้ Bluetooth และไม่ต้องมีบัญชี Apple อุปกรณ์ทั้งสองแค่มีเบราว์เซอร์ และทุกการส่งเข้ารหัสแบบ end-to-end ไฟล์จึงเป็นส่วนตัวแม้ตอนที่ผ่านเซิร์ฟเวอร์รีเลย์

OmniBeam คือทางเลือกแทน AirDrop สำหรับ Windows และ Android แบบฟรีที่ทำงานในเบราว์เซอร์

คำถามและคำตอบ

มี AirDrop อย่างเป็นทางการสำหรับ Windows หรือ Android ไหม?

ไม่มี AirDrop มีอยู่ในอุปกรณ์ Apple เท่านั้น และ Apple ไม่ได้ออกให้ Windows หรือ Android ถ้าอยากแชร์ได้รวดเร็วแบบเดียวกันระหว่าง iPhone กับ PC หรือโทรศัพท์ Android คุณต้องใช้เครื่องมือที่ใช้ได้ทั้งสองฝั่ง เช่น OmniBeam ในเบราว์เซอร์

OmniBeam ใกล้เคียง AirDrop แค่ไหน?

ใกล้เคียงมากในการใช้งานประจำวัน: อุปกรณ์ใน Wi‑Fi เดียวกันแสดงขึ้นมาเอง คุณแตะเครื่องหนึ่งแล้วเลือกไฟล์ และอุปกรณ์อีกเครื่องกดรับ ความต่างคือ OmniBeam ทำงานในแท็บเบราว์เซอร์แทนเมนูของระบบ และยังใช้ข้ามเครือข่ายได้หลังจับคู่ครั้งเดียว

ส่งไปยัง PC Windows ที่ไม่ได้เปิดเบราว์เซอร์ได้ไหม?

อุปกรณ์ที่รับต้องเปิดหน้าเว็บไว้ เหมือนที่ AirDrop ต้องให้เครื่องที่รับตื่นอยู่และมองเห็นได้ บน Windows แอป OmniBeam ฟรีจาก Microsoft Store ทำให้ง่ายขึ้น: แอปจะเริ่มพร้อม PC ไฟล์จึงเข้ามาได้โดยไม่ต้องเปิดเบราว์เซอร์ก่อน

ใช้กับรูปจาก iPhone ได้ไหม?

ได้ รูปและวิดีโอไปถึงในคุณภาพเต็ม และรูป HEIC จาก iPhone บันทึกเป็น JPG ได้ เพื่อให้เปิดได้บน PC Windows หรือโทรศัพท์ Android ทุกเครื่อง

ปลอดภัยไหม?

ทุกการส่งเข้ารหัสแบบ end-to-end บนอุปกรณ์ของคุณ และไม่มีอะไรเก็บไว้บนเซิร์ฟเวอร์ระหว่างทาง

หลายอุปกรณ์รับพร้อมกันได้ไหม?

ได้ ใช้ “ส่งถึงทุกคน” เพื่อส่งไฟล์เดียวกันไปยังทุกอุปกรณ์ที่เปิดอยู่ หรือเข้าห้องสาธารณะเพื่อให้กลุ่มโทรศัพท์และคอมพิวเตอร์แชร์ถึงกันได้ สะดวกมากในห้องเรียนหรือที่ประชุม ซึ่ง AirDrop จะส่งได้แค่อุปกรณ์ Apple ในห้อง

ใช้แบบออฟไลน์ได้ไหม?

อุปกรณ์ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อหากัน แม้ตัวไฟล์จะส่งตรงผ่าน Wi‑Fi ของคุณทุกครั้งที่ทำได้
