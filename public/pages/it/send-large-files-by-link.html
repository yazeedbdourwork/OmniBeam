Invia un file con un link, crittografato

Quando l'altra persona non è online nello stesso momento, o non vuoi associare i dispositivi, condividi i file tramite link. Vengono crittografati sul tuo dispositivo prima di partire.

Passaggi

  1. Apri omnibeam.site, poi tocca Condividi file tramite link nel menu ⋯ in alto.
  2. Scegli per quanto deve funzionare il link (1 ora, 1 giorno o 3 giorni) e, se vuoi, "Elimina dopo il primo download".
  3. Scegli i file. Vengono crittografati e caricati, e ottieni un link e un codice QR.
  4. Invia il link via WhatsApp, email o qualsiasi app. Chi lo apre può scaricare i file da qualsiasi dispositivo.

Quanto è privato?

I file e i loro nomi vengono crittografati nel tuo browser con una chiave casuale. La chiave è la parte del link dopo "#", che i browser non inviano mai a un server, quindi OmniBeam conserva solo dati che non può leggere. Tratta il link come il file stesso: chiunque lo abbia può scaricare.

Limiti

  • I link hanno un limite di dimensione, mostrato quando ne crei uno.
  • I file vengono eliminati automaticamente alla scadenza del link. Puoi anche eliminare un link tu stesso in qualsiasi momento dalla stessa finestra.
  • Per file molto grandi, invia invece direttamente a un dispositivo: i trasferimenti diretti non hanno limiti di dimensione.

Un link è comodo quando l'altra persona non è online insieme a te. Il file viene crittografato prima di lasciare il browser, quindi solo le persone a cui dai il link possono aprirlo.

Inviare un file grande con un link è gratis, e il file viene crittografato prima di lasciare il tuo dispositivo.

Domande e risposte

Quando un link è meglio di un trasferimento diretto?

Usa un link quando l'altra persona non è online nello stesso momento, quando vuoi inviare lo stesso file a più persone, o quando non puoi associare i dispositivi. Per file molto grandi verso i tuoi dispositivi, un trasferimento diretto è più veloce e non ha limiti.

Posso vedere se il file è stato scaricato?

Puoi scegliere "Elimina dopo il primo download", così il link smette di funzionare una volta usato. Puoi anche eliminare il link tu stesso in qualsiasi momento dalla stessa finestra.

L'altra persona ha bisogno di OmniBeam?

No. Basta aprire il link in un browser su qualsiasi dispositivo e scaricare i file. Non c'è niente da installare e non serve un account.

OmniBeam può vedere i miei file?

No. I file vengono crittografati nel tuo browser prima del caricamento, e la chiave resta nella parte del link dopo "#", che non viene mai inviata al server.

Per quanto resta disponibile un link?

Lo scegli quando lo crei: 1 ora, 1 giorno o 3 giorni. Dopo quel tempo i file vengono eliminati automaticamente e il link smette di funzionare.

Posso inviare più file con un solo link?

Sì. Scegli tutti i file che vuoi, e chi apre il link li vede tutti e può scaricarli uno per uno o insieme.

Posso condividere il link come codice QR?

Sì. Ogni link ha il suo codice QR, così chi ti è vicino può inquadrarlo con la fotocamera del telefono e scaricare subito.
