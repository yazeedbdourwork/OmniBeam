Termini d'uso di OmniBeam

Ultimo aggiornamento: 26 ottobre 2026

Usando OmniBeam.Site, accetti di condividere solo file e testi che hai il diritto legale di distribuire. I trasferimenti vanno dal dispositivo di un utente a quello di un altro; gli utenti sono gli unici responsabili dei contenuti che trasmettono.

Uso consentito

  • Non inviare malware, contenuti illegali o qualsiasi cosa che violi i diritti di altri.
  • Non usare le stanze pubbliche per inviare file indesiderati a sconosciuti.
  • Non usare i link condivisi per pubblicare o distribuire contenuti al pubblico; servono a inviare file a persone che conosci.
  • Non cercare di sovraccaricare, attaccare o usare in modo improprio il servizio o il suo server di inoltro.

Link condivisi

I link hanno limiti di dimensione e di tempo e vengono eliminati automaticamente alla scadenza. I link che violano questi termini possono essere rimossi.

Nessuna garanzia

OmniBeam è fornito "così com'è", senza garanzie di alcun tipo. Conserva le tue copie dei file importanti; non siamo responsabili di trasferimenti persi, danneggiati o incompleti.

Modifiche

Questi termini possono cambiare man mano che il servizio cresce. La data qui sopra indica la versione più recente.

Questi termini valgono per chiunque invii file con OmniBeam.

Domande e risposte

Cosa coprono questi termini?

Coprono il tuo uso di OmniBeam: inviare file e testo tra dispositivi, associare dispositivi, entrare in stanze pubbliche e condividere file con un link. Le risposte qui sotto riassumono i punti principali con parole semplici; se qualcosa qui sembra diverso dai termini sopra, valgono i termini sopra.

Chi è responsabile dei file che invio?

Tu. OmniBeam porta solo i file da un dispositivo all'altro, crittografati, e non può vedere cosa contengono. Invia solo file che hai il diritto di condividere, e non usare mai OmniBeam per inviare qualcosa di illegale o dannoso.

Posso usare OmniBeam per lavoro?

Sì. Puoi usarlo per spostare i tuoi file di lavoro tra i tuoi dispositivi o per condividere file con i colleghi, purché sia consentito dalle regole del tuo datore di lavoro e i file siano tuoi da condividere.

Cosa succede ai file condivisi con un link?

Restano conservati crittografati solo finché il link non scade o finché non lo elimini, e poi vengono rimossi. Chiunque abbia il link può scaricare i file, quindi condividilo con attenzione.

C'è la garanzia che i trasferimenti funzionino sempre?

OmniBeam è fornito così com'è, gratuitamente. C'è molto lavoro dietro per rendere affidabili i trasferimenti, ma reti e dispositivi sono diversi, quindi conserva le tue copie dei file importanti finché non sono arrivati.

I termini possono cambiare?

Sì. Quando i termini cambiano, la data di questa pagina viene aggiornata. Usare OmniBeam dopo una modifica significa accettare i nuovi termini.

Ci sono limiti a come posso usare OmniBeam?

Usalo correttamente: non cercare di sovraccaricare o rompere il servizio, non inviare spam o malware, e non usare le stanze pubbliche per molestare altre persone. Gli account non servono, ma l'abuso del servizio può essere bloccato.

Dove posso fare una domanda sui termini?

Invia un messaggio tramite il link per i feedback nella pagina Informazioni. Per domande su come vengono trattati i tuoi dati, vedi l'informativa sulla privacy, che spiega esattamente cosa viene conservato e cosa no.

Posso inviare a più dispositivi insieme?

Sì. Con "Invia a tutti", gli stessi file vanno in un solo passaggio a ogni dispositivo che ha OmniBeam aperto. Per un gruppo puoi anche creare una stanza pubblica: tutti entrano con lo stesso codice breve e possono inviarsi file a vicenda.
