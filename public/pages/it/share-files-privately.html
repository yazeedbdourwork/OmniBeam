Come condividere file in privato

Foto, scansioni di documenti, contratti: molto di ciò che inviamo è personale. Ecco cosa lo protegge davvero lungo il percorso, spiegato senza gergo.

Tre posti in cui un file può essere visto

  1. Sulla rete: chiunque sullo stesso Wi‑Fi pubblico. Qualsiasi sito con https protegge da questo.
  2. Sui server del servizio: l'azienda che trasporta o conserva il file. Da questo protegge solo la crittografia end-to-end.
  3. Sui dispositivi: il tuo e quello dell'altra persona. Questa parte dipende da te.

Cosa significa crittografia end-to-end

Il file viene chiuso a chiave sul tuo dispositivo e aperto solo sull'altro. Il servizio in mezzo passa dati rimescolati e non ha mai la chiave. Se i suoi server venissero violati, o qualcuno chiedesse all'azienda i tuoi file, non ci sarebbe niente di leggibile da consegnare.

Come lo gestisce OmniBeam

  • I trasferimenti diretti tra dispositivi usano WebRTC, che è sempre crittografato end-to-end.
  • Quando una connessione diretta non è possibile e il file passa dal nostro server, i due dispositivi concordano prima una chiave, quindi il server inoltra solo dati rimescolati e non salva nulla.
  • I link condivisi sono crittografati nel tuo browser prima del caricamento. La chiave è la parte del link dopo #, che i browser non inviano mai al server. I link scadono da soli.
  • Nessun account. I dispositivi associati vengono ricordati nel tuo browser.

Cinque abitudini utili

  • Per tutto ciò che è personale, preferisci i trasferimenti diretti o i servizi crittografati end-to-end.
  • Quando un link o una stanza ha una password, invia la password con un'app diversa da quella del link.
  • Scegli link che scadono, ed eliminali quando l'altra persona ha il file.
  • Controlla cosa condividi: le foto possono contenere il luogo in cui sono state scattate.
  • Accetta file solo da dispositivi che riconosci. In OmniBeam, segna come Attendibili solo i tuoi dispositivi.

Domande e risposte

Un link cloud è privato?

Un normale link cloud è conservato sui server del fornitore, e di solito il fornitore può leggere il file. Con la crittografia end-to-end, solo i dispositivi alle due estremità hanno la chiave, quindi nessuno in mezzo può aprire il file.

Come capisco se un servizio usa la crittografia end-to-end?

Cerca una dichiarazione chiara che i file sono crittografati sul tuo dispositivo prima di uscirne, e che la chiave non viene mai inviata al server. OmniBeam spiega proprio questo nella sua pagina sulla privacy.

Cos'altro posso fare per tenere privati i file?

Invia i link solo alle persone che ne hanno bisogno, scegli una scadenza breve, ed elimina un link una volta usato.

Inviare per email è privato?

L'email è comoda ma non è privata per impostazione predefinita: messaggi e allegati di solito restano sui server di posta di entrambe le parti. Per i file privati, trasferimenti o link crittografati end-to-end sono più sicuri.

Devo fidarmi di OmniBeam?

Molto meno che di un normale servizio cloud. I file sono crittografati sul tuo dispositivo, e le chiavi non raggiungono mai i server di OmniBeam, quindi nemmeno OmniBeam può aprirli.
