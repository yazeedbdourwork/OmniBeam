Inviare file da un Mac o un PC Linux al telefono con il clic destro

L'aiutante OmniBeam aggiunge Invia con OmniBeam al menu del clic destro del Finder su Mac e del file manager su Linux. Scegli i file, scegli il telefono e partono, senza aprire il browser sul computer.

Scarica per Mac e Linux (ZIP)

Installare su Mac

  1. Installa Node.js, che l'aiutante usa per inviare i file.
  2. Estrai il download e fai doppio clic su install-mac.command. Se macOS non lo apre, fai clic destro, scegli Apri e poi di nuovo Apri.
  3. Scrivi il codice di associazione del telefono quando richiesto (vedi sotto).

Poi fai clic destro sui file nel Finder e scegli Azioni rapide e Send with OmniBeam. Per il testo selezionato in qualsiasi app, fai clic destro e scegli Servizi e Send text with OmniBeam. Se mancano, attivali in Impostazioni di Sistema, Tastiera, Abbreviazioni da tastiera, Servizi.

Installare su Linux

  1. Installa Node.js 18 o più recente, per esempio sudo apt install nodejs, e zenity (o kdialog su KDE) per la scelta del dispositivo.
  2. Estrai il download, apri un terminale in quella cartella ed esegui sh install-linux.sh.
  3. Scrivi il codice di associazione del telefono quando richiesto.

Poi fai clic destro sui file e scegli Script e Send with OmniBeam in File, Nemo o Caja, oppure Send with OmniBeam direttamente nel menu in Dolphin e Thunar.

Associa il telefono una volta

  1. Sul telefono, apri omnibeam.site, tocca il pulsante del link e Crea un codice di associazione.
  2. Scrivi quel codice nel programma di installazione sul computer.
  3. Sul telefono, riapri la schermata di associazione e spunta Attendibile accanto al computer, così i suoi file arrivano senza chiedere.

Per ricevere, il telefono deve avere omnibeam.site aperto. I file passano dal server di OmniBeam, crittografati end-to-end, quindi il server non può leggerli. Per rimuovere di nuovo le voci del menu, esegui node omnibeam-send.js --uninstall.

Usi Chrome o Edge? L'estensione OmniBeam invia al telefono con un clic destro la pagina, un link, un'immagine o il testo selezionato, su Mac, Linux e Windows.

Domande e risposte

Il menu del clic destro funziona su ogni desktop Linux?

Funziona nei file manager più comuni: File (Nautilus), Nemo, Caja, Dolphin e Thunar. Su altri desktop puoi comunque aprire omnibeam.site nel browser e trascinarci i file.

Posso rimuovere le voci del menu in seguito?

Sì. Esegui node omnibeam-send.js --uninstall nella cartella dell'aiutante, e le voci spariscono dal menu del clic destro.

Invia a iPhone e Android?

Sì. Invia al telefono che hai associato con il codice, che sia un iPhone o un telefono Android, sullo stesso Wi‑Fi o sui dati mobili, purché omnibeam.site sia aperto sul telefono.

Perché l'aiutante ha bisogno di Node.js?

L'aiutante è un piccolo script che funziona con Node.js. Si associa al telefono una volta e poi invia i file che scegli senza aprire un browser sul computer, il che mantiene rapida l'azione del clic destro.

Posso inviare anche il testo selezionato?

Su Mac sì: seleziona il testo in qualsiasi app, fai clic destro e scegli Servizi, poi Send text with OmniBeam. Arriva sul telefono pronto da copiare.

I file sono crittografati?

Sì. Sono crittografati end-to-end sul computer, e il server li inoltra soltanto senza poterli leggere.
