Come trasferire file da Android a un Mac senza cavo

Mac e telefoni Android non condividono AirDrop, e Android File Transfer non c'è più. OmniBeam sposta foto, video e documenti tra loro via Wi‑Fi, direttamente nel browser, senza installare nulla.

Passaggi

  1. Sul Mac apri omnibeam.site in Safari, Chrome o Firefox.
  2. Sul telefono Android apri omnibeam.site in Chrome. Dopo un attimo ogni dispositivo mostra l'altro.
  3. Sul telefono tocca il Mac e scegli foto, video o qualsiasi file.
  4. Fai clic su Accetta sul Mac, poi Salva. Più file si possono salvare insieme come ZIP.

Dal Mac al telefono

Funziona in entrambe le direzioni: trascina i file dal Finder sulla scheda del telefono sul Mac, poi accetta sul telefono.

Ancora più veloce

  • Installa OmniBeam sul telefono (menu di Chrome, poi Installa app). Compare poi nel menu Condividi di Android: condividi dalla Galleria e scegli il Mac.
  • Sul Mac puoi aggiungere OmniBeam al menu del tasto destro nel Finder; vedi inviare file da Mac e Linux.
  • Non siete sullo stesso Wi‑Fi? Associa i due dispositivi una volta con un codice a 6 cifre e si troveranno ovunque.

Android File Transfer non viene più aggiornato, quindi molti utenti Mac non hanno un modo semplice per prendere i file da un telefono Android. Basta una scheda del browser per parte: sul Mac non c'è nulla da installare, e foto e video arrivano nella qualità originale.

Con OmniBeam puoi inviare file da Android a un Mac senza cavo, app o account.

Domande e risposte

Perché il mio Mac non vede il telefono Android via USB?

macOS non supporta senza software aggiuntivo la modalità di trasferimento file che i telefoni Android usano via USB, e AirDrop di Apple non include Android. Uno strumento basato sul browser evita entrambi i problemi.

Quale browser uso sul Mac?

Safari, Chrome, Edge e Firefox funzionano tutti. Apri omnibeam.site in uno di questi e tieni aperta la scheda mentre invii.

Dove vengono salvati i file sul Mac?

Di base nella cartella Download, o dove il tuo browser salva i download. Più file si possono salvare insieme come un unico ZIP.

Posso inviare cartelle?

Sì. Dal Mac puoi inviare un'intera cartella, e su Android puoi selezionare molti file insieme dalla galleria o dal file manager.

Funziona anche al contrario?

Sì, anche dal Mac al telefono Android.

Serve lo stesso Wi‑Fi?

Non per forza. Sullo stesso Wi‑Fi il Mac compare da solo. Se il telefono usa i dati mobili, associa i due dispositivi una volta con un codice a 6 cifre o il codice QR mostrato sul Mac.

È sicuro per i documenti?

Sì. Ogni trasferimento è crittografato end-to-end sul telefono e solo il Mac può decrittarlo. Lungo il percorso non resta nulla su un server.

Posso tenere OmniBeam pronto sul Mac?

Sì. Tieni la scheda fissata nel browser, o aggiungi l'estensione OmniBeam a Chrome, e il Mac sarà pronto a ricevere ogni volta che lo apri.
