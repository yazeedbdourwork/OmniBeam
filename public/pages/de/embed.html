Eine „Schick mir Dateien“-Box für deine Website oder deinen Blog

Lass Besucher, Kunden oder Schüler dir Dateien direkt über deine eigene Seite senden. Du fügst einen kurzen Code ein; die Dateien werden auf ihrem Gerät verschlüsselt und kommen in OmniBeam auf deinem an.

Schritte

  1. Öffne omnibeam.site auf dem Gerät, das die Dateien bekommen soll, und tippe im ⋯-Menü auf Dateien anfragen.
  2. Schreib, was du brauchst (optional), wähle unter „Link gültig für“ 1 Jahr (für eine Website) und tippe auf Anfrage-Link erstellen.
  3. Tippe auf Auf deine Website setzen und dann auf Code kopieren.
  4. Füge den Code in deine Seite ein: in WordPress in einen Block Individuelles HTML, in Blogger in ein Gadget HTML/JavaScript, in Wix in ein Element HTML einbetten, in Squarespace in einen Code-Block.

Besucher sehen eine kleine Box mit „Dateien auswählen“, einem optionalen Namensfeld und einem Senden-Knopf. Sie brauchen keine App und kein Konto. Die Dateien kommen auf deinem Gerät in Empfangene Dateien an; ist OmniBeam dort geschlossen, warten sie auf dem Server und kommen beim Öffnen an, mit einer Benachrichtigung, wenn du sie eingeschaltet hast.

WordPress: das kostenlose OmniBeam-Plugin

Auf WordPress geht es noch einfacher: Lade das OmniBeam-Plugin herunter (omnibeam-wordpress.zip), gehe in WordPress auf Plugins → Neues Plugin hinzufügen → Plugin hochladen, wähle das Zip aus und tippe auf Aktivieren. Füge deinen Code (oder nur seinen Link) unter Einstellungen → OmniBeam Box ein und setze dann den Block OmniBeam: Send me files auf eine beliebige Seite, oder den Shortcode [omnibeam_box]. Eine Box mit eigenem Link und eigener Höhe: [omnibeam_box url="https://omnibeam.site/embed/r/…" height="520"]. Das Plugin akzeptiert nur Boxen von omnibeam.site, und die Dateien gehen nie über deine WordPress-Seite.

So sieht der Code aus

<iframe src="https://omnibeam.site/embed/r/…?lang=de#…" title="Schick mir Dateien" style="width:100%;max-width:520px;height:470px;border:0" loading="lazy"></iframe>
<p><a href="https://omnibeam.site/de/">Bereitgestellt von OmniBeam</a> · kostenloses, Ende-zu-Ende-verschlüsseltes Teilen von Dateien</p>

Lass die Zeile „Bereitgestellt von OmniBeam“ stehen: Sie hält die Box kostenlos.

Ist das privat und sicher?

  • Jeder Upload wird im Browser des Besuchers verschlüsselt. Sein Schlüssel wird mit dem öffentlichen Schlüssel deines Geräts versiegelt, und nur dein Gerät hat den passenden privaten Schlüssel. Weder OmniBeam noch jemand, der den Code deiner Seite liest, kann die Dateien öffnen.
  • Der Code auf deiner Seite ist öffentlich. Wer ihn sieht, kann dir Dateien senden und den Text „Was brauchst du?“ und den Namen deines Geräts lesen. Schreib dort also nichts Privates hinein.
  • Nur dein Gerät kann die Uploads herunterladen, und jeder wird vom Server gelöscht, sobald es ihn hat. Nicht abgeholte Dateien werden nach 7 Tagen gelöscht.
  • Die üblichen Grenzen bleiben: eine Größengrenze pro Upload, eine Grenze pro Netzwerk und Stunde und höchstens 100 Uploads pro Tag und Box.
  • Lösche den Anfrage-Link jederzeit im selben Fenster, dann funktioniert die Box sofort nicht mehr.

Fragen und Antworten

Kostet das etwas?

Nein. Die Box ist kostenlos, ohne Konto, ohne Plugin und ohne Werbung.

Kann ich sie auf mehreren Seiten verwenden?

Ja. Füge denselben Code auf beliebig vielen Seiten ein; alle Uploads kommen auf demselben Gerät an. Erstelle einen eigenen Anfrage-Link, wenn du sie unterscheiden möchtest.

Warum funktioniert die Box nach einer Weile nicht mehr?

Jeder Anfrage-Link endet zu der Zeit, die du gewählt hast. Wähle für eine Website 1 Jahr und erstelle vor dem Ablauf einen neuen Link und Code.

Kann jemand meine Box nutzen, um mir Spam zu senden?

Jeder Besucher der Seite kann dir Dateien senden, wie bei einer E-Mail-Adresse. Dateien öffnen sich nie von selbst, Uploads sind pro Netzwerk und Tag begrenzt, und du kannst den Link löschen, um die Box abzuschalten.
