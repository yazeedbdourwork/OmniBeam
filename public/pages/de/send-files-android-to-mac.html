So überträgst du Dateien von Android auf einen Mac ohne Kabel

Macs und Android-Handys haben kein gemeinsames AirDrop, und Android File Transfer gibt es nicht mehr. OmniBeam bringt Fotos, Videos und Dokumente per WLAN von einem zum anderen, direkt im Browser und ohne Installation.

Schritte

  1. Öffne auf dem Mac omnibeam.site in Safari, Chrome oder Firefox.
  2. Öffne auf dem Android-Handy omnibeam.site in Chrome. Nach einem Moment sieht jedes Gerät das andere.
  3. Tippe auf dem Handy auf den Mac und wähle Fotos, Videos oder beliebige Dateien.
  4. Klicke auf dem Mac auf Annehmen und dann auf Speichern. Mehrere Dateien lassen sich auf einmal als ZIP speichern.

Vom Mac aufs Handy

Es geht in beide Richtungen: Zieh Dateien aus dem Finder auf die Karte des Handys und nimm sie auf dem Handy an.

Noch schneller

  • Installiere OmniBeam auf dem Handy (Chrome-Menü, dann App installieren). Dann erscheint es im Teilen-Menü von Android: aus der Galerie teilen und den Mac wählen.
  • Auf dem Mac kannst du OmniBeam ins Rechtsklick-Menü des Finders holen; siehe Dateien von Mac und Linux senden.
  • Nicht im selben WLAN? Kopple die beiden Geräte einmal mit einem 6‑stelligen Code, dann finden sie sich überall.

Android File Transfer wird nicht mehr aktualisiert, deshalb fehlt vielen Mac-Nutzern ein einfacher Weg, Dateien vom Android-Handy zu holen. Ein Browser-Tab auf jeder Seite reicht: Auf dem Mac musst du nichts installieren, und Fotos und Videos kommen in Originalqualität an.

So überträgst du Dateien von Android auf einen Mac ohne Kabel, ohne App und ohne Konto.

Fragen und Antworten

Warum erkennt mein Mac mein Android-Handy per USB nicht?

macOS unterstützt den Dateiübertragungsmodus, den Android-Handys per USB nutzen, nicht ohne Zusatzsoftware, und AirDrop schließt Android nicht ein. Ein Tool im Browser umgeht beide Probleme.

Welchen Browser nutze ich auf dem Mac?

Safari, Chrome, Edge und Firefox funktionieren alle. Öffne omnibeam.site in einem davon und lass den Tab beim Senden offen.

Wo werden die Dateien auf dem Mac gespeichert?

Standardmäßig im Ordner Downloads oder dort, wo dein Browser Downloads speichert. Mehrere Dateien lassen sich auch zusammen als ZIP speichern.

Kann ich Ordner senden?

Ja. Vom Mac kannst du einen ganzen Ordner senden, und auf Android wählst du viele Dateien auf einmal in der Galerie oder im Dateimanager.

Geht es auch umgekehrt?

Ja, auch vom Mac zum Android-Handy.

Brauche ich dasselbe WLAN?

Nicht unbedingt. Im selben WLAN erscheint der Mac automatisch. Nutzt das Handy mobile Daten, koppel beide Geräte einmal mit einem 6‑stelligen Code oder dem QR-Code auf dem Mac.

Ist das für Dokumente sicher?

Ja. Jede Übertragung wird auf deinem Handy Ende-zu-Ende verschlüsselt, und nur der Mac kann sie entschlüsseln. Unterwegs wird nichts auf einem Server gespeichert.

Kann ich OmniBeam auf dem Mac bereithalten?

Ja. Hefte den Tab im Browser an oder füge die OmniBeam-Erweiterung zu Chrome hinzu, dann ist der Mac empfangsbereit, sobald du ihn öffnest.
