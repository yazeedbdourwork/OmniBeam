Eine Datei per Link senden, verschlüsselt

Wenn die andere Person nicht gerade online ist oder du keine Geräte koppeln willst, teile die Dateien per Link. Sie werden auf deinem Gerät verschlüsselt, bevor sie es verlassen.

Schritte

  1. Öffne omnibeam.site und tippe im ⋯-Menü oben auf Dateien per Link teilen.
  2. Wähle, wie lange der Link gelten soll (1 Stunde, 1 Tag oder 3 Tage), und auf Wunsch „Nach dem ersten Download löschen“.
  3. Wähle die Dateien. Sie werden verschlüsselt und hochgeladen, und du bekommst einen Link und einen QR-Code.
  4. Schick den Link per WhatsApp, E-Mail oder einer anderen App. Wer ihn öffnet, kann die Dateien auf jedem Gerät herunterladen.

Wie privat ist das?

Die Dateien und ihre Namen werden in deinem Browser mit einem Zufallsschlüssel verschlüsselt. Der Schlüssel ist der Teil des Links nach „#“, den Browser nie an einen Server senden, also speichert OmniBeam nur Daten, die es nicht lesen kann. Behandle den Link wie die Datei selbst: Wer ihn hat, kann herunterladen.

Grenzen

  • Links haben eine Größengrenze, die beim Erstellen angezeigt wird.
  • Dateien werden automatisch gelöscht, wenn der Link abläuft. Du kannst einen Link auch jederzeit im selben Fenster selbst löschen.
  • Sehr große Dateien sendest du besser direkt an ein Gerät: Direkte Übertragungen haben keine Größengrenze.

Ein Link ist praktisch, wenn die andere Person nicht gleichzeitig online ist. Die Datei wird verschlüsselt, bevor sie deinen Browser verlässt, deshalb können sie nur die Leute öffnen, denen du den Link gibst.

Eine große Datei per Link zu senden ist kostenlos, und sie wird schon auf deinem Gerät verschlüsselt.

Fragen und Antworten

Wann ist ein Link besser als eine direkte Übertragung?

Nimm einen Link, wenn die andere Person nicht gleichzeitig online ist, wenn du dieselbe Datei an mehrere Personen senden willst oder wenn du keine Geräte koppeln kannst. Für sehr große Dateien an deine eigenen Geräte ist die direkte Übertragung schneller und ohne Größenbeschränkung.

Sehe ich, ob die Datei heruntergeladen wurde?

Du kannst „Nach dem ersten Download löschen“ wählen, dann funktioniert der Link nach einmaliger Nutzung nicht mehr. Du kannst den Link auch jederzeit selbst im selben Fenster löschen.

Braucht die andere Person OmniBeam?

Nein. Sie öffnet den Link einfach in einem Browser auf einem beliebigen Gerät und lädt die Dateien herunter. Nichts muss installiert werden, kein Konto ist nötig.

Kann OmniBeam meine Dateien sehen?

Nein. Die Dateien werden vor dem Hochladen in deinem Browser verschlüsselt, und der Schlüssel steht im Teil des Links nach „#“, der nie an den Server gesendet wird.

Wie lange ist ein Link verfügbar?

Das wählst du beim Erstellen: 1 Stunde, 1 Tag oder 3 Tage. Danach werden die Dateien automatisch gelöscht und der Link funktioniert nicht mehr.

Kann ich mehrere Dateien mit einem Link senden?

Ja. Wähle beliebig viele Dateien; wer den Link öffnet, sieht alle und kann sie einzeln oder zusammen herunterladen.

Kann ich den Link als QR-Code teilen?

Ja. Zu jedem Link gibt es einen QR-Code, den jemand neben dir mit der Handykamera scannen und sofort herunterladen kann.
