Dateien per Rechtsklick vom Mac oder Linux-PC aufs Handy senden

Der OmniBeam-Helfer fügt Send with OmniBeam zum Rechtsklick-Menü des Finders auf dem Mac und des Dateimanagers unter Linux hinzu. Wähle Dateien und dein Handy, und sie gehen hinüber, ohne den Browser am Computer zu öffnen.

Für Mac und Linux herunterladen (ZIP)

Auf dem Mac installieren

  1. Installiere Node.js, mit dem der Helfer Dateien sendet.
  2. Entpacke den Download und doppelklicke auf install-mac.command. Öffnet macOS es nicht, klicke mit rechts darauf, wähle Öffnen und dann noch einmal Öffnen.
  3. Tippe den Kopplungscode von deinem Handy ein, wenn danach gefragt wird (siehe unten).

Klicke dann im Finder mit rechts auf Dateien und wähle Schnellaktionen und Send with OmniBeam. Für markierten Text in jeder App klicke mit rechts und wähle Dienste und Send text with OmniBeam. Fehlen sie, schalte sie in Systemeinstellungen, Tastatur, Tastaturkurzbefehle, Dienste ein.

Unter Linux installieren

  1. Installiere Node.js 18 oder neuer, zum Beispiel sudo apt install nodejs, und zenity (oder kdialog unter KDE) für die Geräteauswahl.
  2. Entpacke den Download, öffne in diesem Ordner ein Terminal und führe sh install-linux.sh aus.
  3. Tippe den Kopplungscode von deinem Handy ein, wenn danach gefragt wird.

Klicke dann mit rechts auf Dateien und wähle Skripte und Send with OmniBeam in Dateien, Nemo oder Caja, oder direkt Send with OmniBeam im Menü von Dolphin und Thunar.

Dein Handy einmal koppeln

  1. Öffne auf dem Handy omnibeam.site, tippe auf die Link-Taste und auf Kopplungscode erstellen.
  2. Tippe diesen Code in das Installationsprogramm am Computer ein.
  3. Öffne auf dem Handy das Kopplungsfenster erneut und hake Vertraut beim Computer an, damit seine Dateien ohne Nachfrage ankommen.

Das Handy braucht omnibeam.site geöffnet, um zu empfangen. Dateien laufen über den OmniBeam-Server, Ende-zu-Ende verschlüsselt, sodass der Server sie nicht lesen kann. Um die Menüeinträge wieder zu entfernen, führe node omnibeam-send.js --uninstall aus.

Du nutzt Chrome oder Edge? Die OmniBeam-Erweiterung sendet die Seite, einen Link, ein Bild oder markierten Text per Rechtsklick an dein Handy, auf Mac, Linux und Windows.

Fragen und Antworten

Funktioniert das Rechtsklick-Menü auf jedem Linux-Desktop?

Es funktioniert in den gängigen Dateimanagern: Dateien (Nautilus), Nemo, Caja, Dolphin und Thunar. Auf anderen Desktops kannst du omnibeam.site im Browser öffnen und die Dateien hineinziehen.

Kann ich die Menüeinträge später entfernen?

Ja. Führe node omnibeam-send.js --uninstall im Ordner des Helfers aus, dann verschwinden die Einträge aus dem Rechtsklick-Menü.

Sendet es an iPhone und Android?

Ja. Es sendet an das Handy, das du mit dem Code gekoppelt hast, ob iPhone oder Android, im selben WLAN oder mit mobilen Daten, solange omnibeam.site auf dem Handy offen ist.

Warum braucht der Helfer Node.js?

Der Helfer ist ein kleines Skript, das mit Node.js läuft. Er koppelt sich einmal mit deinem Handy und sendet dann die gewählten Dateien vom Mac oder Linux-PC, ohne einen Browser auf dem Computer zu öffnen, damit der Rechtsklick schnell bleibt.

Kann ich auch markierten Text senden?

Auf dem Mac ja: Markiere Text in einer beliebigen App, klicke mit rechts und wähle Dienste und dann Send text with OmniBeam. Er kommt aufs Handy und lässt sich kopieren.

Sind die Dateien verschlüsselt?

Ja. Sie werden auf dem Computer Ende-zu-Ende verschlüsselt, und der Server leitet sie nur weiter, ohne sie lesen zu können.
