So überträgst du Dateien zwischen zwei Computern ohne USB-Stick

Auf einen Stick kopieren, sich selbst mailen oder in die Cloud laden dauert doppelt so lange wie nötig. OmniBeam schickt Dateien direkt von einem Computer zum anderen – Windows, Mac, Linux oder Chromebook, in jeder Kombination.

Schritte

  1. Öffne omnibeam.site in einem Browser auf beiden Computern.
  2. Im selben Netz erscheinen sie automatisch. Sonst klickst du auf einem auf Koppeln und gibst den 6‑stelligen Code auf dem anderen ein.
  3. Zieh Dateien oder ganze Ordner auf die Karte des anderen Computers, oder klick darauf und wähle Dateien.
  4. Auf dem anderen Computer annehmen. Ordner behalten ihre Struktur und lassen sich als ein ZIP speichern.

Warum es schnell geht

  • Die Dateien gehen direkt über dein Netzwerk zwischen den beiden Computern, nicht über einen Cloud-Server.
  • Es gibt kein Größenlimit, und große Übertragungen laufen von selbst weiter, wenn die Verbindung abbricht.
  • Alles ist Ende-zu-Ende-verschlüsselt, und nichts wird irgendwo gespeichert.

Machst du das öfter?

Unter Windows holst du dir die OmniBeam-App aus dem Microsoft Store, um aus ihrem Fenster oder dem Windows-Menü Teilen zu senden (so geht's), und mit der Chrome-Erweiterung sendest du die Seite oder den Link, den du gerade ansiehst, mit einem Klick.

Das klappt zwischen Windows, Mac, Linux und Chromebook in jeder Kombination, denn es braucht nur einen aktuellen Browser. Im selben Netz finden sich die Computer von selbst; an verschiedenen Orten nimmst du einen Kopplungscode.

So überträgst du Dateien zwischen zwei Computern ohne USB-Stick: Mit OmniBeam kannst du sie direkt übertragen.

Fragen und Antworten

Funktioniert es zwischen Windows und Mac?

Ja. OmniBeam läuft auf beiden im Browser, du kannst also von einem Windows-PC an einen Mac, von einem Mac an ein Chromebook oder zwischen beliebigen zwei Computern senden.

Kann ich einen ganzen Ordner verschieben?

Ja. Zieh den Ordner in OmniBeam auf den anderen Computer. Auf der Empfängerseite lassen sich die Dateien zusammen als ZIP speichern, damit die Ordnerstruktur erhalten bleibt.

Und sehr große Dateien?

Direkte Übertragungen haben keine Größenbeschränkung, und bricht die Verbindung ab, geht die Übertragung dort weiter, wo sie stand. Für eine ganze Festplatte ist eine externe Platte trotzdem schneller.

Müssen beide Computer im selben Netz sein?

Nein. Im selben Netz erscheinen sie automatisch; sonst koppel sie einmal mit einem Code, danach finden sie sich.

Ist es in einem geteilten oder öffentlichen Netz sicher?

Ja. Jede Übertragung wird auf dem sendenden Computer Ende-zu-Ende verschlüsselt und nur auf dem empfangenden entschlüsselt, andere im selben Netz können die Dateien also nicht lesen.

Kann ich auch Texte oder Links kopieren?

Ja. Füge Text in OmniBeam ein und sende ihn, oder schalte die Zwischenablage-Synchronisierung ein, um kopierten Text mit einem Klick an den anderen Computer zu senden.

Brauche ich auf beiden Computern ein Konto?

Nein. Kein Konto, keine Anmeldung, nichts zu installieren. Öffne die Seite auf beiden Computern und sende los.
