Dateien privat teilen

Fotos, Ausweis-Scans, Verträge: Vieles, was wir senden, ist persönlich. Hier steht ohne Fachchinesisch, was es unterwegs wirklich schützt.

Drei Stellen, an denen eine Datei sichtbar sein kann

  1. Im Netzwerk: jeder im selben öffentlichen WLAN. Jede Seite mit https schützt davor.
  2. Auf den Servern des Dienstes: die Firma, die die Datei transportiert oder speichert. Davor schützt nur Ende-zu-Ende-Verschlüsselung.
  3. Auf den Geräten: deinem und dem der anderen Person. Das liegt bei dir.

Was Ende-zu-Ende-Verschlüsselung bedeutet

Die Datei wird auf deinem Gerät verschlossen und erst auf dem anderen wieder geöffnet. Der Dienst dazwischen reicht nur unlesbare Daten weiter und hat nie den Schlüssel. Würden seine Server gehackt oder würde jemand die Firma nach deinen Dateien fragen, gäbe es nichts Lesbares herauszugeben.

Wie OmniBeam das löst

  • Direkte Übertragungen zwischen Geräten nutzen WebRTC, das immer Ende-zu-Ende verschlüsselt ist.
  • Ist keine direkte Verbindung möglich und geht die Datei über unseren Server, vereinbaren die beiden Geräte zuerst einen Schlüssel, sodass der Server nur unlesbare Daten weiterleitet und nichts speichert.
  • Geteilte Links werden vor dem Hochladen in deinem Browser verschlüsselt. Der Schlüssel ist der Teil des Links nach #, den Browser nie an den Server senden. Links laufen von selbst ab.
  • Keine Konten. Gekoppelte Geräte werden in deinem eigenen Browser gespeichert.

Fünf hilfreiche Gewohnheiten

  • Nutze für alles Persönliche direkte Übertragungen oder Ende-zu-Ende-verschlüsselte Dienste.
  • Hat ein Link oder Raum ein Passwort, schick das Passwort über eine andere App als den Link.
  • Wähle Links, die ablaufen, und lösche sie, wenn die andere Person die Datei hat.
  • Prüfe, was du teilst: Fotos können den Aufnahmeort enthalten.
  • Nimm Dateien nur von Geräten an, die du kennst. Markiere in OmniBeam nur deine eigenen Geräte als Vertraut.

Ein schneller Test für jeden Dienst zum Teilen von Dateien: Könnte er deine Dateien lesen, wenn er wollte? Werden die Dateien auf deinem Gerät verschlüsselt, bevor sie es verlassen, sieht der Dienst nur unlesbare Daten. So verschlüsselt OmniBeam jede Übertragung.

Dateien privat teilen heißt: Ende-zu-Ende-Verschlüsselung, wie oben erklärt.

Fragen und Antworten

Ist ein Cloud-Link privat?

Ein normaler Cloud-Link liegt auf den Servern des Anbieters, der die Datei meist lesen kann. Bei Ende-zu-Ende-Verschlüsselung haben nur die Geräte an beiden Enden den Schlüssel, und niemand dazwischen kann die Datei öffnen.

Wie erkenne ich Ende-zu-Ende-Verschlüsselung?

Achte auf eine klare Aussage, dass Dateien auf deinem Gerät verschlüsselt werden, bevor sie es verlassen, und dass der Schlüssel nie an den Server geht. OmniBeam erklärt genau das in seiner Datenschutzerklärung.

Was kann ich noch tun, um Dateien privat zu halten?

Schick Links nur an die Personen, die sie brauchen, wähle eine kurze Gültigkeit und lösche einen Link, sobald er genutzt wurde.

Ist Senden per E-Mail privat?

E-Mail ist bequem, aber nicht von Haus aus privat: Nachrichten und Anhänge liegen meist auf den Mailservern beider Seiten. Für private Dateien sind Ende-zu-Ende-verschlüsselte Übertragungen oder Links sicherer.

Muss ich OmniBeam vertrauen?

Viel weniger als einem normalen Cloud-Dienst. Die Dateien werden auf deinem Gerät verschlüsselt, und die Schlüssel erreichen nie die Server von OmniBeam, sodass selbst OmniBeam sie nicht öffnen kann.
