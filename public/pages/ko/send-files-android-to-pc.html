USB 케이블 없이 Android에서 PC로 파일 옮기는 방법

USB 케이블, 드라이버, "파일 전송" 모드는 번거롭습니다. OmniBeam으로 어떤 Android 휴대폰에서든 Windows PC, Mac, Chromebook으로 Wi‑Fi를 통해 Chrome에서 바로 파일을 보내세요.

단계

  1. PC와 휴대폰의 Chrome에서 omnibeam.site를 여세요.
  2. 서로가 보일 때까지 잠시 기다리세요. 안 나타나나요? 페어링 코드를 쓰세요. PC에서 링크 버튼을 누르고 코드를 만든 뒤 휴대폰에 입력하세요.
  3. 휴대폰에서 PC를 탭하고 사진, 동영상, 아무 파일이나 고르세요.
  4. PC에서 받고 저장하세요. 여러 파일은 ZIP 하나로 함께 저장할 수 있습니다.

더 빠르게: Android 공유 메뉴

OmniBeam을 홈 화면에 추가하세요(Chrome 메뉴에서 홈 화면에 추가 또는 앱 설치). 그러면 갤러리, 파일 등 대부분의 앱 공유 메뉴에 OmniBeam이 나타납니다. 사진을 고르고 공유를 탭한 뒤 OmniBeam을 고르고 PC를 선택하세요.

큰 동영상을 위한 팁

  • 전송이 끝날 때까지 휴대폰 화면을 켜 두고 페이지를 열어 두세요.
  • 연결이 느리면 설정(위쪽 ⋯ 메뉴)에서 사진과 동영상 작게를 고르세요. 보내기 전에 사진은 2048픽셀로 줄이고 동영상은 720p로 다시 인코딩합니다.
  • 같은 Wi‑Fi에서의 전송이 가장 빠릅니다. 진행 카드의 경로가 "인터넷"이나 "서버"라면 같은 Wi‑Fi에서 느린 전송을 고치는 방법을 보세요.
  • Android 휴대폰에서 자주 보낸다면 무료 Windows용 OmniBeam 앱을 설치하고, 파일이 올 때 시작 메뉴에서 여세요.

휴대폰이 모바일 데이터를 쓸 때처럼 휴대폰과 PC가 다른 네트워크에 있어도 됩니다. 코드로 페어링하면 파일이 암호화된 연결로 이동합니다. 먼저 클라우드 폴더에 올리지 않으므로 큰 동영상도 바로 도착하기 시작합니다.

OmniBeam은 USB 케이블 없이 Wi‑Fi나 모바일 데이터로 Android에서 PC로 파일을 보냅니다.

자주 묻는 질문

PC에 무언가 설치해야 하나요?

아니요. PC의 아무 브라우저에서나 omnibeam.site를 여세요. 파일을 자주 보낸다면 Microsoft Store의 무료 OmniBeam 앱이 백그라운드에서 준비해 둡니다.

Android 갤러리에서 바로 공유할 수 있나요?

네. 브라우저 메뉴에서 OmniBeam을 앱으로 설치하면 Android 공유 메뉴에 나타나므로 갤러리에서 바로 사진을 보낼 수 있습니다.

PC는 유선 랜이고 휴대폰은 Wi‑Fi라면요?

둘 다 같은 집 네트워크에 있으면 괜찮습니다. 다른 네트워크라면 코드로 한 번 페어링하세요.

USB 케이블보다 빠른가요?

좋은 Wi‑Fi에서는 비슷하고, 사진 몇 장이라면 더 빠릅니다. 케이블을 찾거나 휴대폰의 파일 전송 모드를 켤 필요가 없기 때문입니다.

Windows에서는 파일이 어디에 저장되나요?

다운로드 폴더나 브라우저가 다운로드를 저장하는 곳에 저장됩니다. 여러 파일은 ZIP 하나로 함께 저장할 수 있습니다.

PC에서 휴대폰으로 파일을 다시 보낼 수 있나요?

네. PC의 OmniBeam에서 휴대폰을 클릭하고 파일을 고른 뒤 휴대폰에서 받으세요. 예전 OmniBeam 트레이 앱으로는 파일 탐색기에서 파일을 오른쪽 클릭해 휴대폰으로 보낼 수도 있습니다.
