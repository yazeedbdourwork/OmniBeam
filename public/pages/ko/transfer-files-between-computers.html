USB 메모리 없이 두 컴퓨터 사이에서 파일 옮기는 방법

USB 메모리에 복사하기, 나에게 메일 보내기, 클라우드에 올리기는 모두 필요한 시간의 두 배가 걸립니다. OmniBeam은 Windows, Mac, Linux, Chromebook 어떤 조합이든 한 컴퓨터에서 다른 컴퓨터로 파일을 바로 보냅니다.

단계

  1. 두 컴퓨터의 브라우저에서 omnibeam.site를 여세요.
  2. 같은 네트워크라면 자동으로 나타납니다. 그렇지 않으면 한 컴퓨터에서 페어링 버튼을 클릭하고 다른 컴퓨터에서 6자리 코드를 입력하세요.
  3. 파일이나 폴더 전체를 다른 컴퓨터의 카드로 끌어다 놓거나, 카드를 클릭해 파일을 고르세요.
  4. 다른 컴퓨터에서 받기를 누르세요. 폴더는 구조가 유지되며 ZIP 하나로 저장할 수 있습니다.

빠른 이유

  • 파일은 클라우드 서버를 거치지 않고 네트워크에서 두 컴퓨터 사이로 직접 갑니다.
  • 크기 제한이 없고, 연결이 끊겨도 큰 전송이 저절로 이어집니다.
  • 모든 것이 종단 간 암호화되며 어디에도 저장되지 않습니다.

자주 하시나요?

Windows에서는 Microsoft Store OmniBeam 앱을 받아 전용 창이나 Windows 공유 메뉴에서 보내세요(작동 방식). Chrome 확장 프로그램을 추가하면 보고 있는 페이지나 링크를 클릭 한 번에 보낼 수 있습니다.

최신 브라우저만 있으면 되므로 Windows, Mac, Linux, Chromebook 어떤 조합에서도 작동합니다. 같은 네트워크에서는 컴퓨터들이 서로를 저절로 찾고, 다른 장소에서는 페어링 코드를 쓰세요.

USB 메모리, 케이블, 클라우드 계정 없이 두 컴퓨터 사이에서 파일을 옮길 수 있습니다.

자주 묻는 질문

Windows와 Mac 사이에서도 되나요?

네. OmniBeam은 두 브라우저에서 모두 작동하므로 Windows PC에서 Mac으로, Mac에서 Chromebook으로, 어떤 두 컴퓨터 사이에서든 보낼 수 있습니다.

폴더 전체를 옮길 수 있나요?

네. OmniBeam에서 폴더를 다른 컴퓨터로 끌어다 놓으세요. 받는 쪽에서는 폴더 구조를 유지하도록 파일을 ZIP 하나로 함께 저장할 수 있습니다.

아주 큰 파일은요?

직접 전송에는 크기 제한이 없고, 연결이 끊기면 멈춘 곳부터 이어집니다. 드라이브 전체라면 외장 디스크가 여전히 더 빠릅니다.

두 컴퓨터가 같은 네트워크에 있어야 하나요?

아니요. 같은 네트워크라면 자동으로 나타나고, 그렇지 않으면 코드로 한 번 페어링하면 그 뒤로 서로를 찾습니다.

공용 네트워크에서도 안전한가요?

네. 모든 전송은 보내는 컴퓨터에서 종단 간 암호화되고 받는 컴퓨터에서만 복호화되므로, 같은 네트워크의 다른 사람은 파일을 읽을 수 없습니다.

컴퓨터 사이에서 텍스트나 링크도 복사할 수 있나요?

네. 텍스트를 OmniBeam에 붙여넣어 보내거나, 클립보드 동기화를 켜면 한 컴퓨터에서 복사한 텍스트를 클릭 한 번에 다른 컴퓨터로 보낼 수 있습니다.

두 컴퓨터 모두 계정이 필요한가요?

아니요. 계정도, 가입도, 설치할 것도 없습니다. 두 컴퓨터에서 페이지를 열고 보내기 시작하세요.
