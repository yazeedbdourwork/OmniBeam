케이블 없이 Android에서 Mac으로 파일 옮기는 방법

Mac과 Android 휴대폰은 AirDrop을 함께 쓸 수 없고, Android File Transfer도 사라졌습니다. OmniBeam은 사진, 동영상, 문서를 Wi‑Fi로 브라우저에서 바로 옮기며, 설치할 것이 없습니다.

단계

  1. Mac의 Safari, Chrome, Firefox에서 omnibeam.site를 여세요.
  2. Android 휴대폰의 Chrome에서 omnibeam.site를 여세요. 잠시 후 두 기기가 서로를 표시합니다.
  3. 휴대폰에서 Mac을 탭하고 사진, 동영상, 아무 파일이나 고르세요.
  4. Mac에서 받기를 클릭한 다음 저장하세요. 여러 파일은 ZIP으로 한 번에 저장할 수 있습니다.

Mac에서 휴대폰으로

양방향으로 됩니다. Finder에서 파일을 Mac에 보이는 휴대폰 카드로 끌어다 놓고, 휴대폰에서 받으세요.

더 빠르게 쓰기

  • 휴대폰에 OmniBeam을 설치하세요(Chrome 메뉴 → 앱 설치). 그러면 Android 공유 메뉴에 나타나므로 갤러리에서 공유하고 Mac을 고르면 됩니다.
  • Mac에서는 Finder의 오른쪽 클릭 메뉴에 OmniBeam을 추가할 수 있습니다. Mac과 Linux에서 파일 보내기를 참고하세요.
  • 같은 Wi‑Fi가 아닌가요? 6자리 코드로 두 기기를 한 번 페어링하면 어디서든 서로 찾습니다.

Android File Transfer는 더 이상 업데이트되지 않아, 많은 Mac 사용자가 Android 휴대폰에서 파일을 꺼낼 쉬운 방법이 없습니다. 양쪽에 브라우저 탭 하나씩이면 충분합니다. Mac에 설치할 것이 없고, 사진과 동영상은 원본 화질로 도착합니다.

OmniBeam으로 케이블, 앱, 계정 없이 Android에서 Mac으로 파일을 보낼 수 있습니다.

자주 묻는 질문

왜 Mac이 USB로 Android 휴대폰을 인식하지 못하나요?

macOS는 추가 소프트웨어 없이 Android 휴대폰이 USB로 쓰는 파일 전송 모드를 지원하지 않으며, Apple의 AirDrop은 Android를 포함하지 않습니다. 브라우저 기반 도구는 두 문제를 모두 피합니다.

Mac에서는 어떤 브라우저를 써야 하나요?

Safari, Chrome, Edge, Firefox 모두 됩니다. 아무 브라우저에서 omnibeam.site를 열고 보내는 동안 탭을 열어 두세요.

Mac에서 파일은 어디에 저장되나요?

기본적으로 다운로드 폴더, 또는 브라우저에 설정된 다운로드 위치에 저장됩니다. 여러 파일을 ZIP 하나로 묶어 저장할 수도 있습니다.

폴더도 보낼 수 있나요?

네. Mac에서는 폴더 전체를 보낼 수 있고, Android에서는 갤러리나 파일 관리자에서 많은 파일을 한 번에 고를 수 있습니다.

반대로도 되나요?

네, Mac에서 Android 휴대폰으로도 됩니다.

같은 Wi‑Fi가 필요한가요?

꼭 그렇지는 않습니다. 같은 Wi‑Fi라면 Mac이 자동으로 나타납니다. 휴대폰이 모바일 데이터라면 Mac에 표시된 6자리 코드나 QR 코드로 두 기기를 한 번 페어링하세요.

문서를 보내도 안전한가요?

네. 모든 전송은 휴대폰에서 종단 간 암호화되며 Mac만 복호화할 수 있습니다. 도중에 서버에 아무것도 저장되지 않습니다.

Mac에서 OmniBeam을 늘 준비해 둘 수 있나요?

네. 브라우저에서 탭을 고정하거나 Chrome에 OmniBeam 확장 프로그램을 추가하면, Mac을 열 때마다 바로 받을 수 있습니다.
