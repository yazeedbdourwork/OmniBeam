웹사이트나 블로그용 "파일을 보내 주세요" 상자

방문자, 고객, 학생이 내 페이지에서 바로 파일을 보낼 수 있게 하세요. 짧은 코드 하나만 붙여넣으면, 파일은 상대 기기에서 암호화되어 내 기기의 OmniBeam에 도착합니다.

단계

  1. 파일을 받을 기기에서 omnibeam.site를 열고 ⋯ 메뉴에서 파일 요청을 탭하세요.
  2. 필요한 것을 적고(선택), "링크 유효 기간"에서 1년(웹사이트용)을 고른 뒤 요청 링크 만들기를 탭하세요.
  3. 웹사이트에 넣기를 탭하고 코드 복사를 탭하세요.
  4. 코드를 페이지에 붙여넣으세요. WordPress에서는 사용자 정의 HTML 블록, Blogger에서는 HTML/JavaScript 가젯, Wix에서는 Embed HTML 요소, Squarespace에서는 Code 블록입니다.

방문자에게는 "파일 선택", 선택 입력인 이름 칸, 보내기 버튼이 있는 작은 상자가 보입니다. 앱도 계정도 필요 없습니다. 파일은 내 기기의 "받은 파일"로 도착합니다. 그곳에서 OmniBeam이 닫혀 있으면 파일은 서버에서 기다렸다가 열 때 도착하며, 알림을 켜 두었다면 알림도 옵니다.

WordPress: 무료 OmniBeam 플러그인

WordPress에서는 더 쉬운 방법이 있습니다. OmniBeam 플러그인(omnibeam-wordpress.zip)을 내려받고, WordPress에서 플러그인 → 새로 추가 → 플러그인 업로드로 가서 zip을 고른 뒤 활성화를 탭하세요. 설정 → OmniBeam Box에 코드(또는 링크만)를 붙여넣고, 원하는 페이지에 OmniBeam: Send me files 블록이나 단축 코드 [omnibeam_box]를 추가하세요. 링크와 높이를 따로 정한 상자: [omnibeam_box url="https://omnibeam.site/embed/r/…" height="520"]. 플러그인은 omnibeam.site의 상자만 받아들이며, 파일은 절대 내 WordPress 사이트를 거치지 않습니다.

코드 모양

<iframe src="https://omnibeam.site/embed/r/…?lang=ko#…" title="파일을 보내 주세요" style="width:100%;max-width:520px;height:470px;border:0" loading="lazy"></iframe>
<p><a href="https://omnibeam.site/ko/">Powered by OmniBeam</a> · 무료, 종단 간 암호화 파일 공유</p>

"Powered by OmniBeam" 줄은 남겨 두세요. 상자가 무료로 유지되는 이유입니다.

비공개이고 안전한가요?

  • 모든 업로드는 방문자의 브라우저에서 암호화됩니다. 그 키는 내 기기의 공개 키로 봉인되고, 짝이 되는 개인 키는 내 기기에만 있으므로 OmniBeam도, 내 페이지 코드를 읽는 누구도 파일을 열 수 없습니다.
  • 페이지의 코드는 공개됩니다. 그것을 본 사람은 누구나 나에게 파일을 보낼 수 있고 "필요한 것" 텍스트와 내 기기 이름을 읽을 수 있으니, 개인적인 내용은 쓰지 마세요.
  • 업로드는 내 기기만 내려받을 수 있으며, 내 기기가 받는 즉시 서버에서 삭제됩니다. 찾아가지 않은 파일은 7일 뒤 삭제됩니다.
  • 일반적인 제한은 그대로입니다. 업로드당 크기 제한, 네트워크당 시간당 제한, 상자당 하루 최대 100건의 업로드입니다.
  • 같은 창에서 언제든 요청 링크를 삭제하면 상자는 즉시 작동을 멈춥니다.

자주 묻는 질문

비용이 드나요?

아니요. 상자는 무료이며 계정도 광고도 없습니다. WordPress 플러그인도 무료입니다.

여러 페이지에서 쓸 수 있나요?

네. 원하는 모든 페이지에 같은 코드를 붙여넣으세요. 모든 업로드가 같은 기기로 옵니다. 구분하고 싶다면 별도의 요청 링크를 만드세요.

얼마 뒤에 상자가 작동을 멈추는 이유는?

모든 요청 링크는 고른 시간에 끝납니다. 웹사이트에는 1년을 고르고, 끝나기 전에 새 링크와 코드를 만드세요.

누군가 내 상자로 스팸을 보낼 수 있나요?

이메일 주소처럼, 페이지를 방문한 누구나 파일을 보낼 수 있습니다. 파일은 절대 저절로 열리지 않고, 업로드는 네트워크별·하루별로 제한되며, 링크를 삭제해 상자를 끌 수 있습니다.
