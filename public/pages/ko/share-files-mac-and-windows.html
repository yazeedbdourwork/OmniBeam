USB 메모리 없이 Mac과 Windows PC 사이에서 파일 공유하는 방법

macOS와 Windows 사이의 네트워크 공유는 SMB 설정, 사용자 이름, 방화벽을 뜻합니다. USB 메모리는 방을 가로질러 걸어가야 하고요. OmniBeam은 Mac과 Windows PC 사이에서 브라우저로 클릭 몇 번이면 파일을 옮깁니다.

단계

  1. Mac에서는 Safari나 Chrome, PC에서는 Edge나 Chrome으로 omnibeam.site를 여세요.
  2. 같은 네트워크라면 서로의 컴퓨터가 보입니다. 그렇지 않으면 링크 버튼의 코드로 한 번 페어링하세요.
  3. 파일이나 폴더 전체를 다른 컴퓨터로 끌어다 놓거나, 클릭해서 파일을 고르세요.
  4. 다른 컴퓨터에서 받기를 누르세요. 여러 파일은 ZIP 하나로 저장할 수 있고, 폴더는 구조가 유지됩니다.

파일 공유 설정이 필요 없습니다

Mac과 Windows 사이의 기존 파일 공유에는 같은 작업 그룹, 다른 컴퓨터의 계정, 올바른 방화벽 규칙이 필요합니다. OmniBeam은 각 컴퓨터에 브라우저만 있으면 됩니다. 두 컴퓨터 사이의 연결은 직접이고 암호화되어 있어 공용 사무실 네트워크에서도 더 안전합니다.

더 빠르게 쓰기

  • Windows에서는 Microsoft Store에서 무료 OmniBeam 앱을 설치하고 시작 메뉴에서 여세요.
  • 두 컴퓨터를 페어링하고 자동 수락을 켜면, 내 Mac에서 보낸 파일이 클릭 없이 PC에 도착합니다.
  • 설정에서 클립보드 동기화를 켜면 한 컴퓨터에서 복사한 텍스트를 다른 컴퓨터에 붙여넣을 수 있습니다.
  • PC에서 폴더 자동 보내기를 쓰면 스크린샷처럼 폴더에 새로 생긴 파일이 저절로 보내집니다.

MacBook과 Windows 노트북, iMac과 게이밍 PC, 페어링한 뒤라면 다른 네트워크에 있는 회사 노트북과 집 컴퓨터 등 어떤 조합에서도 작동합니다.

OmniBeam으로 USB 메모리, 클라우드 폴더, 네트워크 설정 없이 Wi‑Fi로 Mac과 Windows 사이에서 파일을 공유할 수 있습니다.

자주 묻는 질문

큰 동영상 파일도 되나요?

네. 직접 보내기에는 크기 제한이 없고, 1GB 이상의 파일은 도착하면서 조각별로 확인됩니다.

폴더 전체를 보낼 수 있나요?

네. 폴더를 다른 컴퓨터로 끌어다 놓으세요. 하위 폴더와 함께 도착하며 ZIP 하나로 저장할 수 있습니다.

컴퓨터들이 같은 네트워크에 있어야 하나요?

한 번 페어링하면 그럴 필요 없습니다. 페어링한 컴퓨터는 집의 노트북과 사무실의 PC처럼 어떤 네트워크에서든 서로를 찾습니다.

iCloud Drive나 OneDrive보다 빠른가요?

일회성 전송이라면 대개 그렇습니다. 파일을 클라우드에 올렸다가 다시 내려받지 않고 컴퓨터 사이에서 직접 보내기 때문입니다.

Linux에서도 되나요?

네. Linux와 Chromebook을 포함해 최신 브라우저가 있는 컴퓨터라면 무엇이든 참여할 수 있습니다.

받은 파일은 어디에 저장되나요?

각 컴퓨터 브라우저의 다운로드 폴더에 저장됩니다. Mac에서는 Finder의 다운로드 폴더, Windows에서는 파일 탐색기의 다운로드 폴더입니다.

사무실 네트워크에서도 연결이 안전한가요?

네. 두 컴퓨터는 암호화된 연결을 쓰며, 페어링한 기기나 같은 네트워크의 기기만 서로를 볼 수 있습니다.
