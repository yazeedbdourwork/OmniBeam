개인정보 처리방침: 내 파일과 메시지

최종 업데이트: 2026년 11월 6일

내 파일과 메시지

OmniBeam은 가능하면 언제나 내 기기 사이에서 파일과 메시지를 직접, WebRTC로 종단 간 암호화해 보냅니다. 이 경우 우리 서버에는 전혀 닿지 않습니다.

직접 연결이 불가능할 때(예: 엄격한 방화벽이나 VPN 뒤)는 대신 우리 서버를 거칩니다. 그래도 여전히 종단 간 암호화됩니다. 두 기기가 서버는 절대 볼 수 없는 키를 정하므로, 서버는 읽을 수 없는 데이터를 저장하지 않고 전달만 합니다. 모든 전송은 먼저 받는 기기에서 수락해야 합니다.

링크로 공유한 파일

링크로 파일을 공유하면 브라우저가 업로드 전에 파일(이름 포함)을 암호화합니다. 키는 링크의 "#" 뒤 부분에만 있고, 브라우저는 이를 서버로 절대 보내지 않으므로 우리는 읽을 수 없는 데이터를 저장합니다. 공유한 파일은 링크가 만료될 때(최대 3일), 선택했다면 첫 다운로드 후, 또는 링크를 삭제할 때 자동으로 삭제됩니다. 링크를 받은 사람은 누구나 파일을 내려받을 수 있으니 의도한 사람에게만 공유하세요.

요청 링크로 보내진 파일

누군가 내가 만든 요청 링크로 파일을 보내면, 그 사람의 브라우저가 업로드 전에 파일과 이름을 내 기기와 링크만 가진 키("#" 뒤 부분으로, 서버에 절대 닿지 않음)로 암호화합니다. 우리는 읽을 수 없는 데이터를 내 기기가 가져갈 때까지 저장하고 바로 삭제합니다. 아무도 가져가지 않은 파일은 최대 7일 뒤 삭제되며, 링크를 삭제하면 아직 기다리는 것도 모두 삭제됩니다. 내 링크로 보내진 것은 내 기기만 내려받을 수 있습니다.

다른 웹사이트의 "파일을 보내 주세요" 상자

누군가 자기 웹사이트에 OmniBeam 상자를 넣어 방문자에게서 파일을 받을 수 있습니다(작동 방식 참고). 상자로 보낸 파일은 내 브라우저에서 암호화되고, 상자를 만든 사람의 기기만 열 수 있도록 봉인됩니다. OmniBeam은 읽을 수 없습니다. 상자는 쿠키를 설정하지 않으며 분석 도구도 불러오지 않습니다. 상자에 적힌 내용(요청하는 것, 기기 이름)은 그 페이지의 나머지처럼 공개됩니다.

Telegram 봇

Telegram의 OmniBeam 봇에 기기를 연결하면, 연결을 해제할 때까지 서버는 봇과의 채팅 번호, Telegram에서의 이름, 연결된 기기 이름, 그 기기가 쓰는 요청 링크를 보관합니다. 봇에게 보낸 파일과 텍스트는 Telegram과 OmniBeam 서버를 거치므로 종단 간 암호화되지 않습니다. 서버는 내 기기만 열 수 있도록 봉인한 채 내 기기가 가져갈 때까지만 보관하고 그 뒤 삭제합니다(늦어도 7일 뒤). OmniBeam에서 Telegram으로 보내는 파일은 저장되지 않고 서버를 거칩니다. Telegram에서의 채팅에는 Telegram 자체의 개인정보 처리방침이 적용됩니다.

상태 페이지

상태 페이지는 OmniBeam의 각 부분이 작동하는지, 하루별 가동 시간, 문제가 언제 있었는지만 보여 줍니다. 외부(Cloudflare)와 서버 자체가 5분마다 하는 자동 점검으로 만들어지며, 방문자나 그 파일에 관한 내용은 전혀 없습니다.

연결 데이터

기기들이 서로를 찾을 수 있도록 서버는 내 IP 주소, 앱에 표시되는 무작위 기기 이름, 두 브라우저를 연결하는 데 필요한 기술 정보를 봅니다. 이것들은 내가 온라인인 동안만 메모리에 보관되며, 디스크에 기록되거나 공유되지 않습니다.

서버는 간단한 하루 합계(예: 연결 수, 전송 수, 보낸 방식)도 기록합니다. 숫자일 뿐이며 IP 주소, 이름, 파일 정보는 없습니다. 사이트 방문도 같은 방식으로 셉니다. 어떤 페이지를 열었는지, 국가(저장하지 않는 IP 주소로 판단), 기기와 브라우저 종류, 링크한 사이트, 페이지를 연 시간입니다. 여기에는 쿠키를 쓰지 않으며 내 기기에는 아무것도 저장되지 않습니다. 쿠키 배너에서 "괜찮습니다"를 골랐다면 방문은 세지 않습니다.

내 기기에 남는 것

기기 이름, 테마, 언어, 페어링한 기기, 내가 만든 링크, 받은 파일 기록(7일 보관)은 내 브라우저에 저장됩니다. 기록은 앱에서 지우거나 사이트 데이터를 삭제해 지울 수 있습니다. 빠르게 열리고 인터넷 없이도 작동하도록 OmniBeam은 자체 앱 파일(내 파일은 절대 아님)의 사본도 브라우저에 보관하며, 업데이트할 때마다 교체합니다.

방문자 통계

사이트가 물을 때 허용하면, OmniBeam은 Google 애널리틱스로 방문을 세고 사이트 사용 방식(예: 본 페이지, 국가, 기기와 브라우저 종류)을 확인합니다. Google 애널리틱스 스크립트는 내가 "허용"을 누른 뒤, 그것도 페이지 로딩이 끝난 뒤에만 불러옵니다. 고르기 전까지, 그리고 "괜찮습니다"를 고르면 Google에는 아무것도 보내지 않습니다. Google은 이 요청으로 내 IP 주소를 받습니다. 내가 보내는 파일과 메시지는 절대 포함되지 않습니다. 선택은 언제든 바꿀 수 있습니다: 쿠키 설정. Google이 이 데이터를 사용하는 방법도 보세요.

문제 보고

전송이 실패하거나 직접 연결이 안 되는 등 문제가 생기면, 고칠 수 있도록 페이지가 짧은 익명 보고를 보냅니다. 무엇이 실패했는지, 연결 경로, 브라우저와 시스템 종류입니다. 보고에는 파일 이름, 파일 내용, 메시지, 페어링 코드, 주소가 절대 들어가지 않으며, 최근 수백 건만 보관합니다. 한꺼번에 많은 문제가 보고되면 빨리 고칠 수 있도록 요약(몇 건, 어떤 종류, 어떤 브라우저)이 이메일이나 Telegram으로 사이트 운영자에게 갑니다. OmniBeam이 열려 있는 동안 멈춘 브라우저 탭과 멈춘 전송도 같은 정보만 담아 Telegram으로 하나씩 운영자에게 보고됩니다.

알림

알림은 설정에서 켜지 않는 한 꺼져 있습니다. 켜면 서버는 브라우저가 주는 알림 주소(Apple, Google, Microsoft, Mozilla 같은 브라우저 제작사의 푸시 서비스를 가리킴), 언어, 페어링을 변환한 코드를 보관해 어떤 알림이 내 것인지 압니다. 알림은 어떤 기기가 몇 개의 파일을 보내려 하는지 알려 주며, 그 푸시 서비스를 통해 옵니다. 파일 내용이나 메시지는 절대 들어가지 않습니다. 알림을 끄거나 브라우저가 알림을 더 받지 않으면 이 모든 것이 삭제됩니다.

브라우저 확장 프로그램

Chrome과 Edge용 OmniBeam 확장 프로그램은 브라우저의 OmniBeam 탭과만 통신합니다. 사용하면 내가 고른 페이지 주소, 링크, 이미지, 선택한 텍스트를 그 탭으로 보내고, 탭이 다른 전송처럼 내 기기로 보냅니다. 방문 기록을 읽거나 수집하지 않고, 기기 목록은 브라우저가 열려 있는 동안만 보관하며, 버튼을 누를 때 선택한 텍스트를 읽는 것과 오른쪽 클릭한 이미지(옵션을 허용하면 모든 이미지)를 제외하면 다른 웹사이트에 접근하지 않습니다.

Windows용 OmniBeam 앱

Microsoft Store의 OmniBeam 앱은 이 웹사이트를 전용 창에서 엽니다. 작동 방식이 같으며 이 방침이 그대로 모두 적용됩니다.

카메라, 마이크, 화면

OmniBeam은 내가 요청할 때만 카메라, 마이크, 화면을 씁니다. 사진을 찍거나, 음성 메모를 녹음하거나, 화면을 공유하거나, ⚡ Wi‑Fi 전송 빠르게를 켤 때 한순간입니다(바로 꺼지며 아무것도 녹음되지 않음). 브라우저가 먼저 묻습니다. 사진과 음성 메모는 다른 파일처럼 보내지고, 공유한 화면은 고른 기기로 종단 간 암호화되어 바로 갑니다. 이 중 어느 것도 우리 서버에 저장되지 않습니다.

비밀 메모

기기로 보낸 비밀 메모는 그곳에서 한 번만 보이고 기록에 남지 않습니다. 비밀 메모 링크는 파일 링크처럼 작동합니다. 메모는 내 기기에서 암호화되고, 서버는 읽을 수 없으며, 한 번 읽히면 바로 서버에서 삭제됩니다.

PDF로 스캔, 채팅 보기, 사진 크기

"PDF로 스캔"은 내 기기에서 페이지 가장자리를 찾아 PDF를 만듭니다. 이를 위해 사진을 업로드하지 않으며, 만든 PDF는 다른 파일처럼 보내집니다. 채팅 보기는 이미 내 기기에 보관된 기록만 보여 주며, 추가로 저장되는 것은 없습니다. "작게"로 보내는 사진은 보내기 전에 내 기기에서 줄어듭니다.

후원자 코드

기부 후 후원자 코드를 받았다면, 코드를 되돌릴 수 있도록 서버는 만든 코드 목록을 각각의 만든 날짜와 운영자가 적을 수 있는 짧은 메모(예: 이름)와 함께 보관합니다. 내 브라우저는 코드를 보관하고 연결할 때 서버에 보여 주므로, 다른 기기에서도 내 기기 카드의 ♥를 볼 수 있습니다. 서버는 이것을 내가 온라인인 동안만 메모리에 보관합니다. 기부 자체는 OmniBeam이 아니라 내가 고른 결제 사이트(예: PayPal)가 처리합니다.

광고 없음

OmniBeam에는 계정, 광고, 광고 추적기가 없습니다. 페이지 글꼴은 Google Fonts가 아니라 omnibeam.site 자체에서 제공합니다.

호스팅

사이트는 웹 호스트에서 실행되며, 보안을 위해 표준 서버 로그(예: IP 주소와 요청 시간)가 보관될 수 있습니다.

문의

개인정보에 관한 질문: Facebook으로 메시지를 보내 주세요.

이 방침은 OmniBeam이 내 파일과 메시지를 어떻게 다루는지, 그리고 무엇을 절대 보관하지 않는지 설명합니다.
