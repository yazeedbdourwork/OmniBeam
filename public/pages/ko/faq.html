OmniBeam: 자주 묻는 질문

OmniBeam은 iPhone과 Windows PC처럼 아무 두 기기 사이에서 파일, 사진, 동영상, 텍스트를 보내는 무료 웹사이트입니다. 두 기기에서 omnibeam.site를 열고 보내면 됩니다. 설치할 앱도 계정도 없으며, 모든 전송은 종단 간 암호화됩니다.

기본

OmniBeam은 무엇인가요?

OmniBeam은 브라우저에서 내 기기들 사이에 파일을 보내는 방법입니다. AirDrop과 비슷하지만 모든 브랜드에서 됩니다. iPhone, iPad, Android, Windows, Mac, Linux, Chromebook에서 Safari, Chrome, Edge, Firefox 등 최신 브라우저로 사용할 수 있습니다.

OmniBeam은 무료인가요?

네. 파일 전송, 링크, 채팅을 비롯한 모든 기능이 무료이며, 계정도 광고도 없습니다. 프로젝트를 응원하고 싶은 분은 기부하고 추가 테마가 있는 후원자 배지를 받을 수 있지만, 그 때문에 잠긴 기능은 없습니다.

앱을 설치해야 하나요?

아니요. OmniBeam은 웹 브라우저에서 실행됩니다. 원하면 휴대폰 홈 화면에 추가하거나, Windows에서 Microsoft Store로 설치하거나, Chrome, Edge, Firefox 확장 프로그램을 추가할 수 있지만 웹사이트만으로 모든 것이 됩니다.

계정을 만들어야 하나요?

아니요. 가입도, 이메일 주소도, 비밀번호도 없습니다. 각 기기에는 이름만 붙으며, 이름은 바꿀 수 있습니다.

파일은 어떻게 보내나요?

두 기기에서 omnibeam.site를 엽니다. 같은 Wi‑Fi라면 잠시 후 서로 보입니다. 상대 기기를 탭하고 파일을 고른 뒤, 상대 기기에서 수락합니다. 파일이 바로 넘어갑니다.

네트워크와 기기

두 기기가 같은 Wi‑Fi에 있어야 하나요?

아니요. 같은 Wi‑Fi라면 자동으로 서로를 찾습니다. 모바일 데이터를 쓰는 휴대폰처럼 다른 네트워크라면 6자리 코드나 QR 코드 스캔으로 한 번만 페어링하세요. 그다음부터는 페어링된 기기가 어디에 있든 서로를 찾습니다.

iPhone에서 Windows나 Android로 보낼 수 있나요?

네. OmniBeam은 바로 그걸 위해 만들어졌습니다. iPhone에서 PC로, Android에서 iPhone으로, Android에서 Mac으로, Mac에서 Windows로, 어떤 조합이든 됩니다. 단계는 모든 기기에서 같습니다.

인터넷 없이도 되나요?

기기들이 서로를 찾으려면 omnibeam.site에 연결되어 있어야 합니다. 같은 Wi‑Fi라면 그 뒤 파일 자체는 로컬 네트워크로 바로 전송됩니다.

개인정보와 보안

OmniBeam은 안전한가요?

네. 모든 전송은 보내는 기기에서 종단 간 암호화되고, 받는 기기만 복호화할 수 있습니다. 가능하면 파일은 기기 사이에서 직접 전송됩니다. 그럴 수 없을 때는 암호화된 데이터가 내용을 읽을 수 없는 릴레이를 거칩니다. 실시간 전송은 아무것도 저장되지 않으며, 모든 파일은 받는 기기에서 수락해야 합니다.

OmniBeam이 내 파일을 보관하나요?

아니요. 실시간 전송은 절대 서버에 저장되지 않습니다. 링크로 공유한 파일이나 파일 요청으로 누군가 보낸 파일만 암호화된 채 저장되고, 링크가 만료되면 삭제됩니다.

OmniBeam은 오픈 소스인가요?

네. 소스 코드가 GPL-3.0 라이선스로 GitHub에 공개되어 있어 누구나 작동 방식을 확인할 수 있습니다.

파일과 제한

파일 크기 제한이 있나요?

직접 전송에는 없습니다. OmniBeam은 제한을 두지 않으며, Chrome, Edge, Firefox에서는 큰 파일이 디스크에 바로 기록됩니다. 공유 링크에는 앱에 표시되는 크기 제한이 있습니다. 링크가 만료될 때까지 파일을 보관하기 때문입니다.

사진과 동영상이 원본 화질로 가나요?

네, 기본적으로 원본 파일이 전송됩니다. 시간이나 공간을 아끼고 싶으면 더 작은 사진이나 더 작은 동영상을 고를 수 있고, iPhone의 HEIC 사진은 JPG로 저장할 수 있습니다.

연결이 끊기면 어떻게 되나요?

처음부터 다시 하지 않고 멈춘 곳부터 이어집니다. 직접 연결이 돌아오면 그쪽으로, 아니면 암호화된 릴레이를 통해 이어집니다.

지금 온라인이 아닌 사람에게 보낼 수 있나요?

네. 기본 7일, 최대 30일 동안 유효한 암호화 링크로 파일을 공유하세요. PIN을 추가하고 OmniBeam이 링크를 이메일로 보내게 할 수도 있습니다.

다른 도구와 비교

AirDrop과 무엇이 다른가요?

AirDrop은 가까이 있는 Apple 기기끼리만 됩니다. OmniBeam은 브라우저에서 모든 브랜드 사이에, 다른 네트워크를 넘어서도 됩니다. OmniBeam과 AirDrop 비교를 보세요.

WeTransfer와 무엇이 다른가요?

WeTransfer는 먼저 파일을 자사 서버에 업로드합니다. OmniBeam은 크기 제한 없이 기기에서 기기로 바로 보내고, 암호화 링크도 만들 수 있습니다. OmniBeam과 WeTransfer 비교를 보세요.

Snapdrop, PairDrop, LocalSend와는 무엇이 다른가요?

모두 로컬 네트워크에서 파일을 보냅니다. OmniBeam은 여기에 네트워크 간 페어링, 암호화 링크, 끊긴 뒤 이어받기, 채팅, Windows와 브라우저용 앱을 더합니다. 비교 페이지에서 항목별로 설명합니다.
