Windows용 OmniBeam: Microsoft Store에서 무료 앱 받기

OmniBeam은 Microsoft Store에 있습니다. 앱은 OmniBeam을 전용 창에서 열고, 시작 메뉴나 작업 표시줄에서 시작되며, Windows 공유 메뉴에도 나타나므로 먼저 브라우저를 열지 않고도 iPhone이나 Android 휴대폰으로 파일을 보낼 수 있습니다.

Microsoft Store에서 OmniBeam 받기

설치

  1. Microsoft Store의 OmniBeam 페이지를 열고 받기를 클릭하세요. 무료이며 계정도 광고도 없습니다.
  2. 시작 메뉴에서 OmniBeam을 여세요. 클릭 한 번에 열 수 있게, 작업 표시줄의 아이콘을 오른쪽 클릭하고 작업 표시줄에 고정을 고르세요.

Windows 10과 11에서 작동합니다. OmniBeam이 좋아질 때마다 앱이 저절로 업데이트되므로 다시 내려받을 필요가 없습니다.

휴대폰을 한 번 페어링하기

  1. 휴대폰에서 omnibeam.site를 여세요. 같은 Wi‑Fi라면 PC가 저절로 나타납니다.
  2. 다른 네트워크라면 PC의 앱에서 링크 버튼을 클릭하고 휴대폰 카메라로 QR 코드를 스캔하거나 6자리 코드를 입력하세요.
  3. 휴대폰에서 페어링 화면을 열고 PC 옆의 신뢰함을 체크하면 PC의 파일이 묻지 않고 도착합니다.

PC에서 보내기

  • 앱에서 휴대폰을 클릭해 파일을 고르거나, 파일 탐색기에서 파일을 끌어다 놓으세요.
  • 파일 탐색기에서 파일을 선택하고 오른쪽 클릭한 뒤 공유, 그다음 OmniBeam을 고르세요.
  • 링크나 메모를 보내려면 휴대폰을 가리키고 메시지 보내기를 고르세요. 설정에서 클립보드 동기화를 켜면 PC에서 복사한 텍스트가 휴대폰에 도착합니다.

Chrome이나 Edge에서 보내기: OmniBeam 확장 프로그램

확장 프로그램은 보고 있는 페이지, 링크, 이미지, 선택한 텍스트를 오른쪽 클릭으로 휴대폰에 보냅니다. Chrome 웹 스토어에서 추가하세요. Microsoft Edge에서도 작동합니다.

트레이 아이콘과 보내기 메뉴가 좋으신가요?

시계 옆의 아이콘과 오른쪽 클릭 보내기 메뉴의 OmniBeam을 원한다면 예전 트레이 앱도 여전히 쓸 수 있습니다. Node.js 22 이상이 필요합니다. 트레이 앱(ZIP)을 내려받고, 계속 둘 폴더에 압축을 푼 뒤 install-tray.cmd를 두 번 클릭하세요. 대부분의 사람에게는 Microsoft Store 앱이 더 쉽습니다.

네트워크가 허용하면 파일은 기기 사이에서 직접 이동하며, 항상 종단 간 암호화됩니다.

자주 묻는 질문

앱과 웹사이트의 차이는 무엇인가요?

하는 일은 같습니다. Microsoft Store 앱은 Windows와 함께 시작되어 대기하므로, 휴대폰이 먼저 브라우저를 열지 않고도 언제든 PC로 보낼 수 있습니다. 웹사이트는 아무것도 설치하지 않고 작동합니다.

앱이 저절로 업데이트되나요?

네. Microsoft Store가 자동으로 최신 상태로 유지하므로 항상 최신 버전을 씁니다.

파일 탐색기에서 파일을 보낼 수 있나요?

예전 트레이 앱으로는 됩니다. 오른쪽 클릭 보내기 메뉴에 OmniBeam이 추가되므로 파일을 선택하고 보내기, 그다음 OmniBeam을 고르면 됩니다. Microsoft Store 앱에서는 창으로 파일을 끌어다 놓거나 파일 선택을 쓰세요.

앱을 삭제할 수 있나요?

네. 다른 앱처럼 Windows 설정이나 시작 메뉴에서 제거하세요. 웹사이트로 돌아가면 기기는 브라우저에서 계속 페어링된 상태입니다.
