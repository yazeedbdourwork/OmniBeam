Cara transfer file dari Android ke Mac tanpa kabel

Mac dan HP Android tidak berbagi AirDrop, dan Android File Transfer sudah tidak ada. OmniBeam memindahkan foto, video, dan dokumen di antara keduanya lewat Wi‑Fi, langsung di browser tanpa memasang apa pun.

Langkah-langkah

  1. Di Mac, buka omnibeam.site di Safari, Chrome, atau Firefox.
  2. Di HP Android, buka omnibeam.site di Chrome. Sesaat kemudian kedua perangkat saling terlihat.
  3. Di HP, ketuk Mac dan pilih foto, video, atau file apa saja.
  4. Klik Terima di Mac, lalu Simpan. Beberapa file bisa disimpan sekaligus sebagai ZIP.

Dari Mac ke HP

Bisa dua arah: seret file dari Finder ke kartu HP, lalu terima di HP.

Supaya lebih cepat lagi

  • Pasang OmniBeam di HP (menu Chrome, lalu Instal aplikasi). Setelah itu OmniBeam muncul di menu bagikan Android: bagikan dari Galeri dan pilih Mac.
  • Di Mac Anda bisa menambahkan OmniBeam ke menu klik kanan Finder; lihat mengirim file dari Mac dan Linux.
  • Tidak di Wi‑Fi yang sama? Pasangkan kedua perangkat sekali dengan kode 6 digit, dan keduanya saling menemukan di mana pun.

Android File Transfer sudah tidak diperbarui, jadi banyak pengguna Mac tidak punya cara mudah mengambil file dari ponsel Android. Cukup satu tab browser di tiap sisi: tidak ada yang perlu dipasang di Mac, dan foto serta video tiba dengan kualitas aslinya.

Tips: di Mac, Safari, Chrome, dan Firefox semuanya bisa dipakai. Biarkan tab OmniBeam terbuka selama file masuk, lalu temukan file di folder Unduhan.

Dengan OmniBeam Anda bisa transfer file dari Android ke Mac tanpa kabel, gratis dan tanpa akun.

Tanya jawab

Mengapa Mac tidak melihat ponsel Android lewat USB?

macOS tidak mendukung mode transfer file yang dipakai ponsel Android lewat USB tanpa perangkat lunak tambahan, dan AirDrop dari Apple tidak mencakup Android. Alat berbasis browser menghindari kedua masalah itu.

Browser apa yang sebaiknya dipakai di Mac?

Safari, Chrome, Edge, dan Firefox semuanya bisa. Buka omnibeam.site di salah satunya dan biarkan tab terbuka selama mengirim.

Di mana file disimpan di Mac?

Secara bawaan file masuk ke folder Unduhan, atau ke tempat browser Anda menyimpan unduhan. Beberapa file juga bisa disimpan bersama sebagai satu ZIP.

Bisakah saya mengirim folder?

Bisa. Anda bisa mengirim seluruh folder dari Mac, dan di Android Anda bisa memilih banyak file sekaligus dari galeri atau pengelola file.

Apakah bisa ke arah sebaliknya?

Bisa, dari Mac ke ponsel Android juga: klik ponsel di Mac, pilih file, lalu terima di ponsel.

Bisakah dipasang seperti aplikasi?

Bisa, tetapi tidak wajib. Tambahkan omnibeam.site ke layar utama ponsel, pasang OmniBeam dari Microsoft Store di Windows, atau tambahkan ekstensi Chrome. Situsnya bekerja sama di browser terbaru mana pun.

OmniBeam tersedia dalam bahasa apa saja?

Situs, panduan, dan artikel tersedia dalam 15 bahasa: Inggris, Arab, Prancis, Spanyol, Turki, Jerman, Portugis, Hindi, Indonesia, Rusia, Jepang, Mandarin, Korea, Italia, dan Urdu. Tautan di bagian bawah setiap halaman membuka halaman yang sama dalam bahasa lain, praktis untuk dibagikan kepada teman.

Bisakah saya mengirim ke beberapa perangkat sekaligus?

Bisa. Dengan “Kirim ke semua”, file yang sama terkirim ke setiap perangkat yang membuka OmniBeam dalam satu langkah. Untuk kelompok, Anda juga bisa membuat ruang publik; semua orang masuk dengan kode pendek yang sama dan bisa saling mengirim file.
