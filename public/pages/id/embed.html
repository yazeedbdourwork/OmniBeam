Kotak "Kirimi saya file" untuk situs web atau blog Anda

Biarkan pengunjung, klien, atau siswa mengirimi Anda file langsung dari halaman Anda sendiri. Anda menempelkan satu kode pendek; file dienkripsi di perangkat mereka dan tiba di OmniBeam di perangkat Anda.

Langkah-langkah

  1. Buka omnibeam.site di perangkat yang akan menerima file, lalu ketuk Minta file di menu ⋯.
  2. Tulis apa yang Anda butuhkan (opsional), pilih 1 tahun (untuk situs web) di "Tautan berlaku selama", lalu ketuk Buat tautan permintaan.
  3. Ketuk Pasang di situs web Anda, lalu Salin kode.
  4. Tempel kode di halaman Anda: di WordPress dalam blok HTML Khusus, di Blogger dalam gadget HTML/JavaScript, di Wix dalam elemen Embed HTML, di Squarespace dalam blok Code.

Pengunjung melihat kotak kecil berisi "Pilih file", kolom nama opsional, dan tombol Kirim. Mereka tidak perlu aplikasi atau akun. File tiba di perangkat Anda di File diterima; jika OmniBeam tertutup di sana, file menunggu di server dan tiba saat Anda membukanya, dengan notifikasi jika Anda menyalakannya.

WordPress: plugin OmniBeam yang gratis

Di WordPress lebih mudah lagi: unduh plugin OmniBeam (omnibeam-wordpress.zip), lalu di WordPress buka Plugin → Tambah Baru → Unggah Plugin, pilih file zip, dan ketuk Aktifkan. Tempel kode Anda (atau hanya tautannya) di Pengaturan → OmniBeam Box, lalu tambahkan blok OmniBeam: Send me files ke halaman mana pun, atau shortcode [omnibeam_box]. Kotak dengan tautan dan tinggi sendiri: [omnibeam_box url="https://omnibeam.site/embed/r/…" height="520"]. Plugin hanya menerima kotak dari omnibeam.site, dan file tidak pernah melewati situs WordPress Anda.

Biarkan baris "Didukung oleh OmniBeam": itulah yang membuat kotak ini tetap gratis.

Apakah privat dan aman?

  • Setiap unggahan dienkripsi di browser pengunjung. Kuncinya disegel dengan kunci publik perangkat Anda, dan hanya perangkat Anda yang memiliki kunci privat pasangannya, jadi baik OmniBeam maupun orang yang membaca kode halaman Anda tidak bisa membuka file.
  • Kode di halaman Anda bersifat publik. Siapa pun yang melihatnya bisa mengirimi Anda file dan membaca teks "apa yang Anda butuhkan" serta nama perangkat Anda, jadi jangan tulis hal pribadi di sana.
  • Hanya perangkat Anda yang bisa mengunduh unggahan, dan setiap unggahan dihapus dari server begitu perangkat Anda menerimanya. File yang tidak diambil dihapus setelah 7 hari.
  • Batas yang biasa tetap berlaku: batas ukuran per unggahan, batas per jaringan per jam, dan paling banyak 100 unggahan per hari per kotak.
  • Hapus tautan permintaan di jendela yang sama kapan saja, dan kotak langsung berhenti berfungsi.

Tanya jawab

Apakah berbayar?

Tidak. Kotak ini gratis, tanpa akun, tanpa plugin, dan tanpa iklan.

Bisakah saya memakainya di beberapa halaman?

Bisa. Tempel kode yang sama di halaman mana saja; semua unggahan tiba di perangkat yang sama. Buat tautan permintaan terpisah jika ingin membedakannya.

Mengapa kotak berhenti berfungsi setelah beberapa waktu?

Setiap tautan permintaan berakhir pada waktu yang Anda pilih. Untuk situs web, pilih 1 tahun, lalu buat tautan dan kode baru sebelum berakhir.

Bisakah orang memakai kotak saya untuk mengirim spam?

Siapa pun yang mengunjungi halaman bisa mengirimi Anda file, sama seperti alamat email. File tidak pernah terbuka sendiri, unggahan dibatasi per jaringan dan per hari, dan Anda bisa menghapus tautan untuk mematikan kotak.
