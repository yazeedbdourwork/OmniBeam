Cara mengirim file dari PC ke iPhone tanpa iTunes

Memindahkan file dari Windows ke iPhone biasanya berarti iTunes, kabel, atau mengirim email ke diri sendiri. OmniBeam melakukannya di browser kedua perangkat, dalam kualitas penuh.

Langkah-langkah

  1. Di PC, buka omnibeam.site. Di iPhone, buka alamat yang sama di Safari.
  2. Di Wi‑Fi yang sama, kedua perangkat saling tampil sesaat kemudian. Di jaringan berbeda, ketuk tombol tautan di satu perangkat, buat kode pasangan, lalu masukkan (atau pindai kode QR) di perangkat lain.
  3. Di PC, klik iPhone lalu pilih file, atau seret file ke atasnya. Satu folder utuh juga bisa: tiba sebagai ZIP.
  4. Di iPhone, ketuk Terima, lalu Simpan.

Di mana file tersimpan di iPhone

  • File yang disimpan masuk ke aplikasi File, di folder Unduhan (Di iPhone Saya atau iCloud Drive).
  • Untuk memasukkan foto atau video ke aplikasi Foto, buka di File, ketuk tombol bagikan, lalu pilih Simpan Gambar atau Simpan Video.
  • Ada yang terlewat? Tombol unduh di atas OmniBeam menampilkan file yang Anda terima dalam 7 hari terakhir.

Satu klik untuk lain kali

Pasangkan kedua perangkat sekali dan tandai PC sebagai Tepercaya di layar Pasangan iPhone. Setelah itu keduanya saling menemukan di jaringan mana pun, dan file dari PC masuk tanpa ditanya. Di PC, aplikasi OmniBeam gratis dari Microsoft Store membuat OmniBeam selalu sekali klik di taskbar dan di menu Bagikan Windows: lihat OmniBeam untuk Windows.

Di iPhone, foto dan video yang diterima bisa langsung disimpan ke app Foto, dan file lain masuk ke app File. Tambahkan OmniBeam ke Layar Utama dari Safari agar lebih cepat ditemukan lain kali.

Tanya jawab

Di mana file muncul di iPhone?

Safari menanyakan tempat menyimpannya. Foto dan video bisa langsung masuk ke aplikasi Foto, dan file lain seperti PDF, musik, atau dokumen disimpan di aplikasi File.

Bisakah saya mengirim folder dari PC?

Bisa. Seret folder ke iPhone di OmniBeam pada PC. File tiba di iPhone dan bisa disimpan bersama.

Apakah bisa dengan iPad?

Bisa. Langkahnya sama di iPad: buka omnibeam.site di Safari dan terima file.

Bisakah saya mengirim musik ke iPhone?

Bisa. MP3 dan file audio lain disimpan di aplikasi File, tempat Anda bisa memutarnya, atau membukanya di aplikasi pemutar musik lain.

Mengapa saya harus mengetuk Terima di iPhone?

Demi keamanan Anda, perangkat hanya menerima file setelah Anda menyetujuinya. Anda bisa menyalakan terima otomatis untuk perangkat Anda sendiri yang sudah dipasangkan di jendela pemasangan.

Bisakah saya mengirim ke beberapa perangkat sekaligus?

Bisa. Dengan “Kirim ke semua”, file yang sama terkirim ke setiap perangkat yang membuka OmniBeam dalam satu langkah. Untuk kelompok, Anda juga bisa membuat ruang publik; semua orang masuk dengan kode pendek yang sama dan bisa saling mengirim file.

Bagaimana cara mengukur kecepatan jaringan saya?

OmniBeam punya tes kecepatan antara dua perangkat Anda. Jalankan sebelum mengirim file besar untuk melihat seberapa cepat transfer langsung di jaringan Anda; jika lambat, dekatkan perangkat ke router atau matikan VPN.

Apakah saya perlu membuat akun?

Tidak. OmniBeam tidak meminta akun, pendaftaran, atau alamat email. Buka omnibeam.site di kedua perangkat, dan keduanya saling muncul. Jika Anda memasangkan dua perangkat sekali dengan kode 6 digit, keduanya akan saling menemukan secara otomatis, bahkan di jaringan berbeda.
