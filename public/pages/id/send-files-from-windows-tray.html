OmniBeam untuk Windows: dapatkan aplikasi gratisnya di Microsoft Store

OmniBeam ada di Microsoft Store. Aplikasinya membuka OmniBeam di jendelanya sendiri, dijalankan dari menu Start atau taskbar, dan muncul di menu Bagikan Windows, jadi Anda bisa mengirim file ke iPhone atau ponsel Android tanpa membuka browser lebih dulu.

Dapatkan OmniBeam di Microsoft Store

Pasang

  1. Buka halaman OmniBeam di Microsoft Store lalu klik Dapatkan. Gratis, tanpa akun dan tanpa iklan.
  2. Buka OmniBeam dari menu Start. Agar selalu sekali klik, klik kanan ikonnya di taskbar lalu pilih Sematkan ke taskbar.

Berjalan di Windows 10 dan 11. Aplikasi memperbarui dirinya sendiri setiap kali OmniBeam makin baik, jadi tidak ada yang perlu diunduh ulang.

Pasangkan ponsel sekali

  1. Di ponsel, buka omnibeam.site. Di Wi‑Fi yang sama, PC muncul dengan sendirinya.
  2. Di jaringan lain, klik tombol tautan di aplikasi pada PC lalu pindai kode QR-nya dengan kamera ponsel, atau ketik kode 6 digit.
  3. Di ponsel, buka layar Pasangan dan centang Tepercaya di samping PC, agar filenya masuk tanpa ditanya.

Kirim dari PC

  • Klik ponsel di aplikasi lalu pilih file, atau seret file dari File Explorer ke atasnya.
  • Di File Explorer, pilih file, klik kanan, pilih Bagikan lalu OmniBeam.
  • Untuk mengirim tautan atau catatan, arahkan kursor ke ponsel lalu pilih Kirim pesan. Jika Sinkronisasi papan klip aktif di Pengaturan, teks yang Anda salin di PC sampai di ponsel.

Kirim dari Chrome atau Edge: ekstensi OmniBeam

Ekstensi ini mengirim halaman yang sedang dibuka, tautan, gambar, atau teks yang dipilih ke ponsel Anda dengan klik kanan. Tambahkan dari Chrome Web Store; ekstensi ini juga berjalan di Microsoft Edge.

Lebih suka ikon tray dan menu Send to?

Aplikasi tray lama masih tersedia jika Anda ingin ikon di samping jam dan OmniBeam di menu Send to pada klik kanan. Aplikasi ini perlu Node.js 22 atau lebih baru: unduh aplikasi tray (ZIP), ekstrak ke folder yang akan Anda simpan, lalu klik dua kali install-tray.cmd. Bagi kebanyakan orang, aplikasi Microsoft Store adalah pilihan yang lebih mudah.

File berpindah langsung antarperangkat Anda selama jaringan memungkinkan, dan selalu terenkripsi end-to-end.

Tanya jawab

Apa bedanya aplikasi dengan situs web?

Keduanya melakukan tugas yang sama. Aplikasi Microsoft Store menyala bersama Windows dan selalu siap, jadi ponsel bisa mengirim ke PC kapan saja tanpa membuka browser dulu. Situs web bekerja tanpa memasang apa pun.

Apakah aplikasinya memperbarui diri sendiri?

Ya. Microsoft Store memperbaruinya secara otomatis, sehingga Anda selalu memakai versi terbaru.

Bisakah saya mengirim file dari File Explorer?

Dengan aplikasi tray yang lama bisa: aplikasi itu menambahkan OmniBeam ke menu klik kanan Kirim ke, jadi Anda memilih file, memilih Kirim ke, lalu OmniBeam. Di aplikasi Microsoft Store, seret file ke jendela atau gunakan pemilih file.

Bisakah saya menghapus aplikasinya?

Bisa. Copot seperti aplikasi lain dari Pengaturan Windows atau menu Start. Perangkat Anda tetap terpasang di browser jika Anda kembali ke situs web.
