Kirim file dengan tautan, terenkripsi

Saat orang lain tidak sedang online bersamaan, atau Anda tidak ingin memasangkan perangkat, bagikan file lewat tautan. File dienkripsi di perangkat Anda sebelum keluar darinya.

Langkah-langkah

  1. Buka omnibeam.site, lalu ketuk Bagikan file lewat tautan di menu ⋯ di atas.
  2. Pilih berapa lama tautan berlaku (1 jam, 1 hari, atau 3 hari) dan, jika mau, “Hapus setelah unduhan pertama”.
  3. Pilih file. File dienkripsi dan diunggah, lalu Anda mendapat tautan dan kode QR.
  4. Kirim tautan lewat WhatsApp, email, atau aplikasi apa pun. Siapa pun yang membukanya bisa mengunduh file di perangkat apa pun.

Seberapa privat?

File dan namanya dienkripsi di browser Anda dengan kunci acak. Kuncinya adalah bagian tautan setelah “#”, yang tidak pernah dikirim browser ke server, sehingga OmniBeam hanya menyimpan data yang tidak bisa dibacanya. Perlakukan tautan seperti file itu sendiri: siapa pun yang memilikinya bisa mengunduh.

Batasan

  • Tautan memiliki batas ukuran, yang ditampilkan saat Anda membuatnya.
  • File dihapus otomatis saat tautan kedaluwarsa. Anda juga bisa menghapus tautan sendiri kapan saja dari jendela yang sama.
  • Untuk file yang sangat besar, kirim langsung ke perangkat: transfer langsung tidak punya batas ukuran.

Tautan berguna saat orang lain tidak sedang online bersamaan dengan Anda. File dienkripsi sebelum keluar dari browser Anda, jadi hanya orang yang Anda beri tautan yang bisa membukanya.

Mengirim file besar dengan tautan itu gratis, dan file sudah terenkripsi sebelum keluar dari perangkat Anda.

Tanya jawab

Kapan tautan lebih baik daripada transfer langsung?

Gunakan tautan saat orang lain tidak online pada saat yang sama, saat Anda ingin mengirim file yang sama ke beberapa orang, atau saat Anda tidak bisa memasangkan perangkat. Untuk file sangat besar ke perangkat sendiri, transfer langsung lebih cepat dan tanpa batas ukuran.

Bisakah saya melihat apakah file sudah diunduh?

Anda bisa memilih “Hapus setelah unduhan pertama”, sehingga tautan berhenti bekerja begitu dipakai. Anda juga bisa menghapus tautan sendiri kapan saja dari jendela yang sama.

Apakah orang lain butuh OmniBeam?

Tidak. Mereka cukup membuka tautan di browser pada perangkat apa pun lalu mengunduh file. Tidak ada yang perlu dipasang dan tidak perlu akun.

Bisakah OmniBeam melihat file saya?

Tidak. File dienkripsi di browser Anda sebelum diunggah, dan kuncinya tetap berada di bagian tautan setelah tanda “#”, yang tidak pernah dikirim ke server.

Berapa lama tautan tetap tersedia?

Anda memilihnya saat membuat tautan: 1 jam, 1 hari, atau 3 hari. Setelah itu file dihapus otomatis dan tautan berhenti bekerja.

Bagaimana cara mengukur kecepatan jaringan saya?

OmniBeam punya tes kecepatan antara dua perangkat Anda. Jalankan sebelum mengirim file besar untuk melihat seberapa cepat transfer langsung di jaringan Anda; jika lambat, dekatkan perangkat ke router atau matikan VPN.

Apakah saya perlu membuat akun?

Tidak. OmniBeam tidak meminta akun, pendaftaran, atau alamat email. Buka omnibeam.site di kedua perangkat, dan keduanya saling muncul. Jika Anda memasangkan dua perangkat sekali dengan kode 6 digit, keduanya akan saling menemukan secara otomatis, bahkan di jaringan berbeda.

Apakah ada batas ukuran file?

Transfer langsung tidak punya batas ukuran: Anda bisa mengirim video panjang atau seluruh folder. Cukup biarkan halaman terbuka di kedua perangkat dan pastikan ruang kosong di perangkat penerima cukup. Tautan punya batas, yang ditampilkan saat Anda membuatnya.
