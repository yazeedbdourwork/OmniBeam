Kirim file dari Mac atau PC Linux ke ponsel dengan klik kanan

Pembantu OmniBeam menambahkan Send with OmniBeam ke menu klik kanan Finder di Mac dan pengelola file di Linux. Pilih file, pilih ponsel Anda, dan file terkirim tanpa membuka browser di komputer.

Unduh untuk Mac dan Linux (ZIP)

Pasang di Mac

  1. Pasang Node.js, yang dipakai pembantu ini untuk mengirim file.
  2. Ekstrak unduhan lalu klik dua kali install-mac.command. Jika macOS tidak mau membukanya, klik kanan, pilih Open, lalu Open lagi.
  3. Ketik kode pasangan dari ponsel Anda saat diminta (lihat di bawah).

Lalu klik kanan file di Finder dan pilih Quick Actions dan Send with OmniBeam. Untuk teks yang dipilih di aplikasi apa pun, klik kanan lalu pilih Services dan Send text with OmniBeam. Jika tidak ada, nyalakan di System Settings, Keyboard, Keyboard Shortcuts, Services.

Pasang di Linux

  1. Pasang Node.js 18 atau lebih baru, misalnya sudo apt install nodejs, dan zenity (atau kdialog di KDE) untuk memilih perangkat.
  2. Ekstrak unduhan, buka terminal di folder itu, lalu jalankan sh install-linux.sh.
  3. Ketik kode pasangan dari ponsel Anda saat diminta.

Lalu klik kanan file dan pilih Scripts dan Send with OmniBeam di Files, Nemo, atau Caja, atau langsung Send with OmniBeam di menu Dolphin dan Thunar.

Pasangkan ponsel sekali

  1. Di ponsel, buka omnibeam.site, ketuk tombol tautan lalu Buat kode pasangan.
  2. Ketik kode itu di pemasang di komputer.
  3. Di ponsel, buka lagi layar Pasangan dan centang Tepercaya di samping komputer, agar filenya masuk tanpa ditanya.

Ponsel perlu membuka omnibeam.site untuk menerima. File melewati server OmniBeam, terenkripsi end-to-end, sehingga server tidak bisa membacanya. Untuk menghapus entri menu lagi, jalankan node omnibeam-send.js --uninstall.

Memakai Chrome atau Edge? Ekstensi OmniBeam mengirim halaman, tautan, gambar, atau teks yang dipilih ke ponsel Anda dengan klik kanan, di Mac, Linux, dan Windows.

Tanya jawab

Apakah menu klik kanan bekerja di setiap desktop Linux?

Menu itu bekerja di pengelola file yang umum: Files (Nautilus), Nemo, Caja, Dolphin, dan Thunar. Di desktop lain Anda tetap bisa membuka omnibeam.site di browser dan menyeret file ke sana.

Bisakah saya menghapus item menu nanti?

Bisa. Jalankan node omnibeam-send.js --uninstall di folder helper, maka entri itu hilang dari menu klik kanan.

Apakah bisa mengirim ke iPhone dan Android?

Bisa. Helper mengirim ke ponsel yang Anda pasangkan dengan kode, baik iPhone maupun Android, di Wi‑Fi yang sama atau dengan data seluler, selama omnibeam.site terbuka di ponsel.

Mengapa helper butuh Node.js?

Helper adalah skrip kecil yang berjalan dengan Node.js. Ia dipasangkan dengan ponsel Anda sekali, lalu mengirim file yang Anda pilih tanpa membuka browser di komputer, sehingga aksi klik kanan tetap cepat.

Bisakah saya mengirim teks yang dipilih juga?

Di Mac bisa: pilih teks di aplikasi apa pun, klik kanan, pilih Layanan, lalu Send text with OmniBeam. Teks tiba di ponsel, siap disalin.
