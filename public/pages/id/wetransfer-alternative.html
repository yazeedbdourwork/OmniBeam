Alternatif gratis untuk WeTransfer untuk mengirim file besar

Paket gratis WeTransfer membatasi seberapa banyak yang bisa Anda kirim dan menyimpan file di servernya. OmniBeam mengirim file besar langsung dari perangkat Anda ke perangkat orang lain, tanpa batas ukuran, atau lewat tautan terenkripsi saat orang itu sedang tidak online.

Dua cara mengirim file besar

  1. Langsung: buka omnibeam.site di kedua perangkat, pasangkan sekali dengan kode QR jika beda jaringan, lalu kirim. Ukuran berapa pun bisa, dari satu foto sampai proyek video 50 GB.
  2. Lewat tautan: di menu ⋯ pilih Bagikan file lewat tautan, pilih file, lalu bagikan tautannya. Berlaku hingga 7 hari, dengan PIN dan batas unduhan jika mau.
  3. Ketik alamat email orangnya di Kirim ke, dan OmniBeam mengirimkan tautannya lewat email.
  4. Orang itu membuka tautan di browser apa pun lalu mengunduh. Tanpa akun di kedua sisi.

Dibandingkan dengan WeTransfer

Di WeTransfer file diunggah dulu ke servernya lalu diunduh belakangan, jadi file besar menempuh perjalanan dua kali dan Anda menunggu unggahan selesai. Dengan pengiriman langsung OmniBeam, file hanya menempuh perjalanan sekali, dari perangkat Anda ke perangkatnya, dan langsung mulai masuk. Tautan dienkripsi di perangkat Anda, jadi server OmniBeam hanya menyimpan data yang tidak bisa dibacanya.

Tips untuk file yang sangat besar

  • File 1 GB ke atas memakai mode file besar: tiap potongan 16 MB diperiksa saat tiba, dan hanya potongan yang rusak yang dikirim ulang.
  • Jika koneksi putus, transfer berlanjut dari potongan terakhir yang sudah diperiksa, bukan mulai dari awal.
  • Biarkan perangkat pengirim tetap menyala dan halamannya terbuka. Untuk transfer panjang di laptop, colokkan ke charger.
  • Agar paling cepat, hubungkan kedua perangkat ke Wi‑Fi yang sama atau sambungkan komputer dengan kabel.

Pengiriman langsung paling cocok untuk perangkat Anda sendiri atau orang yang bisa membuka OmniBeam pada saat yang sama. Tautan lebih baik jika orang lain jauh atau sibuk, karena ia bisa mengunduh kapan saja sampai tautan kedaluwarsa.

OmniBeam adalah alternatif WeTransfer gratis untuk mengirim file besar: tanpa daftar, tanpa iklan di halaman unduhan, dan tanpa batas ukuran untuk pengiriman langsung.

Tanya jawab

Benarkah tidak ada batas ukuran?

Untuk pengiriman langsung antara dua perangkat, tidak ada. Tautan punya batas yang ditentukan server, terlihat di jendela tautan.

Berapa lama tautan berlaku?

Dari 1 jam sampai 7 hari, sesuai pilihan Anda. Anda juga bisa membatasi hanya 1, 3, 5, atau 10 unduhan, dan menghapus tautan lebih awal.

Apakah OmniBeam bisa melihat file saya?

Tidak. Pengiriman langsung terenkripsi antara dua perangkat, dan tautan dienkripsi di browser Anda dengan kunci yang hanya ada di dalam tautan itu sendiri.

Apakah penerima perlu akun?

Tidak. Ia membuka tautan atau OmniBeam di browser. Tidak ada yang perlu mendaftar.

Bisakah saya mengirim tautan lewat email?

Bisa. Ketik alamat email di Kirim ke, dan OmniBeam mengirim tautan dari no-reply@omnibeam.site. PIN, jika Anda pasang, tidak pernah ada di email.

Bagaimana jika laptop saya tidur saat transfer besar?

Transfer berhenti selama tidur. Buka OmniBeam lagi di kedua perangkat dan transfer berlanjut sendiri dari potongan terakhir yang diperiksa.
