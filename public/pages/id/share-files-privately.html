Cara berbagi file secara privat

Foto, pindaian KTP, kontrak: banyak yang kita kirim bersifat pribadi. Inilah yang benar-benar melindunginya di perjalanan, dijelaskan tanpa istilah teknis.

Tiga tempat file bisa dilihat

  1. Di jaringan: siapa pun di Wi‑Fi publik yang sama. Situs mana pun dengan https melindungi dari ini.
  2. Di server layanan: perusahaan yang membawa atau menyimpan file. Hanya enkripsi end-to-end yang melindungi dari ini.
  3. Di perangkat: milik Anda dan milik orang lain. Bagian itu tergantung Anda.

Arti enkripsi end-to-end

File dikunci di perangkat Anda dan hanya dibuka di perangkat lain. Layanan di tengah hanya meneruskan data acak dan tidak pernah memegang kuncinya. Jika servernya diretas, atau seseorang meminta file Anda kepada perusahaan itu, tidak ada yang bisa dibaca untuk diserahkan.

Cara OmniBeam menanganinya

  • Transfer langsung antarperangkat memakai WebRTC, yang selalu terenkripsi end-to-end.
  • Saat koneksi langsung tidak memungkinkan dan file melewati server kami, kedua perangkat menyepakati kunci terlebih dulu, sehingga server hanya meneruskan data acak dan tidak menyimpan apa pun.
  • Tautan berbagi dienkripsi di browser Anda sebelum diunggah. Kuncinya adalah bagian tautan setelah #, yang tidak pernah dikirim browser ke server. Tautan kedaluwarsa dengan sendirinya.
  • Tanpa akun. Perangkat yang dipasangkan diingat di browser Anda sendiri.

Lima kebiasaan yang membantu

  • Utamakan transfer langsung atau layanan terenkripsi end-to-end untuk apa pun yang pribadi.
  • Jika tautan atau ruang memakai kata sandi, kirim kata sandinya lewat aplikasi lain, bukan bersama tautannya.
  • Pilih tautan yang kedaluwarsa, dan hapus saat orang lain sudah menerima filenya.
  • Periksa apa yang Anda bagikan: foto bisa berisi lokasi tempat foto diambil.
  • Hanya terima file dari perangkat yang Anda kenali. Di OmniBeam, tandai hanya perangkat Anda sendiri sebagai Tepercaya.

Detail lebih lanjut ada di kebijakan privasi kami.

Tes cepat untuk layanan berbagi file mana pun: apakah layanan itu bisa membaca file Anda kalau mau? Jika file dienkripsi di perangkat Anda sebelum keluar, layanan hanya melihat data acak. Begitulah OmniBeam mengenkripsi setiap transfer.

Untuk berbagi file secara privat, gunakan pengiriman terenkripsi ujung ke ujung seperti OmniBeam.

Tanya jawab

Apakah tautan cloud itu privat?

Tautan cloud biasa disimpan di server penyedia, dan penyedia biasanya bisa membaca file tersebut. Dengan enkripsi ujung ke ujung, hanya perangkat di kedua ujung yang memegang kuncinya, sehingga tidak ada pihak di tengah yang bisa membuka file.

Bagaimana mengetahui layanan memakai enkripsi ujung ke ujung?

Cari pernyataan jelas bahwa file dienkripsi di perangkat Anda sebelum keluar, dan bahwa kuncinya tidak pernah dikirim ke server. OmniBeam menjelaskan hal ini di halaman privasinya.

Apa lagi yang harus saya lakukan agar file tetap privat?

Kirim tautan hanya kepada orang yang membutuhkannya, pilih masa berlaku yang singkat, dan hapus tautan setelah dipakai.

Apakah mengirim lewat email itu privat?

Email praktis tetapi tidak privat secara bawaan: pesan dan lampiran biasanya disimpan di server email kedua pihak. Untuk file pribadi, transfer atau tautan dengan enkripsi ujung ke ujung lebih aman.

Apakah saya harus memercayai OmniBeam?

Jauh lebih sedikit daripada layanan cloud biasa. File dienkripsi di perangkat Anda, dan kuncinya tidak pernah sampai ke server OmniBeam, jadi OmniBeam pun tidak bisa membukanya.
