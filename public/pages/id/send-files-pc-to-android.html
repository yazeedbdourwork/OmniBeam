Cara mengirim file dari PC ke ponsel Android tanpa kabel

Jawaban singkat: buka omnibeam.site di PC dan di ponsel Android, klik ponsel di PC, pilih file, lalu ketuk Terima di ponsel. File dikirim lewat Wi‑Fi dalam kualitas penuh, tanpa kabel USB, tanpa aplikasi, dan tanpa akun.

Langkah demi langkah

  1. Di PC, buka omnibeam.site di Chrome, Edge, atau Firefox.
  2. Di ponsel Android, buka omnibeam.site di Chrome atau browser lain. Di Wi‑Fi yang sama, setiap perangkat melihat yang lain setelah sesaat.
  3. Di PC, klik ponsel dan pilih file, atau seret file ke atasnya. Anda bisa memilih banyak file atau satu folder penuh.
  4. Di ponsel, ketuk Terima. File tersimpan di Download, dan foto serta video bisa dibuka di Galeri.

Jika PC dan ponsel di jaringan berbeda

Saat ponsel memakai data seluler, atau PC ada di jaringan kantor atau VPN, keduanya tidak saling melihat otomatis. Di PC, klik tombol tautan dan buat kode pemasangan, lalu pindai kode QR dengan kamera ponsel atau ketik kode 6 digit. Setelah itu keduanya tetap terpasang dan saling menemukan di jaringan mana pun.

Cara lebih cepat untuk sehari-hari

  • Klik kanan file di Windows dan gunakan Send to, dengan aplikasi baki OmniBeam yang gratis atau aplikasi Microsoft Store.
  • Pasang OmniBeam di ponsel dari menu Chrome (Tambahkan ke layar utama). Setelah itu ia juga muncul di menu Bagikan Android, untuk mengirim ke arah sebaliknya.
  • Tandai PC sebagai perangkat tepercaya di ponsel dan aktifkan Terima otomatis, sehingga file dari PC Anda tiba tanpa ketukan.
  • Kirim teks, tautan, dan kata sandi yang disalin lewat chat dengan ponsel, bukan lewat email ke diri sendiri.

Kenapa tidak pakai kabel USB?

Kabel bisa, tetapi Android sering membukanya dalam mode hanya mengisi daya, Windows harus menemukan penyimpanan ponsel, dan Anda perlu kabel yang tepat. Lewat Wi‑Fi, OmniBeam biasanya sama cepatnya untuk foto, dokumen, dan file APK, dan tetap bekerja saat ponsel ada di ruangan lain atau jaringan lain. Untuk video yang sangat besar, hubungkan keduanya ke Wi‑Fi yang sama agar paling cepat.

Semuanya dienkripsi end-to-end di PC, dan hanya ponsel Anda yang bisa membuka file. Tidak ada yang disimpan di server.

Tanya jawab

Apakah saya perlu memasang aplikasi di Android?

Tidak. Buka omnibeam.site di browser ponsel. Memasangnya di layar utama itu opsional dan hanya membuatnya lebih cepat dibuka.

Ke mana file disimpan di ponsel?

Ke folder Download, seperti unduhan lainnya. Di sebagian besar ponsel, foto dan video juga muncul di Galeri atau Google Foto.

Apakah ada batas ukuran?

Tidak. OmniBeam tidak membatasi kirim langsung, jadi Anda bisa mengirim video besar, file ZIP, dan folder penuh. Biarkan layar ponsel menyala selama transfer yang lama.

Bisakah saya mengirim satu folder penuh dari PC?

Bisa. Seret folder ke ponsel, atau gunakan opsi folder saat memilih file. File tiba dengan namanya, dan Anda bisa menyimpan semuanya sekaligus.

Apakah berfungsi di Samsung, Xiaomi, Oppo, Pixel, dan lainnya?

Ya. Berfungsi di ponsel atau tablet Android apa pun dengan browser terbaru, juga di Android TV.

Apakah caranya sama dari Mac atau Chromebook?

Ya. Langkahnya sama di komputer mana pun, karena OmniBeam berjalan di browser.
