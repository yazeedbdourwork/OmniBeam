Send files from a Mac or Linux PC to your phone with a right-click

The OmniBeam helper adds Send with OmniBeam to the right-click menu of Finder on a Mac and of the file manager on Linux. Pick files, choose your phone and they go across, without opening the browser on the computer.

Download for Mac and Linux (ZIP)

Install on a Mac

  1. Install Node.js, which the helper uses to send files.
  2. Unzip the download and double-click install-mac.command. If macOS won't open it, right-click it, choose Open and then Open again.
  3. Type the pairing code from your phone when asked (see below).

Then right-click files in Finder and choose Quick Actions and Send with OmniBeam. For selected text in any app, right-click and choose Services and Send text with OmniBeam. If they are missing, turn them on in System Settings, Keyboard, Keyboard Shortcuts, Services.

Install on Linux

  1. Install Node.js 18 or newer, for example sudo apt install nodejs, and zenity (or kdialog on KDE) for the device chooser.
  2. Unzip the download, open a terminal in that folder and run sh install-linux.sh.
  3. Type the pairing code from your phone when asked.

Then right-click files and choose Scripts and Send with OmniBeam in Files, Nemo or Caja, or Send with OmniBeam straight in the menu in Dolphin and Thunar.

Pair your phone once

  1. On the phone, open omnibeam.site, tap the link button and Create a pairing code.
  2. Type that code into the installer on the computer.
  3. On the phone, open the Pair screen again and tick Trusted next to the computer, so its files arrive without asking.

The phone needs omnibeam.site open to receive. Files go through the OmniBeam server, end-to-end encrypted, so the server can't read them. To remove the menu entries again, run node omnibeam-send.js --uninstall.

Using Chrome or Edge? The OmniBeam extension sends the page, a link, an image or selected text to your phone with a right-click, on Mac, Linux and Windows.

Questions and answers

Does the right-click menu work on every Linux desktop?

It works in the common file managers: Files (Nautilus), Nemo, Caja, Dolphin and Thunar. On other desktops you can still open omnibeam.site in the browser and drag the files in.

Can I remove the menu items later?

Yes. Run node omnibeam-send.js --uninstall in the helper’s folder, and the entries disappear from the right-click menu.

Does it send to iPhone and Android?

Yes. It sends to the phone you paired with the code, whether it is an iPhone or an Android phone, on the same Wi‑Fi or on mobile data, as long as omnibeam.site is open on the phone.

Why does the helper need Node.js?

The helper is a small script that runs with Node.js. It pairs with your phone once and then sends the files you pick without opening a browser on the computer, which keeps the right-click action quick.

Can I send selected text too?

On a Mac, yes: select text in any app, right-click and choose Services, then Send text with OmniBeam. It arrives on the phone ready to copy.

Are the files encrypted?

Yes. They are encrypted end to end on the computer, and the server only passes them along without being able to read them.
