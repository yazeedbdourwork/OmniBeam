How to transfer files between two computers without a USB stick

Copying to a USB stick, emailing yourself or uploading to the cloud all take twice as long as they should. OmniBeam sends files from one computer straight to another, Windows, Mac, Linux or Chromebook, in any mix.

Steps

  1. Open omnibeam.site in a browser on both computers.
  2. On the same network they appear automatically. Otherwise, click the pair button on one and type the 6‑digit code on the other.
  3. Drag files or whole folders onto the other computer's card, or click it and choose files.
  4. Accept on the other computer. Folders keep their structure and can be saved as one ZIP.

Why it's quick

  • Files go directly between the two computers over your network, not through a cloud server.
  • There is no size limit, and big transfers continue by themselves if the connection drops.
  • Everything is encrypted end to end, and nothing is stored anywhere.

Doing this often?

On Windows, get the OmniBeam app from the Microsoft Store to send from its own window or the Windows Share menu (how it works), and add the Chrome extension to send the page or link you're looking at in one click.

This works between any mix of Windows, Mac, Linux and Chromebook, because all it needs is a modern browser. On the same network the computers find each other by themselves; in different places, use a pairing code.

You can transfer files between two computers without a USB stick, a cable or a cloud account.

Questions and answers

Does it work between Windows and Mac?

Yes. OmniBeam works in the browser on both, so you can send from a Windows PC to a Mac, from a Mac to a Chromebook, or between any two computers.

Can I move a whole folder?

Yes. Drag the folder onto the other computer in OmniBeam. On the receiving side, the files can be saved together as one ZIP to keep the folder structure.

What about very large files?

Direct transfers have no size limit, and if the connection drops, the transfer continues where it stopped. For a whole drive, an external disk is still quicker.

Do both computers need to be on the same network?

No. On the same network they appear automatically; otherwise pair them once with a code and they find each other from then on.

Is it safe on a shared or public network?

Yes. Every transfer is encrypted end to end on the sending computer and decrypted only on the receiving one, so other people on the same network cannot read the files.

Can I copy text or links between the computers too?

Yes. Paste text into OmniBeam and send it, or turn on clipboard sync so text you copy on one computer can be sent to the other in one click.

Do I need an account on both computers?

No. There is no account, no sign-up and nothing to install. Open the page on both computers and start sending.
