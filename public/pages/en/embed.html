A “Send me files” box for your website or blog

Let visitors, clients or students send you files straight from your own page. You paste one short code; the files are encrypted on their device and arrive in OmniBeam on yours.

Steps

  1. Open omnibeam.site on the device that should receive the files, and tap Request files in the ⋯ menu.
  2. Write what you need (optional), choose 1 year (for a website) under “Link works for”, and tap Make request link.
  3. Tap Put this on your website, then Copy code.
  4. Paste the code into your page: in WordPress a Custom HTML block, in Blogger an HTML/JavaScript gadget, in Wix an Embed HTML element, in Squarespace a Code block.

Visitors see a small box with “Choose files”, an optional name field and a Send button. They need no app and no account. The files arrive on your device in Received files; if OmniBeam is closed there, they wait on the server and arrive when you open it, with a notification if you turned notifications on.

WordPress: the free OmniBeam plugin

On WordPress there is an easier way: download the OmniBeam plugin (omnibeam-wordpress.zip), then in WordPress go to Plugins → Add New → Upload Plugin, choose the zip and tap Activate. Paste your code (or just its link) in Settings → OmniBeam Box, then add the block OmniBeam: Send me files to any page, or the shortcode [omnibeam_box]. A box with its own link and height: [omnibeam_box url="https://omnibeam.site/embed/r/…" height="520"]. The plugin only accepts boxes from omnibeam.site, and the files never pass through your WordPress site.

Keep the “Powered by OmniBeam” line: it is how the box stays free.

Is it private and safe?

  • Every upload is encrypted in the visitor's browser. Its key is sealed with your device's public key, and only your device has the matching private key, so neither OmniBeam nor anyone who reads your page's code can open the files.
  • The code on your page is public. Anyone who sees it can send you files and can read the “what do you need” text and the name of your device, so don't write anything private there.
  • Only your device can download the uploads, and each one is deleted from the server as soon as it has it. Unclaimed files are deleted after 7 days.
  • The usual limits stay on: a size limit per upload, a limit per network per hour, and at most 100 uploads a day per box.
  • Delete the request link in the same window at any time and the box stops working at once.

Questions and answers

Does it cost anything?

No. The box is free, with no account and no ads. The WordPress plugin is free too.

Can I use it on several pages?

Yes. Paste the same code on every page you like; all uploads arrive on the same device. Make a separate request link if you want to tell them apart.

Why does the box stop working after a while?

Every request link ends at the time you chose. For a website choose 1 year, and make a new link and code before it ends.

Can someone use my box to send me spam?

Anyone who visits the page can send you files, as with an email address. Files never open by themselves, uploads are limited per network and per day, and you can delete the link to turn the box off.
