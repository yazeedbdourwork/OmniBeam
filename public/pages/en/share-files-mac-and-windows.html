How to share files between a Mac and a Windows PC without a USB stick

Network shares between macOS and Windows mean SMB settings, user names and firewalls. A USB stick means walking across the room. OmniBeam moves files between a Mac and a Windows PC in the browser, in a few clicks.

Steps

  1. Open omnibeam.site in Safari or Chrome on the Mac and in Edge or Chrome on the PC.
  2. On the same network, each computer shows the other. If not, pair them once with a code from the link button.
  3. Drag files or a whole folder onto the other computer, or click it to choose files.
  4. Accept on the other computer. Several files can be saved as one ZIP, and folders keep their structure.

No file sharing settings needed

Classic file sharing between Mac and Windows needs the same workgroup, an account on the other computer and the right firewall rules. OmniBeam only needs a browser on each one. The connection between the two computers is direct and encrypted, so it is also safer on a shared office network.

Make it even quicker

  • On Windows, install the free OmniBeam app from the Microsoft Store and open it from the Start menu.
  • Pair the two computers and turn on Auto-accept, so files from your own Mac arrive on the PC without a click.
  • Turn on Clipboard sync in Settings to copy text on one computer and paste it on the other.
  • Use Auto-send a folder on the PC to send every new file in a folder, such as screenshots, by itself.

It works with any mix of computers: MacBook to Windows laptop, iMac to gaming PC, or a work laptop to a home computer on another network once they are paired.

With OmniBeam you can share files between Mac and Windows over Wi‑Fi without a USB stick, cloud folder or network settings.

Questions and answers

Does it work with large video files?

Yes. There is no size limit for direct sends, and files of 1 GB and more are checked piece by piece as they arrive.

Can I send a whole folder?

Yes. Drag the folder onto the other computer. It arrives with its sub-folders, and you can save it as one ZIP.

Do the computers need to be on the same network?

Not if you pair them once. Paired computers find each other on any network, for example a laptop at home and a PC at the office.

Is it faster than iCloud Drive or OneDrive?

For one-off transfers, usually yes, because the files go directly between the computers instead of uploading to the cloud and downloading again.

Does it work on Linux too?

Yes. Any computer with a modern browser can join, including Linux and Chromebooks.

Where are received files saved?

In the Downloads folder of the browser on each computer. On a Mac that is the Downloads folder in Finder, on Windows the Downloads folder in File Explorer.

Is the connection secure on an office network?

Yes. The two computers use an encrypted connection, and only devices you pair or that are on the same network can see each other.
