Windows کے لیے OmniBeam: Microsoft Store سے مفت ایپ لیں

OmniBeam، Microsoft Store میں ہے۔ ایپ OmniBeam کو اس کی اپنی ونڈو میں کھولتی ہے، Start مینو یا ٹاسک بار سے شروع ہوتی ہے، اور Windows کے Share مینو میں نظر آتی ہے، اس لیے آپ پہلے براؤزر کھولے بغیر اپنے iPhone یا Android فون پر فائلیں بھیج سکتے ہیں۔

Microsoft Store سے OmniBeam لیں

انسٹال کریں

  1. Microsoft Store میں OmniBeam کا صفحہ کھولیں اور Get پر کلک کریں۔ یہ مفت ہے، نہ اکاؤنٹ نہ اشتہارات۔
  2. Start مینو سے OmniBeam کھولیں۔ اسے ایک کلک کی دوری پر رکھنے کے لیے ٹاسک بار پر اس کے آئیکن پر رائٹ کلک کریں اور Pin to taskbar چنیں۔

Windows 10 اور 11 پر چلتی ہے۔ ہر بار جب OmniBeam بہتر ہوتا ہے ایپ خود اپ ڈیٹ ہو جاتی ہے، اس لیے دوبارہ کچھ ڈاؤن لوڈ نہیں کرنا پڑتا۔

اپنا فون ایک بار جوڑیں

  1. فون پر omnibeam.site کھولیں۔ ایک ہی Wi‑Fi پر PC خود نظر آ جاتا ہے۔
  2. مختلف نیٹ ورک پر PC کی ایپ میں لنک بٹن پر کلک کریں اور فون کے کیمرے سے اس کا QR کوڈ اسکین کریں، یا 6 ہندسوں کا کوڈ لکھیں۔
  3. فون پر جوڑنے کی اسکرین کھولیں اور PC کے ساتھ قابل اعتماد پر نشان لگائیں، تاکہ اس کی فائلیں بغیر پوچھے آئیں۔

PC سے بھیجیں

  • ایپ میں فون پر کلک کر کے فائلیں چنیں، یا File Explorer سے فائلیں اس پر گھسیٹ کر چھوڑیں۔
  • File Explorer میں فائلیں منتخب کریں، رائٹ کلک کریں، Share اور پھر OmniBeam چنیں۔
  • لنک یا نوٹ بھیجنے کے لیے فون کی طرف اشارہ کریں اور پیغام بھیجیں چنیں۔ ترتیبات میں کلپ بورڈ ہم آہنگی آن ہو تو PC پر کاپی کیا گیا متن فون پر پہنچ جاتا ہے۔

Chrome یا Edge سے بھیجیں: OmniBeam ایکسٹینشن

ایکسٹینشن رائٹ کلک سے وہ صفحہ جس پر آپ ہیں، لنک، تصویر یا منتخب متن آپ کے فون پر بھیجتی ہے۔ اسے Chrome Web Store سے شامل کریں؛ یہ Microsoft Edge میں بھی چلتی ہے۔

ٹرے آئیکن اور Send to مینو پسند ہے؟

اگر آپ گھڑی کے ساتھ ایک آئیکن اور رائٹ کلک Send to مینو میں OmniBeam چاہتے ہیں تو پرانی ٹرے ایپ اب بھی دستیاب ہے۔ اسے Node.js 22 یا نیا چاہیے: ٹرے ایپ (ZIP) ڈاؤن لوڈ کریں، اسے ایسے فولڈر میں ان زپ کریں جو آپ رکھیں گے اور install-tray.cmd پر ڈبل کلک کریں۔ زیادہ تر لوگوں کے لیے Microsoft Store کی ایپ آسان انتخاب ہے۔

جب بھی نیٹ ورک اجازت دے فائلیں سیدھا آپ کی ڈیوائسز کے درمیان جاتی ہیں، اور ہمیشہ اینڈ ٹو اینڈ انکرپٹڈ ہوتی ہیں۔

سوالات و جوابات

ایپ اور ویب سائٹ میں کیا فرق ہے؟

دونوں ایک ہی کام کرتی ہیں۔ Microsoft Store کی ایپ Windows کے ساتھ شروع ہوتی ہے اور تیار رہتی ہے، اس لیے آپ کا فون پہلے براؤزر کھولے بغیر کسی بھی وقت PC کو بھیج سکتا ہے۔ ویب سائٹ کچھ انسٹال کیے بغیر چلتی ہے۔

کیا ایپ خود اپ ڈیٹ ہوتی ہے؟

جی ہاں۔ Microsoft Store اسے خود بخود تازہ رکھتا ہے، اس لیے آپ کے پاس ہمیشہ نیا ورژن ہوتا ہے۔

کیا میں File Explorer سے فائلیں بھیج سکتا ہوں؟

پرانی ٹرے ایپ کے ساتھ ہاں: یہ OmniBeam کو رائٹ کلک Send to مینو میں شامل کرتی ہے، اس لیے آپ فائلیں منتخب کریں، Send to اور پھر OmniBeam چنیں۔ Microsoft Store ایپ میں فائلیں ونڈو پر گھسیٹیں یا فائل چناؤ استعمال کریں۔

کیا میں ایپ ہٹا سکتا ہوں؟

جی ہاں۔ اسے کسی بھی دوسری ایپ کی طرح Windows Settings یا Start مینو سے ان انسٹال کریں۔ اگر آپ ویب سائٹ پر واپس جائیں تو آپ کی ڈیوائسز براؤزر میں جڑی رہتی ہیں۔
