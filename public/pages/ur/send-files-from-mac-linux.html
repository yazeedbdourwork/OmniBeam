Mac یا Linux PC سے رائٹ کلک کے ذریعے اپنے فون پر فائلیں بھیجیں

OmniBeam مددگار Mac پر Finder اور Linux پر فائل مینیجر کے رائٹ کلک مینو میں OmniBeam سے بھیجیں شامل کرتا ہے۔ فائلیں چنیں، اپنا فون چنیں اور وہ چلی جاتی ہیں، کمپیوٹر پر براؤزر کھولے بغیر۔

Mac اور Linux کے لیے ڈاؤن لوڈ کریں (ZIP)

Mac پر انسٹال کریں

  1. Node.js انسٹال کریں، جسے مددگار فائلیں بھیجنے کے لیے استعمال کرتا ہے۔
  2. ڈاؤن لوڈ ان زپ کریں اور install-mac.command پر ڈبل کلک کریں۔ اگر macOS اسے نہ کھولے تو رائٹ کلک کریں، Open چنیں اور پھر دوبارہ Open۔
  3. پوچھا جائے تو اپنے فون سے جوڑنے کا کوڈ لکھیں (نیچے دیکھیں)۔

پھر Finder میں فائلوں پر رائٹ کلک کریں اور Quick Actions اور Send with OmniBeam چنیں۔ کسی بھی ایپ میں منتخب متن کے لیے رائٹ کلک کریں اور Services اور Send text with OmniBeam چنیں۔ اگر یہ نظر نہ آئیں تو انہیں System Settings، Keyboard، Keyboard Shortcuts، Services میں آن کریں۔

Linux پر انسٹال کریں

  1. Node.js 18 یا نیا انسٹال کریں، مثلاً sudo apt install nodejs، اور ڈیوائس چننے کے لیے zenity (یا KDE پر kdialog)۔
  2. ڈاؤن لوڈ ان زپ کریں، اس فولڈر میں ٹرمینل کھولیں اور sh install-linux.sh چلائیں۔
  3. پوچھا جائے تو اپنے فون سے جوڑنے کا کوڈ لکھیں۔

پھر فائلوں پر رائٹ کلک کریں اور Files، Nemo یا Caja میں Scripts اور Send with OmniBeam چنیں، یا Dolphin اور Thunar میں سیدھا مینو میں Send with OmniBeam۔

اپنا فون ایک بار جوڑیں

  1. فون پر omnibeam.site کھولیں، لنک بٹن ٹیپ کریں اور جوڑنے کا کوڈ بنائیں۔
  2. وہ کوڈ کمپیوٹر پر انسٹالر میں لکھیں۔
  3. فون پر جوڑنے کی اسکرین دوبارہ کھولیں اور کمپیوٹر کے ساتھ قابل اعتماد پر نشان لگائیں، تاکہ اس کی فائلیں بغیر پوچھے آئیں۔

وصول کرنے کے لیے فون پر omnibeam.site کھلا ہونا چاہیے۔ فائلیں OmniBeam سرور سے جاتی ہیں، اینڈ ٹو اینڈ انکرپٹڈ، اس لیے سرور انہیں نہیں پڑھ سکتا۔ مینو کے اندراجات دوبارہ ہٹانے کے لیے node omnibeam-send.js --uninstall چلائیں۔

Chrome یا Edge استعمال کرتے ہیں؟ OmniBeam ایکسٹینشن Mac، Linux اور Windows پر رائٹ کلک سے صفحہ، لنک، تصویر یا منتخب متن آپ کے فون پر بھیجتی ہے۔

سوالات و جوابات

کیا رائٹ کلک مینو ہر Linux ڈیسک ٹاپ پر چلتا ہے؟

یہ عام فائل مینیجرز میں چلتا ہے: Files (Nautilus)، Nemo، Caja، Dolphin اور Thunar۔ دوسرے ڈیسک ٹاپس پر آپ پھر بھی براؤزر میں omnibeam.site کھول کر فائلیں اس میں گھسیٹ سکتے ہیں۔

کیا میں بعد میں مینو آئٹمز ہٹا سکتا ہوں؟

جی ہاں۔ مددگار کے فولڈر میں node omnibeam-send.js --uninstall چلائیں، اور اندراجات رائٹ کلک مینو سے غائب ہو جاتے ہیں۔

کیا یہ iPhone اور Android پر بھیجتا ہے؟

جی ہاں۔ یہ اس فون پر بھیجتا ہے جسے آپ نے کوڈ سے جوڑا، چاہے وہ iPhone ہو یا Android فون، ایک ہی Wi‑Fi پر ہو یا موبائل ڈیٹا پر، جب تک فون پر omnibeam.site کھلا ہو۔

مددگار کو Node.js کیوں چاہیے؟

مددگار ایک چھوٹا اسکرپٹ ہے جو Node.js سے چلتا ہے۔ یہ ایک بار آپ کے فون سے جڑتا ہے اور پھر کمپیوٹر پر براؤزر کھولے بغیر آپ کی چنی ہوئی فائلیں بھیجتا ہے، جس سے رائٹ کلک کا عمل تیز رہتا ہے۔

کیا میں منتخب متن بھی بھیج سکتا ہوں؟

Mac پر ہاں: کسی بھی ایپ میں متن منتخب کریں، رائٹ کلک کریں اور Services، پھر Send text with OmniBeam چنیں۔ یہ فون پر کاپی کے لیے تیار پہنچتا ہے۔

کیا فائلیں انکرپٹڈ ہیں؟

جی ہاں۔ یہ کمپیوٹر پر اینڈ ٹو اینڈ انکرپٹ ہوتی ہیں، اور سرور انہیں پڑھے بغیر صرف آگے بڑھاتا ہے۔
