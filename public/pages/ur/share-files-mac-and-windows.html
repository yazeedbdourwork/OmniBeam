USB اسٹک کے بغیر Mac اور Windows PC کے درمیان فائلیں کیسے شیئر کریں

macOS اور Windows کے درمیان نیٹ ورک شیئرز کا مطلب ہے SMB سیٹنگز، یوزر نیمز اور فائر والز۔ USB اسٹک کا مطلب ہے کمرے میں آنا جانا۔ OmniBeam، Mac اور Windows PC کے درمیان براؤزر میں چند کلکس میں فائلیں منتقل کرتا ہے۔

طریقہ

  1. Mac پر Safari یا Chrome میں اور PC پر Edge یا Chrome میں omnibeam.site کھولیں۔
  2. ایک ہی نیٹ ورک پر ہر کمپیوٹر دوسرے کو دکھاتا ہے۔ ورنہ لنک بٹن کے کوڈ سے انہیں ایک بار جوڑ لیں۔
  3. فائلیں یا پورا فولڈر دوسرے کمپیوٹر پر گھسیٹ کر چھوڑیں، یا فائلیں چننے کے لیے اس پر کلک کریں۔
  4. دوسرے کمپیوٹر پر قبول کریں۔ کئی فائلیں ایک ZIP کے طور پر محفوظ ہو سکتی ہیں، اور فولڈرز اپنی ترتیب برقرار رکھتے ہیں۔

فائل شیئرنگ کی کوئی سیٹنگ نہیں چاہیے

Mac اور Windows کے درمیان روایتی فائل شیئرنگ کے لیے ایک ہی ورک گروپ، دوسرے کمپیوٹر پر اکاؤنٹ اور صحیح فائر وال اصول چاہیے۔ OmniBeam کو ہر ایک پر صرف ایک براؤزر چاہیے۔ دونوں کمپیوٹرز کے درمیان کنکشن براہ راست اور انکرپٹڈ ہے، اس لیے یہ مشترکہ دفتری نیٹ ورک پر بھی زیادہ محفوظ ہے۔

اسے اور جلدی بنائیں

  • Windows پر Microsoft Store سے مفت OmniBeam ایپ انسٹال کریں اور اسے Start مینو سے کھولیں۔
  • دونوں کمپیوٹرز جوڑیں اور "خودکار قبولیت" آن کریں، تاکہ آپ کے اپنے Mac کی فائلیں بغیر کلک کے PC پر آئیں۔
  • سیٹنگز میں کلپ بورڈ ہم آہنگی آن کریں تاکہ ایک کمپیوٹر پر متن کاپی کر کے دوسرے پر پیسٹ کر سکیں۔
  • PC پر "فولڈر خودکار بھیجیں" استعمال کریں تاکہ کسی فولڈر کی ہر نئی فائل، جیسے اسکرین شاٹس، خود بھیجی جائے۔

یہ کمپیوٹرز کے کسی بھی امتزاج کے ساتھ چلتا ہے: MacBook سے Windows لیپ ٹاپ، iMac سے گیمنگ PC، یا جوڑنے کے بعد کسی دوسرے نیٹ ورک پر دفتر کا لیپ ٹاپ اور گھر کا کمپیوٹر۔

OmniBeam سے آپ USB اسٹک، کلاؤڈ فولڈر یا نیٹ ورک سیٹنگز کے بغیر Wi‑Fi پر Mac اور Windows کے درمیان فائلیں شیئر کر سکتے ہیں۔

سوالات و جوابات

کیا یہ بڑی ویڈیو فائلوں کے ساتھ چلتا ہے؟

جی ہاں۔ براہ راست بھیجنے کی کوئی سائز حد نہیں، اور 1 GB اور اس سے بڑی فائلیں پہنچتے ہوئے ٹکڑا ٹکڑا جانچی جاتی ہیں۔

کیا میں پورا فولڈر بھیج سکتا ہوں؟

جی ہاں۔ فولڈر کو دوسرے کمپیوٹر پر گھسیٹ کر چھوڑیں۔ یہ اپنے ذیلی فولڈرز کے ساتھ پہنچتا ہے، اور آپ اسے ایک ZIP کے طور پر محفوظ کر سکتے ہیں۔

کیا کمپیوٹرز کا ایک ہی نیٹ ورک پر ہونا ضروری ہے؟

اگر آپ انہیں ایک بار جوڑ لیں تو نہیں۔ جڑے ہوئے کمپیوٹر کسی بھی نیٹ ورک پر ایک دوسرے کو ڈھونڈ لیتے ہیں، مثلاً گھر پر لیپ ٹاپ اور دفتر میں PC۔

کیا یہ iCloud Drive یا OneDrive سے تیز ہے؟

ایک بار کی منتقلی کے لیے عام طور پر ہاں، کیونکہ فائلیں کلاؤڈ پر اپ لوڈ اور دوبارہ ڈاؤن لوڈ ہونے کی بجائے سیدھا کمپیوٹرز کے درمیان جاتی ہیں۔

کیا یہ Linux پر بھی چلتا ہے؟

جی ہاں۔ جدید براؤزر والا کوئی بھی کمپیوٹر شامل ہو سکتا ہے، Linux اور Chromebooks سمیت۔

موصول فائلیں کہاں محفوظ ہوتی ہیں؟

ہر کمپیوٹر پر براؤزر کے Downloads فولڈر میں۔ Mac پر یہ Finder کا Downloads فولڈر ہے، اور Windows پر File Explorer کا Downloads فولڈر۔

کیا دفتری نیٹ ورک پر کنکشن محفوظ ہے؟

جی ہاں۔ دونوں کمپیوٹر انکرپٹڈ کنکشن استعمال کرتے ہیں، اور صرف وہی ڈیوائسز ایک دوسرے کو دیکھ سکتی ہیں جو آپ جوڑیں یا جو ایک ہی نیٹ ورک پر ہوں۔
