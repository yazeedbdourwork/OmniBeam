آپ کی ویب سائٹ یا بلاگ کے لیے "مجھے فائلیں بھیجیں" باکس

وزیٹرز، کلائنٹس یا طلبہ کو سیدھا اپنے صفحے سے آپ کو فائلیں بھیجنے دیں۔ آپ ایک مختصر کوڈ پیسٹ کرتے ہیں؛ فائلیں ان کی ڈیوائس پر انکرپٹ ہوتی ہیں اور آپ کی ڈیوائس پر OmniBeam میں پہنچتی ہیں۔

طریقہ

  1. جس ڈیوائس پر فائلیں وصول کرنی ہیں اس پر omnibeam.site کھولیں، اور ⋯ مینو میں فائلیں مانگیں ٹیپ کریں۔
  2. لکھیں کہ آپ کو کیا چاہیے (اختیاری)، "لنک کی مدت" میں 1 سال (ویب سائٹ کے لیے) چنیں، اور درخواست کا لنک بنائیں ٹیپ کریں۔
  3. اسے اپنی ویب سائٹ پر لگائیں ٹیپ کریں، پھر کوڈ کاپی کریں۔
  4. کوڈ اپنے صفحے میں پیسٹ کریں: WordPress میں Custom HTML بلاک، Blogger میں HTML/JavaScript گیجٹ، Wix میں Embed HTML عنصر، Squarespace میں Code بلاک۔

وزیٹرز کو ایک چھوٹا باکس نظر آتا ہے جس میں "فائلیں چنیں"، نام کا اختیاری خانہ اور بھیجیں بٹن ہوتا ہے۔ انہیں نہ ایپ چاہیے نہ اکاؤنٹ۔ فائلیں آپ کی ڈیوائس پر "موصول شدہ فائلیں" میں پہنچتی ہیں؛ اگر وہاں OmniBeam بند ہو تو وہ سرور پر انتظار کرتی ہیں اور جب آپ اسے کھولیں تب پہنچتی ہیں، اور اگر اطلاعات آن ہوں تو اطلاع بھی آتی ہے۔
