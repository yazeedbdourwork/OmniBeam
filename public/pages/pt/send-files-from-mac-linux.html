Envie arquivos de um Mac ou PC Linux para o celular com o clique direito

O assistente do OmniBeam adiciona Send with OmniBeam ao menu do clique direito do Finder no Mac e do gerenciador de arquivos no Linux. Escolha os arquivos e o celular, e eles são enviados sem abrir o navegador no computador.

Baixar para Mac e Linux (ZIP)

Instalação no Mac

  1. Instale o Node.js, que o assistente usa para enviar arquivos.
  2. Descompacte o download e clique duas vezes em install-mac.command. Se o macOS não abrir, clique com o botão direito, escolha Abrir e depois Abrir de novo.
  3. Digite o código de pareamento do seu celular quando for pedido (veja abaixo).

Depois clique com o botão direito nos arquivos no Finder e escolha Ações Rápidas e Send with OmniBeam. Para um texto selecionado em qualquer app, clique com o botão direito e escolha Serviços e Send text with OmniBeam. Se não aparecerem, ative-os em Ajustes do Sistema, Teclado, Atalhos de Teclado, Serviços.

Instalação no Linux

  1. Instale o Node.js 18 ou mais recente, por exemplo sudo apt install nodejs, e o zenity (ou kdialog no KDE) para escolher o dispositivo.
  2. Descompacte o download, abra um terminal nessa pasta e rode sh install-linux.sh.
  3. Digite o código de pareamento do seu celular quando for pedido.

Depois clique com o botão direito nos arquivos e escolha Scripts e Send with OmniBeam no Files, Nemo ou Caja, ou Send with OmniBeam direto no menu do Dolphin e do Thunar.

Pareie o celular uma vez

  1. No celular, abra omnibeam.site, toque no botão de link e em Criar um código de pareamento.
  2. Digite esse código no instalador do computador.
  3. No celular, abra a tela de pareamento de novo e marque Confiável ao lado do computador, para que os arquivos dele cheguem sem perguntar.

O celular precisa estar com omnibeam.site aberto para receber. Os arquivos passam pelo servidor do OmniBeam, criptografados de ponta a ponta, então o servidor não consegue lê-los. Para remover os itens do menu, rode node omnibeam-send.js --uninstall.

Usa Chrome ou Edge? A extensão do OmniBeam envia para o celular a página, um link, uma imagem ou o texto selecionado com o botão direito, no Mac, Linux e Windows.

Envie arquivos também sem o clique direito, abrindo omnibeam.site no Mac ou no Linux.

Perguntas e respostas

O menu do botão direito funciona em todos os desktops Linux?

Funciona nos gerenciadores de arquivos mais comuns: Arquivos (Nautilus), Nemo, Caja, Dolphin e Thunar. Em outros desktops, você ainda pode abrir omnibeam.site no navegador e arrastar os arquivos.

Posso remover os itens do menu depois?

Sim. Rode node omnibeam-send.js --uninstall na pasta da ferramenta, e os itens somem do menu do botão direito.

Envia para iPhone e Android?

Sim. Envia para o celular que você pareou com o código, seja iPhone ou Android, no mesmo Wi‑Fi ou nos dados móveis, desde que omnibeam.site esteja aberto no celular.

Por que a ferramenta precisa do Node.js?

Ela é um pequeno script que roda com Node.js. Ela se pareia uma vez com o seu celular e depois envia os arquivos escolhidos sem abrir navegador no computador, o que deixa o botão direito rápido.

Posso enviar texto selecionado também?

No Mac, sim: selecione um texto em qualquer app, clique com o botão direito e escolha Serviços e depois Send text with OmniBeam. Ele chega ao celular pronto para copiar.

Os arquivos são criptografados?

Sim. Eles são criptografados de ponta a ponta no computador, e o servidor só os repassa sem conseguir lê-los.
