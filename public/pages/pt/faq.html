OmniBeam: perguntas frequentes

O OmniBeam é um site gratuito para enviar arquivos, fotos, vídeos e texto entre dois aparelhos quaisquer, como um iPhone e um PC com Windows. Abra omnibeam.site nos dois e envie. Não há app para instalar nem conta, e cada transferência é criptografada de ponta a ponta.

O básico

O que é o OmniBeam?

O OmniBeam é uma forma de enviar arquivos entre seus aparelhos pelo navegador, como o AirDrop, mas para todas as marcas. Funciona em iPhone, iPad, Android, Windows, Mac, Linux e Chromebook, no Safari, Chrome, Edge, Firefox e outros navegadores modernos.

O OmniBeam é grátis?

Sim. Enviar arquivos, os links, o chat e todos os outros recursos são grátis, sem conta e sem anúncios. Quem quiser apoiar o projeto pode doar e receber um selo de apoiador com temas extras, mas nada fica bloqueado.

Preciso instalar um app?

Não. O OmniBeam funciona no navegador. Se quiser, você pode adicioná-lo à tela inicial do celular, instalá-lo pela Microsoft Store no Windows ou adicionar a extensão do Chrome, Edge ou Firefox, mas o site sozinho faz tudo.

Preciso criar uma conta?

Não. Não há cadastro, e-mail nem senha. Cada aparelho só recebe um nome, que você pode mudar.

Como envio um arquivo?

Abra omnibeam.site nos dois aparelhos. No mesmo Wi‑Fi eles se veem depois de um instante. Toque no outro aparelho, escolha os arquivos e aceite no outro aparelho. Os arquivos passam direto.

Redes e aparelhos

Os dois aparelhos precisam estar no mesmo Wi‑Fi?

Não. No mesmo Wi‑Fi eles se encontram sozinhos. Em redes diferentes, como um celular nos dados móveis, pareie uma vez com um código de 6 dígitos ou lendo um QR code. Depois disso, os aparelhos pareados se encontram onde estiverem.

Posso enviar do iPhone para Windows ou Android?

Sim. É para isso que o OmniBeam foi feito: iPhone para PC, Android para iPhone, Android para Mac, Mac para Windows e qualquer outra combinação. Os passos são os mesmos em todos os aparelhos.

Funciona sem internet?

Os aparelhos precisam de conexão com omnibeam.site para se encontrar. No mesmo Wi‑Fi, o arquivo em si depois vai direto pela sua rede local.

Privacidade e segurança

O OmniBeam é seguro?

Sim. Cada transferência é criptografada de ponta a ponta no aparelho que envia, e só o aparelho que recebe consegue descriptografar. Os arquivos vão direto entre os aparelhos sempre que possível. Quando não dá, os dados criptografados passam por um relay que não consegue lê-los. Nada de uma transferência ao vivo é guardado, e cada arquivo precisa ser aceito no aparelho que recebe.

O OmniBeam guarda meus arquivos?

Não. Transferências ao vivo nunca são salvas em servidor. Só os arquivos que você compartilha por link, ou que alguém envia por um pedido de arquivos, ficam guardados, criptografados, e são apagados quando o link expira.

O OmniBeam é de código aberto?

Sim. O código-fonte está no GitHub com licença GPL-3.0, então qualquer pessoa pode conferir como funciona.

Arquivos e limites

Existe limite de tamanho?

Não nos envios diretos: o OmniBeam não impõe limite, e no Chrome, Edge e Firefox arquivos grandes são gravados direto no disco. Os links compartilhados têm um tamanho máximo, mostrado no app, porque esses arquivos ficam guardados até o link expirar.

Fotos e vídeos vão em qualidade total?

Sim, por padrão vão os arquivos originais. Você pode escolher Fotos menores ou Vídeos menores para economizar tempo ou espaço, e as fotos HEIC do iPhone podem ser salvas como JPG.

O que acontece se a conexão cair?

A transferência continua de onde parou em vez de recomeçar, pela conexão direta quando ela volta ou pelo relay criptografado.

Posso enviar para alguém que não está online agora?

Sim. Compartilhe os arquivos por um link criptografado que vale 7 dias por padrão, ou até 30. Você pode adicionar um PIN e pedir ao OmniBeam que envie o link por e-mail.

Muito mais do que enviar arquivos

Posso conversar ou ligar com o OmniBeam?

Sim. Dispositivos pareados podem conversar, enviar mensagens de voz, criar um chat em grupo e fazer chamadas de voz ou vídeo, tudo com criptografia de ponta a ponta. Você também pode compartilhar a tela, desenhar junto em um quadro branco compartilhado e manter notas e listas de tarefas compartilhadas.

Como sei que pareei com o dispositivo certo?

Em Mais… de um dispositivo, toque em Código de segurança. Os dois dispositivos mostram os mesmos 12 dígitos quando estão conectados diretamente um ao outro. Se os códigos forem diferentes, não envie nada e conecte de novo.

O OmniBeam pode fazer backup das fotos do meu celular no computador?

Sim. O backup de fotos envia as fotos novas do celular para um computador pareado e pula as que já foram enviadas. Você pode ativar o backup automático, para que aconteça sempre que o OmniBeam estiver aberto nos dois.

Comparado a outras ferramentas

Qual a diferença para o AirDrop?

O AirDrop só funciona entre aparelhos Apple próximos. O OmniBeam funciona entre todas as marcas e entre redes diferentes, no navegador. Veja OmniBeam vs AirDrop.

Qual a diferença para o WeTransfer?

O WeTransfer primeiro envia seus arquivos para os servidores dele. O OmniBeam manda direto de aparelho para aparelho, sem limite de tamanho, e também pode criar um link criptografado. Veja OmniBeam vs WeTransfer.

E para Snapdrop, PairDrop ou LocalSend?

Todos enviam arquivos numa rede local. O OmniBeam acrescenta pareamento entre redes, links criptografados, retomada após queda, chat e apps para Windows e navegadores. As comparações explicam ponto a ponto.
