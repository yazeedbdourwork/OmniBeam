AirDrop para Windows e Android: a alternativa no navegador

O AirDrop só funciona entre dispositivos Apple. O OmniBeam traz a mesma ideia de tocar e enviar para qualquer dispositivo, porque roda no navegador.

O que você ganha

  • Dispositivos no mesmo Wi‑Fi se encontram automaticamente, como no AirDrop.
  • Funciona entre iPhone, iPad, Mac, Windows, Android, Linux e Chromebook.
  • Os arquivos vão direto de um dispositivo para o outro e são criptografados de ponta a ponta.
  • Sem limite de tamanho nas transferências diretas, sem conta e nada para instalar.
  • Dispositivos em redes diferentes podem ser pareados uma vez com um código de 6 dígitos.

AirDrop comparado com o OmniBeam

  • Dispositivos: o AirDrop é só para Apple; o OmniBeam funciona em qualquer dispositivo com um navegador moderno.
  • Distância: o AirDrop exige os dispositivos por perto; o OmniBeam também funciona pela internet.
  • Compartilhar com outras pessoas: o OmniBeam também cria um link criptografado que qualquer pessoa pode abrir depois.

Mais detalhes em OmniBeam vs AirDrop.

Use como um app

Instale o OmniBeam pelo navegador (Instalar no Chrome ou Edge, Adicionar à Tela de Início no iPhone). No Windows, baixe o app grátis do OmniBeam na Microsoft Store; veja OmniBeam para Windows.

Ao contrário do AirDrop, o OmniBeam não precisa de Bluetooth nem de conta Apple. Basta um navegador em cada aparelho, e toda transferência é criptografada de ponta a ponta, então os arquivos continuam privados mesmo quando passam pelo servidor de retransmissão.

O OmniBeam é uma alternativa grátis ao AirDrop para Windows e Android.

Perguntas e respostas

Existe um AirDrop oficial para Windows ou Android?

Não. O AirDrop vem só nos aparelhos Apple, e a Apple não o lançou para Windows ou Android. Para compartilhar tão rápido entre um iPhone e um PC ou um celular Android, você precisa de uma ferramenta que funcione dos dois lados, como o OmniBeam no navegador.

O OmniBeam é parecido com o AirDrop?

Muito, no dia a dia: aparelhos no mesmo Wi‑Fi aparecem sozinhos, você toca em um, escolhe os arquivos e o outro aparelho aceita. As diferenças são que o OmniBeam roda em uma aba do navegador, e não no menu do sistema, e que também funciona entre redes diferentes depois de parear uma vez.

Posso enviar para um PC com Windows sem navegador aberto?

A página precisa estar aberta no aparelho que recebe, assim como o AirDrop precisa que o receptor esteja ativo e visível. No Windows, o app gratuito OmniBeam da Microsoft Store facilita: ele abre junto com o PC, então os arquivos podem chegar sem abrir o navegador antes.

Funciona com fotos do iPhone?

Sim. Fotos e vídeos chegam em qualidade total, e as fotos HEIC do iPhone podem ser salvas como JPG para abrir em qualquer PC com Windows ou celular Android.

É seguro?

Cada transferência é criptografada de ponta a ponta no seu aparelho, e nada fica guardado em servidor no caminho.

Vários aparelhos podem receber ao mesmo tempo?

Sim. Use “Enviar para todos” para mandar os mesmos arquivos a todos os aparelhos abertos, ou entre em uma sala pública para que um grupo de celulares e computadores compartilhe entre si. É prático em sala de aula ou em reuniões, onde o AirDrop só alcançaria os aparelhos Apple.

Funciona sem internet?

Os aparelhos precisam de internet para se encontrar, mesmo que os arquivos passem direto pelo seu Wi‑Fi sempre que possível.
