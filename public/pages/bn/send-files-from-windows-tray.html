Windows-এর জন্য OmniBeam: Microsoft Store থেকে ফ্রি অ্যাপটি নিন

OmniBeam Microsoft Store-এ আছে। অ্যাপটি OmniBeam-কে নিজস্ব উইন্ডোতে খোলে, Start মেনু বা টাস্কবার থেকে চালু হয়, আর Windows-এর Share মেনুতে দেখা যায়, তাই আগে ব্রাউজার না খুলেই আপনার iPhone বা Android ফোনে ফাইল পাঠাতে পারবেন।

Microsoft Store থেকে OmniBeam নিন

ইনস্টল

  1. Microsoft Store-এ OmniBeam-এর পেজ খুলে Get ক্লিক করুন। এটি ফ্রি, কোনো অ্যাকাউন্ট বা বিজ্ঞাপন নেই।
  2. Start মেনু থেকে OmniBeam খুলুন। এক ক্লিক দূরে রাখতে টাস্কবারে এর আইকনে ডান-ক্লিক করে Pin to taskbar বেছে নিন।

Windows 10 ও 11-এ কাজ করে। OmniBeam যতবার উন্নত হয়, অ্যাপটি নিজে থেকেই আপডেট হয়, তাই আবার কিছু ডাউনলোড করতে হয় না।

একবার আপনার ফোন পেয়ার করুন

  1. ফোনে omnibeam.site খুলুন। একই Wi‑Fi-তে PC নিজে থেকেই দেখা যায়।
  2. ভিন্ন নেটওয়ার্কে PC-র অ্যাপে লিংক বাটনে ক্লিক করে ফোনের ক্যামেরা দিয়ে এর QR কোড স্ক্যান করুন, অথবা 6-সংখ্যার কোডটি লিখুন।
  3. ফোনে পেয়ার স্ক্রিন খুলে PC-র পাশে বিশ্বস্ত-এ টিক দিন, তাহলে এর ফাইল জিজ্ঞেস ছাড়াই আসবে।

PC থেকে পাঠান

  • অ্যাপে ফোনটিতে ক্লিক করে ফাইল বেছে নিন, অথবা File Explorer থেকে ফাইল টেনে এর ওপর ছাড়ুন।
  • File Explorer-এ ফাইল বাছাই করে ডান-ক্লিক করুন, Share বেছে নিয়ে তারপর OmniBeam।
  • লিংক বা নোট পাঠাতে ফোনের ওপর মাউস রেখে মেসেজ পাঠান বেছে নিন। সেটিংসে ক্লিপবোর্ড সিঙ্ক চালু থাকলে PC-তে কপি করা টেক্সট ফোনে চলে আসে।

Chrome বা Edge থেকে পাঠান: OmniBeam এক্সটেনশন

এক্সটেনশনটি ডান-ক্লিকে খোলা পেজ, লিংক, ছবি বা বাছাই করা টেক্সট আপনার ফোনে পাঠায়। Chrome Web Store থেকে যোগ করুন; এটি Microsoft Edge-এও কাজ করে।

ট্রে আইকন আর Send to মেনু পছন্দ?

ঘড়ির পাশে একটি আইকন আর ডান-ক্লিকের Send to মেনুতে OmniBeam চাইলে পুরোনো ট্রে অ্যাপটি এখনো পাওয়া যায়। এর জন্য Node.js 22 বা নতুন সংস্করণ লাগে: ট্রে অ্যাপটি ডাউনলোড করুন (ZIP), যে ফোল্ডার রেখে দেবেন তাতে আনজিপ করুন এবং install-tray.cmd-এ ডাবল-ক্লিক করুন। বেশিরভাগ মানুষের জন্য Microsoft Store অ্যাপটিই সহজ।

নেটওয়ার্ক অনুমতি দিলেই ফাইল সরাসরি আপনার ডিভাইসগুলোর মধ্যে যায়, আর সবসময় এন্ড-টু-এন্ড এনক্রিপ্ট করা থাকে।

প্রশ্ন ও উত্তর

অ্যাপ আর ওয়েবসাইটের মধ্যে পার্থক্য কী?

দুটি একই কাজ করে। Microsoft Store অ্যাপটি Windows-এর সাথে চালু হয়ে প্রস্তুত থাকে, তাই আগে ব্রাউজার না খুলেই আপনার ফোন যেকোনো সময় PC-তে পাঠাতে পারে। ওয়েবসাইট কিছু ইনস্টল ছাড়াই কাজ করে।

অ্যাপটি কি নিজে থেকে আপডেট হয়?

হ্যাঁ। Microsoft Store এটিকে নিজে থেকেই হালনাগাদ রাখে, তাই আপনার কাছে সবসময় সর্বশেষ সংস্করণ থাকে।

File Explorer থেকে কি ফাইল পাঠানো যায়?

পুরোনো ট্রে অ্যাপ দিয়ে, হ্যাঁ: এটি ডান-ক্লিকের Send to মেনুতে OmniBeam যোগ করে, তাই ফাইল বাছাই করে Send to, তারপর OmniBeam বেছে নিন। Microsoft Store অ্যাপে উইন্ডোর ওপর ফাইল টেনে ছাড়ুন বা ফাইল পিকার ব্যবহার করুন।

অ্যাপটি কি সরানো যায়?

হ্যাঁ। অন্য যেকোনো অ্যাপের মতো Windows Settings বা Start মেনু থেকে আনইনস্টল করুন। ওয়েবসাইটে ফিরে গেলে আপনার ডিভাইসগুলো ব্রাউজারে পেয়ার হয়েই থাকে।
