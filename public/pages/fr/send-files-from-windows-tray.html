OmniBeam pour Windows : l'application gratuite du Microsoft Store

OmniBeam est dans le Microsoft Store. L'application ouvre OmniBeam dans sa propre fenêtre, se lance depuis le menu Démarrer ou la barre des tâches et apparaît dans le menu Partager de Windows : vous envoyez des fichiers vers votre iPhone ou Android sans ouvrir le navigateur.

Obtenir OmniBeam dans le Microsoft Store

Installer

  1. Ouvrez la page OmniBeam du Microsoft Store et cliquez sur Obtenir. C'est gratuit, sans compte et sans publicité.
  2. Ouvrez OmniBeam depuis le menu Démarrer. Pour l'avoir à portée de clic, faites un clic droit sur son icône dans la barre des tâches et choisissez Épingler à la barre des tâches.

Fonctionne sous Windows 10 et 11. L'application se met à jour toute seule à chaque amélioration d'OmniBeam : rien à retélécharger.

Associer votre téléphone une fois

  1. Sur le téléphone, ouvrez omnibeam.site. Sur le même Wi‑Fi, le PC apparaît tout seul.
  2. Sur un autre réseau, cliquez sur le bouton lien dans l'application sur le PC et scannez son code QR avec l'appareil photo du téléphone, ou tapez le code à 6 chiffres.
  3. Sur le téléphone, ouvrez l'écran d'association et cochez De confiance à côté du PC, pour que ses fichiers arrivent sans confirmation.

Envoyer depuis le PC

  • Cliquez sur le téléphone dans l'application et choisissez des fichiers, ou glissez-y des fichiers depuis l'Explorateur.
  • Dans l'Explorateur de fichiers, sélectionnez des fichiers, faites un clic droit, choisissez Partager puis OmniBeam.
  • Pour envoyer un lien ou une note, pointez le téléphone et choisissez Envoyer un message. Avec la synchronisation du presse-papiers activée dans les Réglages, le texte copié sur le PC arrive sur le téléphone.

Envoyer depuis Chrome ou Edge : l'extension OmniBeam

L'extension envoie la page ouverte, un lien, une image ou le texte sélectionné vers votre téléphone d'un clic droit. Ajoutez-la depuis le Chrome Web Store ; elle fonctionne aussi dans Microsoft Edge.

Vous préférez une icône près de l'horloge et le menu Envoyer vers ?

L'ancienne application pour la barre des tâches reste disponible si vous voulez une icône près de l'horloge et OmniBeam dans le menu clic droit Envoyer vers. Elle nécessite Node.js 22 ou plus récent : téléchargez l'application (ZIP), décompressez-la dans un dossier que vous garderez et double-cliquez sur install-tray.cmd. Pour la plupart des gens, l'application du Microsoft Store est plus simple.

Les fichiers passent directement entre vos appareils dès que le réseau le permet, et sont toujours chiffrés de bout en bout.

Questions et réponses

Quelle différence entre l’application et le site ?

Elles font la même chose. L’application du Microsoft Store démarre avec Windows et reste prête : votre téléphone peut envoyer au PC à tout moment sans ouvrir de navigateur. Le site fonctionne sans rien installer.

L’application se met-elle à jour toute seule ?

Oui. Le Microsoft Store la met à jour automatiquement, vous avez donc toujours la dernière version.

Puis-je envoyer des fichiers depuis l’Explorateur ?

Avec l’ancienne application de la zone de notification, oui : elle ajoute OmniBeam au menu Envoyer vers du clic droit. Dans l’application du Microsoft Store, glissez les fichiers dans la fenêtre ou utilisez le sélecteur de fichiers.

Puis-je désinstaller l’application ?

Oui, comme n’importe quelle application, depuis les Paramètres de Windows ou le menu Démarrer. Vos appareils restent appairés dans le navigateur si vous revenez au site.
