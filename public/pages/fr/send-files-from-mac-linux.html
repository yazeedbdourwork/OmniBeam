Envoyer des fichiers d'un Mac ou d'un PC Linux vers votre téléphone en un clic droit

L'outil OmniBeam ajoute Send with OmniBeam au menu clic droit du Finder sur Mac et du gestionnaire de fichiers sous Linux. Choisissez des fichiers, puis votre téléphone, et ils partent, sans ouvrir le navigateur sur l'ordinateur.

Télécharger pour Mac et Linux (ZIP)

Installer sur Mac

  1. Installez Node.js, que l'outil utilise pour envoyer les fichiers.
  2. Décompressez le téléchargement et double-cliquez sur install-mac.command. Si macOS refuse de l'ouvrir, faites un clic droit dessus, choisissez Ouvrir puis encore Ouvrir.
  3. Saisissez le code d'association de votre téléphone quand il est demandé (voir plus bas).

Ensuite, faites un clic droit sur des fichiers dans le Finder et choisissez Actions rapides puis Send with OmniBeam. Pour du texte sélectionné dans n'importe quelle app, clic droit, Services puis Send text with OmniBeam. S'ils n'apparaissent pas, activez-les dans Réglages Système, Clavier, Raccourcis clavier, Services.

Installer sous Linux

  1. Installez Node.js 18 ou plus récent, par exemple sudo apt install nodejs, ainsi que zenity (ou kdialog sous KDE) pour choisir l'appareil.
  2. Décompressez le téléchargement, ouvrez un terminal dans ce dossier et lancez sh install-linux.sh.
  3. Saisissez le code d'association de votre téléphone quand il est demandé.

Ensuite, clic droit sur des fichiers, Scripts puis Send with OmniBeam dans Fichiers, Nemo ou Caja, ou directement Send with OmniBeam dans Dolphin et Thunar.

Associer votre téléphone une fois

  1. Sur le téléphone, ouvrez omnibeam.site, touchez le bouton lien puis Créer un code d'association.
  2. Saisissez ce code dans l'installateur sur l'ordinateur.
  3. Sur le téléphone, rouvrez l'écran d'association et cochez De confiance à côté de l'ordinateur, pour que ses fichiers arrivent sans demande.

Le téléphone doit avoir omnibeam.site ouvert pour recevoir. Les fichiers passent par le serveur OmniBeam, chiffrés de bout en bout : le serveur ne peut pas les lire. Pour retirer les entrées du menu, lancez node omnibeam-send.js --uninstall.

Vous utilisez Chrome ou Edge ? L'extension OmniBeam envoie la page, un lien, une image ou le texte sélectionné vers votre téléphone d'un clic droit, sur Mac, Linux et Windows.

Vous pouvez aussi envoyer depuis Mac ou Linux sans clic droit, en ouvrant simplement omnibeam.site.

Questions et réponses

Le menu du clic droit marche-t-il sur tous les bureaux Linux ?

Il marche dans les gestionnaires de fichiers courants : Fichiers (Nautilus), Nemo, Caja, Dolphin et Thunar. Sur les autres bureaux, vous pouvez toujours ouvrir omnibeam.site dans le navigateur et y glisser les fichiers.

Puis-je retirer les entrées du menu plus tard ?

Oui. Lancez node omnibeam-send.js --uninstall dans le dossier de l’outil, et les entrées disparaissent du menu du clic droit.

Est-ce que ça envoie vers iPhone et Android ?

Oui. L’outil envoie vers le téléphone appairé avec le code, iPhone ou Android, sur le même Wi‑Fi ou en données mobiles, tant qu’omnibeam.site est ouvert sur le téléphone.

Pourquoi l’outil a-t-il besoin de Node.js ?

C’est un petit script qui tourne avec Node.js. Il s’appaire une fois avec votre téléphone puis envoie les fichiers choisis sans ouvrir de navigateur sur l’ordinateur, ce qui garde le clic droit rapide.

Puis-je aussi envoyer du texte sélectionné ?

Sur Mac, oui : sélectionnez du texte dans n’importe quelle app, faites un clic droit et choisissez Services, puis Send text with OmniBeam. Il arrive sur le téléphone, prêt à être copié.

Les fichiers sont-ils chiffrés ?

Oui. Ils sont chiffrés de bout en bout sur l’ordinateur, et le serveur ne fait que les transmettre sans pouvoir les lire.
