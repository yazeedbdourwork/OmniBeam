Comment transférer des fichiers entre deux ordinateurs sans clé USB

Copier sur une clé, s'envoyer un e‑mail ou passer par le cloud prend deux fois plus de temps que nécessaire. OmniBeam envoie les fichiers directement d'un ordinateur à l'autre : Windows, Mac, Linux ou Chromebook, dans n'importe quelle combinaison.

Étapes

  1. Ouvrez omnibeam.site dans un navigateur sur les deux ordinateurs.
  2. Sur le même réseau, ils apparaissent automatiquement. Sinon, cliquez sur le bouton d'appairage sur l'un et saisissez le code à 6 chiffres sur l'autre.
  3. Glissez des fichiers ou des dossiers entiers sur la carte de l'autre ordinateur, ou cliquez dessus pour choisir des fichiers.
  4. Acceptez sur l'autre ordinateur. Les dossiers gardent leur structure et peuvent être enregistrés en un seul ZIP.

Pourquoi c'est rapide

  • Les fichiers passent directement entre les deux ordinateurs par votre réseau, pas par un serveur cloud.
  • Aucune limite de taille, et les gros transferts reprennent tout seuls si la connexion coupe.
  • Tout est chiffré de bout en bout, et rien n'est stocké nulle part.

Vous le faites souvent ?

Sous Windows, installez l'application OmniBeam du Microsoft Store pour envoyer depuis sa fenêtre ou le menu Partager de Windows (comment ça marche), et ajoutez l'extension Chrome pour envoyer la page ou le lien que vous regardez en un clic.

Cela marche entre Windows, Mac, Linux et Chromebook dans n'importe quelle combinaison, car il suffit d'un navigateur récent. Sur le même réseau, les ordinateurs se trouvent tout seuls ; à distance, utilisez un code d'appairage.

Vous pouvez transférer des fichiers entre deux ordinateurs sans clé USB, sans câble et sans cloud.

Questions et réponses

Est-ce que ça marche entre Windows et Mac ?

Oui. OmniBeam fonctionne dans le navigateur des deux : vous pouvez envoyer d’un PC Windows vers un Mac, d’un Mac vers un Chromebook, ou entre deux ordinateurs quelconques.

Puis-je déplacer un dossier entier ?

Oui. Glissez le dossier sur l’autre ordinateur dans OmniBeam. À la réception, les fichiers peuvent être enregistrés dans un seul ZIP pour garder la structure du dossier.

Et les très gros fichiers ?

Les transferts directs n’ont pas de limite de taille, et si la connexion tombe, le transfert reprend là où il s’était arrêté. Pour un disque entier, un disque externe reste plus rapide.

Les deux ordinateurs doivent-ils être sur le même réseau ?

Non. Sur le même réseau, ils apparaissent automatiquement ; sinon, appairez-les une fois avec un code et ils se retrouvent ensuite.

Est-ce sûr sur un réseau partagé ou public ?

Oui. Chaque transfert est chiffré de bout en bout sur l’ordinateur qui envoie et déchiffré seulement sur celui qui reçoit : les autres personnes du réseau ne peuvent pas lire les fichiers.

Puis-je aussi copier du texte ou des liens ?

Oui. Collez du texte dans OmniBeam et envoyez-le, ou activez la synchronisation du presse-papiers pour envoyer en un clic le texte copié sur un ordinateur vers l’autre.

Faut-il un compte sur les deux ordinateurs ?

Non. Pas de compte, pas d’inscription et rien à installer. Ouvrez la page sur les deux ordinateurs et envoyez.
