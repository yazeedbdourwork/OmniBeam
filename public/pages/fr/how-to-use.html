Mode d'emploi d'OmniBeam, étape par étape

OmniBeam envoie fichiers et textes entre vos appareils, directement depuis le navigateur. Voici tout ce qu'il sait faire, étape par étape.

1. Appareils sur le même Wi‑Fi

  1. Ouvrez omnibeam.site sur les deux appareils.
  2. Chaque appareil affiche l'autre automatiquement, avec un nom au hasard comme « Blue Fox ». Touchez votre nom en bas pour renommer cet appareil.
  3. Touchez l'autre appareil et choisissez des fichiers, ou glissez-déposez des fichiers dessus. Sur ordinateur, vous pouvez aussi le survoler et choisir Envoyer des fichiers ou Envoyer un message.
  4. L'autre appareil demande d'accepter. Ensuite les fichiers arrivent et peuvent être enregistrés ou ouverts.

2. Appareils sur des réseaux différents

Les données mobiles, un VPN ou le relais privé iCloud placent les appareils sur des réseaux différents : ils ne se voient pas automatiquement. Appairez-les une fois :

  1. Touchez le bouton lien en haut et choisissez Créer un code d'association.
  2. Sur l'autre appareil, saisissez le code à 6 chiffres, scannez le QR code avec l'appareil photo ou ouvrez le lien partagé.
  3. Les deux appareils se retrouvent ensuite sur n'importe quel réseau. Vous pouvez les dissocier dans la même fenêtre.

3. Salons publics pour plusieurs appareils

Dans la fenêtre d'appairage, créez un salon public. Partagez son code de 5 lettres ou son lien : autant d'appareils que vous voulez peuvent le rejoindre depuis n'importe quel réseau. Idéal pour une classe, une réunion ou un échange de photos en famille. Ajoutez un mot de passe avant de créer le salon pour tenir les inconnus à l'écart.

4. Partager un fichier par lien

Dans le menu ⋯ en haut, touchez Partager des fichiers par lien, choisissez les fichiers et la durée de validité du lien. Les fichiers sont chiffrés sur votre appareil puis envoyés, et vous obtenez un lien et un QR code que n'importe qui peut ouvrir, même plus tard et sur n'importe quel appareil. Détails dans envoyer un fichier avec un lien.

5. Envoyer du texte et des liens

Faites un clic droit sur un appareil (ou un appui long sur un écran tactile) et choisissez Envoyer un message : le chat avec cet appareil s'ouvre, et vous tapez le texte, un lien ou ce que vous avez copié dans la zone du bas (voir Discuter avec un appareil plus bas). Les messages reçus se lisent dans le même chat : quand un message arrive, son chat s'ouvre de lui-même avec un son bref. Si vous êtes occupé à autre chose, une petite bannière en haut indique à la place qui l'a envoyé et ses premiers mots : touchez-la pour ouvrir le chat. Vous pouvez aussi coller dans la page pour envoyer ce qui est dans votre presse-papiers.

6. Fichiers reçus

Touchez le bouton de téléchargement en haut pour voir les fichiers reçus ces 7 derniers jours et les enregistrer à nouveau. Plusieurs fichiers peuvent être enregistrés ensemble dans un seul ZIP, et les photos HEIC de l'iPhone en JPG.

7. Installer OmniBeam comme une application

Sur Android et sur ordinateur avec Chrome ou Edge, OmniBeam propose Installer en bas de la page. Sur iPhone, touchez le bouton Partager dans Safari et choisissez Sur l'écran d'accueil. Installé sur Android, OmniBeam apparaît aussi dans le menu Partager de la galerie et des autres applications.

8. Windows : l'application OmniBeam du Microsoft Store

Installez l'application gratuite OmniBeam du Microsoft Store. Elle s'ouvre dans sa propre fenêtre, se lance depuis le menu Démarrer ou la barre des tâches et apparaît dans le menu Partager de Windows : clic droit sur des fichiers dans l'Explorateur, Partager puis OmniBeam. Dans Chrome ou Edge, l'extension OmniBeam envoie la page, un lien, une image ou le texte sélectionné d'un clic droit. Voir OmniBeam pour Windows pour les étapes.

9. Transferts plus rapides sur le même Wi‑Fi

Touchez ⚡ Transferts Wi‑Fi plus rapides en bas et autorisez le micro une fois. Rien n'est enregistré : les navigateurs ne communiquent l'adresse locale de l'appareil qu'aux sites qui ont cette autorisation, et grâce à elle les appareils se connectent directement par votre Wi‑Fi au lieu de passer par la connexion internet de la box. Touchez l'identifiant réseau à côté du nom de votre appareil pour lancer un test de connexion.

10. Dossiers, file d’attente, annulation et acceptation automatique

  • Dossiers : glissez un dossier sur un appareil, ou survolez-le et choisissez Envoyer un dossier. Il arrive en ZIP avec les mêmes dossiers à l’intérieur.
  • File d’attente et annulation : les fichiers envoyés pendant un transfert attendent leur tour. Touchez ✕ sur un appareil pour arrêter. Avec plusieurs appareils visibles, Envoyer à tous les envoie à chacun.
  • Acceptation automatique : dans la fenêtre de liaison, activez l’acceptation automatique pour un appareil associé afin de recevoir ses fichiers sans confirmation.
  • Appareils de confiance : dans la fenêtre de liaison, cochez « De confiance » à côté de vos propres appareils mémorisés. Ils s’affichent toujours sur l’écran principal, grisés hors ligne, et leurs fichiers arrivent sans confirmation.
  • Photos originales ou plus petites : les photos partent dans leur taille d’origine. Pour une connexion lente, choisissez Plus petites sous Photos dans la fenêtre Plus… ou dans la discussion, ou dans les Réglages sous Taille des photos à l’envoi : les grandes photos sont alors réduites à 2048 px sur le plus grand côté (JPG), dans le bon sens, et OmniBeam affiche combien vous avez gagné. Les GIF, les images avec des parties transparentes et les photos déjà petites partent telles quelles. Les Réglages peuvent aussi réduire les vidéos (720p). Les originaux sur votre appareil ne changent jamais, et votre choix est mémorisé.
  • Transfert interrompu : si la page se recharge ou si la connexion coupe, renvoyez les mêmes fichiers dans la journée : seule la partie manquante est envoyée.
  • Langue : choisissez English, العربية, Français, Español, Türkçe, Deutsch, Português, हिन्दी, Bahasa Indonesia, Русский, 日本語, 简体中文, 한국어, Italiano ou اردو en bas de la page.

11. Envoyer un lien par e-mail ou par SMS

Dans le menu ⋯ en haut, touchez Envoyer à un e-mail ou un téléphone (sur un ordinateur, c'est Envoyer par e-mail). Saisissez une adresse e-mail, ou un numéro de téléphone sur un mobile, puis choisissez les fichiers. OmniBeam les chiffre et les envoie au serveur, puis ouvre votre application e-mail ou Messages avec le lien de téléchargement déjà écrit : il ne reste qu'à appuyer sur Envoyer. Vous pouvez aussi remplir Envoyer à (facultatif) en partageant des fichiers par lien. Les SMS fonctionnent sur les téléphones ; les ordinateurs utilisent l'e-mail.

12. Options du lien : jusqu'à 7 jours, limite de téléchargements et code PIN

  • Durée : un lien est valable 1 heure, 1 jour, 3 jours ou jusqu'à 7 jours. Ensuite, les fichiers sont supprimés du serveur.
  • Téléchargements autorisés : choisissez sans limite, ou 1, 3, 5 ou 10 téléchargements. Une fois la limite atteinte, le lien ne fonctionne plus. Dans Vos liens, vous voyez combien de téléchargements ont été utilisés et combien il en reste.
  • Code PIN : ajoutez un code de 4 à 8 chiffres. La personne aura alors besoin du lien et du code pour télécharger. Donnez-lui le code autrement, par exemple par téléphone, pas dans le même message. Après 10 essais erronés, le lien est bloqué définitivement.

13. Poursuivre un envoi interrompu sur un autre appareil

Si un envoi vers l'un de vos appareils associés s'arrête en cours, par exemple parce que ce téléphone a quitté le Wi‑Fi, OmniBeam affiche quelques secondes plus tard une carte qui propose d'envoyer le reste à un autre de vos appareils associés. Touchez Envoyer à … et seuls les fichiers qui ne sont pas arrivés y sont envoyés. Si le premier appareil revient, le transfert reprend tout seul et la carte disparaît.

14. Historique, galerie et Tout enregistrer

Touchez le bouton de téléchargement en haut pour ouvrir l'Historique. Il a trois onglets :

  • Reçu : les fichiers et messages des 7 derniers jours, prêts à être enregistrés de nouveau.
  • Galerie : les photos et vidéos parmi eux, en miniatures. Touchez-en une pour la voir en grand, puis balayez ou utilisez les flèches du clavier pour passer à la suivante. Tout enregistrer enregistre toutes les photos et vidéos d'un coup : en un seul ZIP sur ordinateur, ou dans Photos sur iPhone et iPad.
  • Envoyé : ce que cet appareil a envoyé, avec Renvoyer (voir l'étape suivante).

Quand deux photos ou vidéos ou plus arrivent ensemble, la fenêtre qui les affiche a aussi un bouton Galerie. Sur iPhone et iPad, touchez Enregistrer dans Photos puis « Enregistrer l'image » ou « Enregistrer la vidéo », pour que les photos aillent dans l'app Photos et non dans Fichiers.

15. Historique des envois, Renvoyer et export

L'onglet Envoyé de l'Historique liste ce que vous avez envoyé ces 7 derniers jours : à quel appareil, quels fichiers, et s'ils sont arrivés, ont été refusés ou ont échoué. Touchez Renvoyer pour envoyer les mêmes fichiers au même appareil, ou choisissez-en un autre s'il n'est pas là. Après un rechargement de la page, Renvoyer vous demande de choisir à nouveau les fichiers, car les navigateurs ne les gardent pas. Exporter télécharge la liste sous forme de tableur (CSV) pour Excel ou Google Sheets, et Tout effacer vide l'onglet.

16. Salles d'équipe pour la famille ou le bureau

Une salle d'équipe est un lien fixe pour un groupe d'appareils. Touchez le bouton de lien en haut, tapez un nom comme Famille ou Bureau sous Salles d'équipe et touchez Créer. Partagez le lien ou montrez son code QR. Chaque appareil qui ouvre le lien une fois reste dans la salle, sur n'importe quel réseau, à chaque ouverture d'OmniBeam, sans code et sans nouvel appairage. Les cartes des membres affichent le nom de l'équipe, et vous pouvez activer l'acceptation automatique pour une équipe. Une salle d'équipe accueille jusqu'à 50 appareils, et vous pouvez la quitter dans la même fenêtre.

17. Nom, image et thème de votre appareil

Touchez le nom de votre appareil en bas, ou Changer le nom et l'image dans les Réglages, pour donner à cet appareil un nom et une image emoji. Les autres appareils voient les deux sur sa carte. Nom au hasard choisit un nouveau nom pour vous. Dans les Réglages, vous pouvez aussi choisir le Thème : Automatique suit votre appareil, ou choisissez Clair ou Sombre.

18. Synchronisation du presse-papiers et test de vitesse

  • Presse-papiers : associez vos appareils, puis activez Synchroniser le presse-papiers avec mes appareils associés dans les Réglages sur les deux. Le texte copié sur l'un arrive dans le presse-papiers de l'autre tant qu'OmniBeam est ouvert. Si le navigateur bloque l'accès au presse-papiers, touchez Envoyer mon presse-papiers.
  • Test de vitesse : touchez Tester la vitesse dans le menu ⋯ ou dans les Réglages pour voir à quelle vitesse cet appareil et un autre peuvent vraiment transférer, et par quel chemin passent les fichiers.

19. Photo, message vocal, partage d'écran et notes secrètes

  • Plus… : survolez un appareil et choisissez Plus…, ou appuyez longuement dessus sur un téléphone, pour voir tout ce que vous pouvez lui envoyer.
  • Prendre une photo : la caméra s'ouvre directement dans OmniBeam. Touchez Prendre la photo, puis Envoyer. Activez Scan de document pour des pages et des tableaux blancs nets en noir et blanc.
  • Message vocal : maintenez le bouton rond pendant que vous parlez et relâchez pour arrêter. Écoutez-le, puis envoyez-le.
  • Partager mon écran : sur un ordinateur, choisissez Partager mon écran puis une fenêtre ou tout l'écran. L'autre appareil, même une tablette ou le navigateur d'une télé, touche Regarder et le voit en direct, sans rien installer. Rien n'est enregistré.
  • Note secrète : envoyez un mot de passe ou un code qui ne s'affiche qu'une fois et n'est jamais enregistré. Dans Partager des fichiers par lien, Plutôt une note secrète crée un lien qui ne s'ouvre qu'une fois.
  • Aperçu : dans Fichiers reçus et Historique, touchez Aperçu pour voir un PDF, une image, un son, un texte ou du code avant de l'enregistrer.

20. Demander des fichiers à n'importe qui

Dans le menu ⋯ en haut, touchez Demander des fichiers. Écrivez ce dont vous avez besoin si vous le souhaitez (par exemple « les photos de samedi »), choisissez combien de temps le lien fonctionne, combien d'envois il accepte et un code PIN facultatif, puis envoyez le lien ou le code QR à qui vous voulez. La personne l'ouvre sur n'importe quel téléphone ou ordinateur, sans application, compte ni appairage, choisit des fichiers et touche Envoyer. Les fichiers sont chiffrés sur son appareil et arrivent sur le vôtre, dans Fichiers reçus. Si OmniBeam est fermé au moment de l'envoi, les fichiers attendent sur le serveur et arrivent la prochaine fois que vous l'ouvrez (avec les notifications activées, vous êtes prévenu). Vos liens de demande indique combien d'envois chaque lien a reçus.

21. Afficher des photos sur une TV

Ouvrez omnibeam.site/tv dans le navigateur de votre smart TV (ou sur un ordinateur relié à la TV), ou choisissez Mode TV dans le menu ⋯. La TV affiche un grand QR code : scannez-le avec l'appareil photo de votre téléphone, et OmniBeam s'ouvre sur le téléphone déjà associé à la TV. Touchez la TV et choisissez des photos ou des vidéos ; elles arrivent toutes seules et défilent en diaporama plein écran, une nouvelle photo toutes les 8 secondes. Avec la télécommande, ◀ et ▶ reculent et avancent, OK met en pause et Retour revient au QR code. Les téléphones sur le même Wi‑Fi voient la TV sans scanner (la TV demande avant d'accepter leurs fichiers). Le mode TV ne fait que recevoir : il n'envoie jamais rien. Chaque QR code associe un téléphone, et un nouveau code apparaît aussitôt pour le suivant.

Mot de passe pour la TV : choisissez Définir un code PIN sur l’écran de la TV et saisissez 4 à 8 chiffres. Après le scan du QR code, le téléphone demande le code PIN, et seuls les téléphones qui le saisissent peuvent s’associer. Avec un code PIN, la TV refuse les fichiers des téléphones non associés, même sur le même Wi‑Fi. Le code PIN ne quitte jamais la TV ni le téléphone. Comme tout transfert OmniBeam, les photos envoyées à la TV sont chiffrées de bout en bout.

22. Un bloc « Envoyez-moi des fichiers » sur votre site

Dans Demander des fichiers, choisissez 1 an (pour un site web), créez le lien, touchez Mettre sur votre site web et copiez le code dans votre site ou blog (un bloc HTML ou Intégration). Les visiteurs vous envoient des fichiers directement depuis la page, chiffrés de bout en bout, et ils arrivent ici comme tout envoi vers le lien. Comment ça marche. Sur WordPress, vous pouvez aussi utiliser l’extension OmniBeam gratuite : un bloc et un shortcode [omnibeam_box].

23. Telegram

Dans Réglages, touchez Associer Telegram, puis Démarrer dans la conversation avec le bot OmniBeam. Les fichiers, photos, vidéos, messages vocaux et textes envoyés au bot arrivent sur cet appareil, et Envoyer vers Telegram dans le menu ⋯ envoie fichiers et texte dans cette conversation. Telegram permet aux bots de recevoir des fichiers jusqu'à 20 Mo et d'en envoyer jusqu'à 50 Mo. Les fichiers qui passent par Telegram ne sont pas chiffrés de bout en bout, car Telegram les voit.

Dépannage

  • Les appareils n'apparaissent pas : vérifiez qu'ils sont sur le même Wi‑Fi et sans VPN, ou appairez-les avec un code.
  • « Envoi via le serveur » ou trajet « internet » sur le même Wi‑Fi : voir comment corriger des transferts lents sur le même Wi‑Fi. Cela fonctionne quand même, plus lentement, et reste chiffré de bout en bout.
  • Le transfert s'arrête quand l'écran s'éteint : les téléphones mettent en pause les pages web quand l'écran se verrouille ou que vous changez d'app. Gardez OmniBeam ouvert et l'écran allumé jusqu'à la fin ; OmniBeam demande au téléphone de rester éveillé et affiche un rappel sur la carte. Si l'écran s'éteint quand même, rouvrez OmniBeam et le transfert reprend tout seul là où il s'était arrêté.

24. Discuter avec un appareil

Choisissez Discussion dans la fenêtre Plus… d’un appareil, ou Discussion à côté d’un appareil associé dans la fenêtre de lien. Vous voyez tout ce que vous avez envoyé à cet appareil et reçu de lui ces 7 derniers jours, messages et fichiers, dans l’ordre comme dans une messagerie : ce qui arrive d’un côté, ce que vous envoyez de l’autre. Les photos reçues affichent une miniature, et chaque fichier reçu a Enregistrer (et Aperçu quand c’est possible). Écrivez dans la zone du bas pour envoyer un message, ou touchez le trombone pour envoyer des fichiers. Un appareil associé hors ligne les reçoit dès qu’il ouvre OmniBeam. Quand quelque chose de nouveau arrive, un petit chiffre apparaît sur la carte de l’appareil : touchez-le pour ouvrir la discussion. La discussion est faite à partir de l’historique de cet appareil ; rien de plus n’est enregistré et rien ne va sur notre serveur. Chaque Envoyer un message ouvre ce chat : c'est le seul endroit où l'on écrit et lit les messages. Quand un message arrive, sa discussion s'ouvre d'elle-même avec un son bref (et une vibration sur les téléphones) ; si vous êtes occupé à autre chose, une bannière s'affiche à la place, et vous recevez une notification quand la discussion n'est pas à l'écran. Le bouton haut-parleur en haut coupe le son (aussi dans les Réglages, Son des messages). Le bouton corbeille efface la discussion avec cet appareil sur cet appareil uniquement, avec quelques secondes pour annuler.

25. Numériser en PDF

  1. Choisissez Numériser en PDF dans la fenêtre Plus… d’un appareil. L’appareil photo s’ouvre dans OmniBeam (ou touchez Utiliser l'app Appareil photo).
  2. Posez la page à plat sous une bonne lumière, avec ses quatre coins dans l’image, et touchez Prendre la page. Prenez autant de pages que nécessaire, puis touchez Terminé.
  3. OmniBeam trouve les bords de chaque page et la redresse. Si une page est mal coupée, touchez-la et faites glisser les quatre coins sur ceux de la page.
  4. Choisissez Couleur ou Noir et blanc (texte noir net sur blanc, idéal pour les documents et les tickets), avancez ou reculez des pages, ou supprimez-en une.
  5. Touchez Envoyer à …. Le PDF est créé sur votre téléphone, sans rien envoyer pour le fabriquer, puis il part comme n’importe quel fichier. Vous pouvez aussi Partager par lien ou Enregistrer le PDF.

26. Avantages de soutien

OmniBeam est gratuit, sans publicité, et rien n’est bloqué. Si vous faites un don avec le bouton ♥, vous pouvez recevoir un code de soutien en remerciement. Saisissez-le dans les Réglages sous Soutien et touchez Débloquer : les autres appareils voient alors un ♥ sur la carte de votre appareil, et vous obtenez quatre thèmes de couleur en plus (Océan, Forêt, Coucher de soleil et Rose) et des images en plus pour votre appareil dans Changer le nom et l'image. Le code fonctionne sur tous vos appareils et continue de marcher hors ligne.
