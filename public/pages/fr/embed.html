Un bloc « Envoyez-moi des fichiers » pour votre site ou blog

Laissez vos visiteurs, clients ou élèves vous envoyer des fichiers directement depuis votre page. Vous collez un petit code ; les fichiers sont chiffrés sur leur appareil et arrivent dans OmniBeam sur le vôtre.

Étapes

  1. Ouvrez omnibeam.site sur l'appareil qui doit recevoir les fichiers et touchez Demander des fichiers dans le menu ⋯.
  2. Écrivez ce dont vous avez besoin (facultatif), choisissez 1 an (pour un site web) sous « Lien valable » et touchez Créer le lien de demande.
  3. Touchez Mettre sur votre site web, puis Copier le code.
  4. Collez le code dans votre page : dans WordPress un bloc HTML personnalisé, dans Blogger un gadget HTML/JavaScript, dans Wix un élément Intégrer du HTML, dans Squarespace un bloc Code.

Les visiteurs voient un petit bloc avec « Choisir des fichiers », un champ facultatif pour leur nom et un bouton Envoyer. Ils n'ont besoin ni d'application ni de compte. Les fichiers arrivent sur votre appareil dans Fichiers reçus ; si OmniBeam y est fermé, ils attendent sur le serveur et arrivent à l'ouverture, avec une notification si vous les avez activées.

WordPress : l’extension OmniBeam gratuite

Sur WordPress, c’est encore plus simple : téléchargez l’extension OmniBeam (omnibeam-wordpress.zip), puis dans WordPress allez dans Extensions → Ajouter → Téléverser une extension, choisissez le zip et touchez Activer. Collez votre code (ou seulement son lien) dans Réglages → OmniBeam Box, puis ajoutez le bloc OmniBeam: Send me files à une page, ou le shortcode [omnibeam_box]. Un bloc avec son propre lien et sa hauteur : [omnibeam_box url="https://omnibeam.site/embed/r/…" height="520"]. L’extension n’accepte que les blocs d’omnibeam.site, et les fichiers ne passent jamais par votre site WordPress.

Gardez la ligne « Propulsé par OmniBeam » : c'est ce qui permet au bloc de rester gratuit.

Est-ce privé et sûr ?

  • Chaque envoi est chiffré dans le navigateur du visiteur. Sa clé est scellée avec la clé publique de votre appareil, et seul votre appareil possède la clé privée correspondante : ni OmniBeam ni quelqu'un qui lit le code de votre page ne peut ouvrir les fichiers.
  • Le code de votre page est public. Quiconque le voit peut vous envoyer des fichiers et lire le texte « de quoi avez-vous besoin » ainsi que le nom de votre appareil : n'y écrivez rien de privé.
  • Seul votre appareil peut télécharger les envois, et chacun est supprimé du serveur dès qu'il l'a reçu. Les fichiers non récupérés sont supprimés après 7 jours.
  • Les limites habituelles restent en place : une taille maximale par envoi, une limite par réseau et par heure, et au plus 100 envois par jour et par bloc.
  • Supprimez le lien de demande dans la même fenêtre à tout moment et le bloc cesse aussitôt de fonctionner.

Questions et réponses

Est-ce payant ?

Non. Le bloc est gratuit, sans compte, sans extension et sans publicité.

Puis-je l'utiliser sur plusieurs pages ?

Oui. Collez le même code sur toutes les pages voulues ; tous les envois arrivent sur le même appareil. Créez un lien de demande distinct si vous voulez les différencier.

Pourquoi le bloc cesse-t-il de fonctionner au bout d'un moment ?

Chaque lien de demande expire à la date choisie. Pour un site, choisissez 1 an, et créez un nouveau lien et un nouveau code avant l'échéance.

Quelqu'un peut-il utiliser mon bloc pour m'envoyer du spam ?

Tout visiteur de la page peut vous envoyer des fichiers, comme avec une adresse e-mail. Les fichiers ne s'ouvrent jamais tout seuls, les envois sont limités par réseau et par jour, et vous pouvez supprimer le lien pour désactiver le bloc.
